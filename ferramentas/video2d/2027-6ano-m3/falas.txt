Hardware e software: a banda do computador!

O Pedro estava no meio do jogo quando o celular travou. A rodinha ficou girando, girando… Ele ficou tão bravo que já ia jogar o celular na cama! A Lara segurou o braço dele: calma! Isso é problema de hardware ou de software? E o Pedro: hã?

Para entender, imagine que o computador é uma banda. Todo computador tem duas partes que trabalham juntas, como os instrumentos e a música.

Os instrumentos são o hardware: as peças físicas, que dá para tocar com a mão. Teclado, mouse, monitor, processador, cabo e pen drive. Tudo isso é hardware.

E a música é o software: os programas. Dá para ouvir, dá para ver funcionando, mas não dá para pegar com a mão! O navegador, os jogos, o editor de texto e os aplicativos do celular são software.

Um precisa do outro! Instrumento sem música fica parado: hardware sem software não faz nada. E música sem instrumento não toca: o software precisa do hardware para funcionar.

Tem até uma brincadeira para lembrar: hardware é o que você chuta; software é o que você xinga quando trava! Mas calma, ninguém precisa chutar nem xingar nada, tá?

Toda banda tem um maestro. No computador, ele se chama sistema operacional: um software especial, que é o primeiro a ligar e comanda todo o resto. Ele mostra a área de trabalho, abre as janelas e conversa com as peças.

Os sistemas operacionais mais conhecidos são o Windows e o Linux, nos computadores, e o Android e o iOS, nos celulares.

E as músicas que a banda toca são os aplicativos: cada um faz uma tarefa para você. O navegador abre os sites, como este portal. O editor de texto serve para escrever trabalhos. A calculadora faz contas. O tocador de música toca as músicas. E o jogo… diverte!

Agora o Pedro entendeu: a tela estava inteira, as peças estavam funcionando. Quem travou foi o jogo, um aplicativo: problema de software! Ele fechou o jogo, abriu de novo, e voltou a funcionar. Missão cumprida!

Onde eu uso isso? Quando o celular trava, o problema costuma ser de software; quando a tela quebra, é de hardware. Quando você instala um jogo, está colocando um software novo no aparelho. E, na oficina de celular, o técnico troca peças, que é hardware, ou formata e atualiza o sistema, que é software.

Agora é com vocês: abram a Missão 3 no portal!
