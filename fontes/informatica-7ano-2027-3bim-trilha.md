## 🤝 Missão 1 – Protocolos: as regras da conversa
**Objetivo:** saber que os aparelhos seguem regras para conversar.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Protocolo** é um conjunto de **regras** para os aparelhos conversarem. É como o telefonema: primeiro “Alô?”, depois a conversa, no fim “Tchau”.
| Passo | O que acontece |
| 1 | O navegador **pede** a página |
| 2 | O servidor **responde** mandando a página |
| 3 | A página aparece na tela |

Se a página não existe, aparece o **erro 404**: página não encontrada.
| Protocolo | Para que serve |
| 🌐 HTTP | As páginas da internet |
| 📶 Wi-Fi | Internet sem fio |
| 🎧 Bluetooth | Ligar o fone sem fio |
### 📖 O que significa?
- **Protocolo**: regras para os aparelhos conversarem.
- **Navegador**: programa que abre os sites.
- **Servidor**: computador que guarda o site.
- **Wi-Fi**: rede sem fio.
- **HTTP**: o protocolo das páginas da internet.
- **Bluetooth**: liga aparelhos pertinho, como o fone sem fio.
### 🌎 Onde eu uso isso?
- Ao **abrir um site**.
- Ao usar o **fone sem fio**.
### ✅ Perguntas rápidas
1. ( ) Protocolo é um conjunto de regras.
2. ( ) O erro 404 quer dizer que a página foi encontrada.
3. ( ) O Bluetooth liga o fone sem fio.
### 🧠 Resumo da Aula
**Protocolo** são as regras da conversa. O navegador **pede**, o servidor **responde**. Erro **404** = página não encontrada.
**Palavras-chave:** protocolo · navegador · servidor

## 🔒 Missão 2 – HTTP, HTTPS e o cadeado
**Objetivo:** saber o que quer dizer o cadeado do site.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
| Endereço | Parece com… | O que acontece |
| **http://** | 📮 Cartão-postal | Os dados viajam **abertos** |
| **https://** e 🔒 | ✉️ Carta lacrada | Os dados viajam **cifrados** |

**Cuidado:** site falso também pode ter cadeado. Confira sempre o **nome do site**.
### 📖 O que significa?
- **HTTPS**: endereço com cadeado; os dados viajam cifrados.
- **Cifrado**: embaralhado, ninguém lê no caminho.
- **Cadeado** 🔒: mostra que a conversa é cifrada.
### 🌎 Onde eu uso isso?
- No **portal da escola**: tem cadeado.
- Antes de digitar a **senha** de um jogo.
### ✅ Perguntas rápidas
1. ( ) No http, os dados viajam abertos.
2. ( ) O https é como uma carta lacrada.
3. ( ) Todo site com cadeado é honesto.
### 🧠 Resumo da Aula
**http** = cartão-postal (aberto). **https** com 🔒 = carta lacrada (cifrado). O cadeado não prova que o site é honesto: confira o **nome**.
**Palavras-chave:** HTTPS · cifrado · cadeado

## 🔑 Missão 3 – Senhas e verificação em duas etapas
**Objetivo:** reconhecer uma senha forte e a segunda prova.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
| Senha fraca | Senha forte |
| Curta: 123456 | Comprida |
| Tem o seu nome | Não tem nada pessoal |
| Só números | Mistura letras, números e símbolos |

**Exemplo de senha forte (inventada):** Pipa!Verde8Voa.
A **verificação em duas etapas** pede a senha e **mais uma prova**:
| Tipo de prova | Exemplo |
| 🧠 Algo que você sabe | A senha |
| 📱 Algo que você tem | O código no celular |
| 👆 Algo que você é | A digital |

O código do celular é **só seu**. Quem pede é **golpista**.
### 📖 O que significa?
- **Senha forte**: comprida e misturada.
- **Verificação em duas etapas**: senha + mais uma prova.
- **Código**: números que chegam no celular para entrar na conta.
### 🌎 Onde eu uso isso?
- Na conta do **jogo**.
- No **celular**, com a digital.
### ✅ Perguntas rápidas
1. ( ) 123456 é uma senha forte.
2. ( ) A digital é algo que você é.
3. ( ) Posso passar o código do celular para um amigo.
### 🧠 Resumo da Aula
Senha forte é **comprida** e **misturada**. Duas etapas = senha + **mais uma prova**. O código é **só seu**.
**Palavras-chave:** senha forte · duas etapas · código

## 🎣 Missão 4 – Golpes e phishing
**Objetivo:** reconhecer um golpe.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Phishing** é o golpe com mensagem ou site **falso**, como uma isca de pescaria.
| Sinal | Exemplo |
| ⏰ Pressa | “Só hoje!” |
| 🎁 Prêmio fácil | “Você ganhou um celular!” |
| 🔑 Pede senha ou código | “Mande o código do SMS” |
| 💸 Pede dinheiro | “Me manda um Pix” |

**Caiu num golpe?** Pare de responder e **conte para um adulto**.
### 📖 O que significa?
- **Golpe**: enganar alguém para tirar vantagem.
- **Phishing**: golpe com mensagem ou site falso.
- **Isca**: o que chama a atenção para a pessoa cair.
### 🌎 Onde eu uso isso?
- Nas **mensagens** do celular.
- Nos **jogos**, com moedas grátis.
### ✅ Perguntas rápidas
1. ( ) Pressa é sinal de golpe.
2. ( ) Pedir a senha é normal.
3. ( ) Se cair num golpe, conto para um adulto.
### 🧠 Resumo da Aula
Sinais de golpe: **pressa**, **prêmio fácil**, pedido de **senha**, **código** ou **dinheiro**. Caiu? **Conte para um adulto**.
**Palavras-chave:** golpe · phishing · isca

## 💬 Missão 5 – Empatia na rede
**Objetivo:** escrever com respeito na internet.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Empatia** é se colocar no lugar do outro.
| Na conversa ao vivo | Na mensagem escrita |
| Você vê o rosto | Você não vê o rosto |
| Ouve o tom de voz | A brincadeira pode parecer ofensa |

**Combinados:**
- 🔠 Não escrever TUDO EM MAIÚSCULAS: parece **grito**.
- 🔁 Ler antes de enviar.
- ⏸️ Com raiva, esperar passar.

Antes de postar: é **verdade**? É **gentil**? É **necessário**?
### 📖 O que significa?
- **Empatia**: se colocar no lugar do outro.
- **Postar**: publicar na internet.
- **Tom**: o jeito de falar (bravo, alegre, brincando).
### 🌎 Onde eu uso isso?
- No **grupo da turma**.
- Nos **comentários** de vídeos.
### ✅ Perguntas rápidas
1. ( ) Empatia é se colocar no lugar do outro.
2. ( ) Escrever tudo em maiúsculas parece grito.
3. ( ) Com raiva, é bom responder na hora.
### 🧠 Resumo da Aula
**Empatia** é se colocar no lugar do outro. Na mensagem escrita, não se vê o rosto. Antes de postar: é **verdade**, **gentil** e **necessário**?
**Palavras-chave:** empatia · postar · tom

## 🛑 Missão 6 – Cyberbullying: como agir
**Objetivo:** saber o que fazer no cyberbullying.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Cyberbullying** é humilhar alguém pela internet, **de propósito** e **várias vezes**.
| Papel | Quem é | O que pode fazer |
| 🎯 Alvo | Quem sofre | Guardar **prints**, **bloquear** e **contar para um adulto** |
| 👀 Espectador | Quem vê | **Não repassar** e **apoiar** o colega |
| 😈 Autor | Quem faz | **Parar** e pedir desculpas |

Desde 2024, o cyberbullying é **crime** no Brasil.
### 📖 O que significa?
- **Cyberbullying**: humilhar alguém pela internet, várias vezes.
- **Print**: foto da tela, que serve de prova.
- **Bloquear**: impedir que a pessoa fale com você.
### 🌎 Onde eu uso isso?
- No **grupo da turma**.
- Nos **jogos on-line**.
### ✅ Perguntas rápidas
1. ( ) Cyberbullying é humilhar alguém pela internet.
2. ( ) Repassar a montagem do colega ajuda.
3. ( ) O alvo pode contar para um adulto.
### 🧠 Resumo da Aula
**Cyberbullying** é humilhar pela internet, várias vezes. O alvo guarda **prints** e **conta para um adulto**. O espectador **não repassa**: repassar a montagem **piora**.
**Palavras-chave:** cyberbullying · print · bloquear

## 📶 Missão 7 – Extra: Wi-Fi público
**Objetivo:** usar o Wi-Fi da rua com cuidado.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Wi-Fi público** é a rede da praça, da rodoviária, da lanchonete.
| Risco | Como acontece |
| 🎭 Rede falsa | Um golpista cria uma rede com nome parecido |
| 👀 Rede aberta | Outras pessoas estão na mesma rede |

**Como se proteger:** pergunte o **nome certo** da rede e use os **dados móveis** para o banco e as senhas.
### 📖 O que significa?
- **Wi-Fi público**: rede de um lugar aberto.
- **Rede aberta**: rede sem senha.
- **Dados móveis**: a internet do celular (4G, 5G).
### 🌎 Onde eu uso isso?
- Na **rodoviária**.
- Na **lanchonete**.
### ✅ Perguntas rápidas
1. ( ) Rede aberta é a rede sem senha.
2. ( ) Golpistas podem criar redes falsas.
3. ( ) No Wi-Fi da praça, entro no banco sem problema.
### 🧠 Resumo da Aula
No **Wi-Fi público**, pergunte o **nome certo** da rede e use os **dados móveis** para o que é importante. No Wi-Fi da praça, **evito entrar no banco**.
**Palavras-chave:** Wi-Fi público · rede aberta · dados móveis

## 🗣️ Missão 8 – Extra: Debate respeitoso
**Objetivo:** discordar com respeito.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
| ✅ Argumento (ataca a ideia) | ❌ Ataque pessoal (ataca a pessoa) |
| “Eu discordo, porque é caro.” | “Você não sabe nada.” |
| “Entendi, mas penso diferente.” | “Cala a boca.” |

**Regras:** ouvir até o fim, esperar a vez, dar um motivo.
### 📖 O que significa?
- **Debate**: conversa com opiniões diferentes.
- **Argumento**: o motivo da sua opinião.
- **Ataque pessoal**: ofender a pessoa.
### 🌎 Onde eu uso isso?
- No **grupo da turma**.
- Nos **comentários**.
### ✅ Perguntas rápidas
1. ( ) No debate, a gente critica a ideia.
2. ( ) “Você não sabe nada” é um argumento.
3. ( ) Esperar a vez é uma regra do debate.
### 🧠 Resumo da Aula
Critique a **ideia**, não a **pessoa**. Use **argumentos** e espere a vez.
**Palavras-chave:** debate · argumento · ataque pessoal
