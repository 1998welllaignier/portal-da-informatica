## 📦 Missão 1 – Pacotes: a informação viaja em pedaços
**Objetivo:** saber que a foto viaja em pedaços.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Na internet, a foto viaja dividida em **pacotes** (pedaços).
| Etiqueta do pacote | Para que serve |
| 📬 Endereço de destino | Para onde vai |
| 🔢 Número de ordem | A posição do pedaço |

Os pacotes podem chegar **fora de ordem**. O **número** ajuda a montar de novo.
{{cena:pacotes-simples}}
### 📖 O que significa?

- **Destino**: para onde vai.
### 🌎 Onde eu uso isso?
- Ao mandar uma **foto**.
- Quando um **vídeo** carrega.
### ✅ Perguntas rápidas
1. ( ) A foto viaja em pacotes.
2. ( ) O pacote tem o endereço de destino.
3. ( ) Os pacotes sempre chegam em ordem.
### 🧠 Resumo da Aula
A informação viaja em **pacotes**, com o **destino** e o número de ordem.
**Palavras-chave:** pacote · destino

## 💾 Missão 3 – Bits e bytes: guardar, compactar e achar
**Objetivo:** comparar o tamanho dos arquivos.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
O computador guarda tudo em **bits**: 0 ou 1.
| Medida | Quanto é | Exemplo do que cabe |
| 🔹 Byte (B) | 8 bits | Uma letra |
| 🖼️ MB (megabyte) | cerca de mil KB | Uma foto |
| 🎬 GB (gigabyte) | cerca de mil MB | Um filme |

Do menor para o maior: **byte → KB → MB → GB**. Muitas fotos? Compacto num .zip.
### 📖 O que significa?
- **Bit**: 0 ou 1.
- **Byte**: 8 bits.
- **Compactar**: juntar arquivos num .zip menor.
- **KB, MB e GB**: medidas de tamanho; cada uma é cerca de mil vezes a anterior.
### 🌎 Onde eu uso isso?
- Quando o celular avisa **“armazenamento cheio”**.
- Para mandar **muitas fotos** de uma vez.
### ✅ Perguntas rápidas
1. ( ) Um byte tem 8 bits.
2. ( ) GB é maior que MB.
3. ( ) Uma foto é maior que um filme.
### 🧠 Resumo da Aula
**Bit** é 0 ou 1; **byte** são 8 bits. Byte → KB → MB → GB. **Compactar** faz um .zip.
**Palavras-chave:** bit · byte · compactar

## 🛒 Missão 5 – Consumo consciente e obsolescência
**Objetivo:** pensar antes de trocar de celular.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
| Tipo de obsolescência | Exemplo |
| 📉 Perceptiva (pela moda) | Trocar só porque saiu um novo |

Antes de trocar: ele **funciona**? Dá para **consertar**? Para durar: **capa** e longe do **calor**. O calor estraga a bateria.
### 📖 O que significa?
- **Obsolescência**: trocar o aparelho antes da hora.
- **Consertar**: arrumar o que quebrou.
### 🌎 Onde eu uso isso?
- Quando sai um **celular novo**.
- Quando a **tela quebra**.
### ✅ Perguntas rápidas
1. ( ) Antes de trocar, vejo se dá para consertar.
2. ( ) A capa protege o celular.
3. ( ) O sol faz bem para a bateria.
### 🧠 Resumo da Aula
**Obsolescência**: trocar antes da hora. Antes de trocar: **consertar**? Para durar: capa e longe do calor.
**Palavras-chave:** obsolescência · consertar

## 💾 Missão 8 – Extra: Backup
**Objetivo:** guardar uma cópia dos arquivos importantes.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Backup** é uma **cópia** dos arquivos em **outro lugar**.
| Onde guardar a cópia | Vantagem | Cuidado |
| 💾 Pen drive | Não precisa de internet | Pode perder |
| ☁️ Nuvem | Acessa de qualquer lugar | Precisa de senha forte |

Celular quebrou? Quem tem backup **não perde** as fotos.
### 📖 O que significa?
- **Backup**: cópia de segurança.
- **Nuvem**: guardar arquivos na internet.
- **Pen drive**: pequeno aparelho que guarda arquivos.
### 🌎 Onde eu uso isso?
- Ao **trocar de celular**.
- Nos **trabalhos** da escola.
### ✅ Perguntas rápidas
1. ( ) Backup é uma cópia de segurança.
2. ( ) A nuvem guarda arquivos na internet.
3. ( ) A cópia fica no mesmo lugar do original.
### 🧠 Resumo da Aula
**Backup**: cópia em outro lugar, no pen drive ou na **nuvem**.
**Palavras-chave:** backup · nuvem
