## 🧭 Missão 1 – Algoritmos do dia a dia
**Objetivo:** saber o que é um algoritmo: passos em ordem para resolver um problema.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Um **algoritmo** é uma lista de **passos em ordem** para resolver um problema. Uma receita é um algoritmo!
O computador **não adivinha nada**. Cada passo precisa ser **claro e preciso**: dizer exatamente o que fazer.
| Algoritmo ruim (vago) | Algoritmo bom (claro e preciso) |
| “Faz o suco aí.” | 1. Pegar um copo. 2. Colocar 2 colheres de suco em pó. 3. Encher o copo com água. 4. Mexer com a colher. |

“Coloque **2 colheres** de açúcar” é **preciso**. “Coloque **um pouco** de açúcar” é **vago**: quanto é um pouco?
### 📖 O que significa?
- **Algoritmo**: passos em ordem para resolver um problema.
- **Instrução**: cada passo do algoritmo.
- **Programa**: algoritmo escrito para o computador.
- **Resultado**: o que se consegue no fim.
- **Lista**: uma sequência de itens, um embaixo do outro.
### 🌎 Onde eu uso isso?
- Numa **receita** de bolo.
- No **caminho** de casa até a escola.
- No **tutorial** de um jogo.
### ✅ Perguntas rápidas
1. ( ) Algoritmo é uma lista de passos em ordem para resolver um problema.
2. ( ) O computador adivinha o que queremos.
3. ( ) “Coloque 2 colheres de açúcar” é uma instrução precisa.
### 🧠 Resumo da Aula
**Algoritmo** é uma lista de passos em ordem. Cada passo é uma **instrução** clara e precisa, porque o computador não adivinha. O algoritmo para o computador se chama **programa**.
**Palavras-chave:** algoritmo · instrução · preciso · programa

## ➡️ Missão 2 – Sequência: a ordem importa
**Objetivo:** fazer os passos um depois do outro, na ordem certa.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Na **sequência**, o computador faz um passo **depois do outro**, sem pular nenhum. **A ordem importa!**
| Ordem certa | Ordem trocada | O que dá errado |
| 1. Calçar a meia. 2. Calçar o tênis. | 1. Calçar o tênis. 2. Calçar a meia. | A meia fica por cima do tênis! |

O **robô** do labirinto também segue uma sequência. Cada seta anda **uma casa**:
| Comando | O que o robô faz |
| ➡️ | Anda uma casa para a direita |
| ⬅️ | Anda uma casa para a esquerda |
| ⬆️ | Anda uma casa para cima |
| ⬇️ | Anda uma casa para baixo |

Cuidado com as paredes 🧱! O robô precisa chegar na estrela ⭐.
### 📖 O que significa?
- **Sequência**: passos um depois do outro, na ordem.
- **Comando**: uma ordem para o robô, como uma seta.
- **Executar**: mandar o computador fazer o programa (botão ▶ Executar).
### 🌎 Onde eu uso isso?
- Para **atravessar a rua**: parar, olhar para os dois lados e só então atravessar.
- Para **escovar os dentes**: primeiro o creme, depois escovar.
### ✅ Perguntas rápidas
1. ( ) Na sequência, os passos são feitos um depois do outro.
2. ( ) Trocar a ordem dos passos nunca muda o resultado.
3. ( ) No labirinto, cada seta anda uma casa.
### 🧠 Resumo da Aula
Na **sequência**, o computador faz um passo depois do outro, sem pular. **A ordem importa**: trocar a ordem muda o resultado. No labirinto, cada seta anda uma casa.
**Palavras-chave:** sequência · ordem · comando · executar

## 🔁 Missão 3 – Repetição: o comando repita
**Objetivo:** usar o “repita” para não escrever o mesmo passo muitas vezes.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Quando um passo se repete, usamos o **repita**. Em vez de escrever ➡️ ➡️ ➡️, escrevemos **repita 3× ➡️**.
| Sem repetição | Com repetição |
| ➡️ ➡️ ➡️ ➡️ ⬇️ ⬇️ (6 comandos) | repita 4× ➡️ · repita 2× ⬇️ (2 comandos) |
| Bater palma, bater palma, bater palma | Repita 3 vezes: bater palma |

No portal, clique numa seta e use o **+** para aumentar quantas vezes ela repete, e o **−** para diminuir.
Toda repetição precisa **parar**. A repetição que nunca para se chama **laço infinito**.
### 📖 O que significa?
- **Repetição**: fazer o mesmo passo várias vezes.
- **Repita**: o comando que diz quantas vezes.
- **Laço infinito**: repetição que nunca para.
### 🌎 Onde eu uso isso?
- O **despertador** toca todo dia na mesma hora.
- A **música** em modo repetir toca de novo.
### ✅ Perguntas rápidas
1. ( ) “Repita 3 vezes: bater palma” bate 3 palmas.
2. ( ) ➡️ ➡️ ➡️ é o mesmo que repita 3× ➡️.
3. ( ) O laço infinito para depois de 3 vezes.
### 🧠 Resumo da Aula
A **repetição** faz o mesmo passo várias vezes. O **repita** diz quantas vezes: ➡️ ➡️ ➡️ = repita 3× ➡️. A repetição que nunca para é o **laço infinito**.
**Palavras-chave:** repetição · repita · laço infinito

## 🔀 Missão 4 – Seleção: se… então… senão
**Objetivo:** escolher o que fazer respondendo uma pergunta de sim ou não.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Às vezes o computador precisa **escolher**. Ele faz uma pergunta de **sim ou não**, a **condição**.
| Se… (condição) | então… (quando é verdade) | senão… (quando é mentira) |
| estiver chovendo | levo o guarda-chuva | vou sem guarda-chuva |
| o sinal estiver verde | atravesso | espero |

**Se** a resposta é **sim** (verdadeiro), faz o **então**. **Senão** (falso), faz o **senão**.
“Está chovendo?” é uma boa condição. “Que horas são?” **não é**, porque a resposta não é sim nem não.
### 📖 O que significa?
- **Seleção**: escolher um caminho.
- **Condição**: pergunta de sim ou não.
- **Verdadeiro**: a resposta é sim.
- **Falso**: a resposta é não.
### 🌎 Onde eu uso isso?
- **Se** a senha estiver certa, o celular abre; **senão**, aparece um aviso.
- No **jogo**: **se** pegar a moeda, ganha pontos.
### ✅ Perguntas rápidas
1. ( ) Na seleção, o computador escolhe um caminho com uma pergunta de sim ou não.
2. ( ) “Que horas são?” é uma boa condição.
3. ( ) Quando a condição é falsa, o computador faz o senão.
### 🧠 Resumo da Aula
Na **seleção**, o computador responde uma **condição** (sim ou não). **Se** for sim, faz o **então**; **senão**, faz o outro caminho.
**Palavras-chave:** seleção · condição · se · então · senão

## 📥 Missão 5 – Entradas e saídas de um problema
**Objetivo:** saber do que o algoritmo precisa (entrada) e o que ele entrega (saída).
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Todo problema tem três partes:
| Pergunta | Nome | Exemplo: fazer um bolo |
| Do que eu preciso para começar? | **Entradas** | farinha, ovos, leite |
| O que eu faço com elas? | **Processamento** | misturar e assar |
| O que eu quero no fim? | **Saída** | o bolo pronto |

Na **calculadora**: os números que você digita são **entradas**. O resultado na tela é a **saída**.
### 📖 O que significa?
- **Entrada**: o que o algoritmo recebe para começar.
- **Processamento**: os passos que o algoritmo faz.
- **Saída**: o resultado que o algoritmo entrega.
### 🌎 Onde eu uso isso?
- Para **mandar um áudio**: a voz entra pelo microfone e sai o áudio enviado.
- No **mapa** do celular: digito aonde quero ir e aparece o caminho.
### ✅ Perguntas rápidas
1. ( ) A farinha e os ovos são entradas do bolo.
2. ( ) O resultado na tela da calculadora é uma entrada.
3. ( ) Misturar e assar é o processamento.
### 🧠 Resumo da Aula
**Entradas** são o que o algoritmo recebe. O **processamento** são os passos. A **saída** é o resultado: entradas → processamento → saída.
**Palavras-chave:** entrada · processamento · saída

## 🧩 Missão 6 – Decompor: dividir para resolver
**Objetivo:** dividir um problema grande em partes menores.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Um problema grande fica fácil se dividirmos em **partes menores**. Isso é **decompor**.
**Exemplo: organizar o aniversário da turma.**
| Parte (subproblema) | O que fazer |
| 🎈 Decoração | balões e faixa |
| 🍰 Comida | bolo e suco |
| 🎵 Diversão | músicas e brincadeiras |
| 🧹 Limpeza | recolher o lixo e arrumar as cadeiras |

Cada parte se chama **subproblema**. Quando todas ficam prontas, o problema grande está resolvido.
### 📖 O que significa?
- **Decompor**: dividir um problema grande em partes menores.
- **Subproblema**: cada parte menor.
- **Equipe**: grupo que divide o trabalho.
### 🌎 Onde eu uso isso?
- Para **arrumar o quarto**: arrumar a cama, guardar as roupas e recolher os brinquedos.
- No **trabalho em grupo**: cada um faz uma parte.
### ✅ Perguntas rápidas
1. ( ) Decompor é dividir um problema grande em partes menores.
2. ( ) Cada parte menor se chama subproblema.
3. ( ) Decompor deixa o problema mais difícil.
### 🧠 Resumo da Aula
**Decompor** é dividir um problema grande em partes menores, os **subproblemas**. Cada parte fica mais fácil.
**Palavras-chave:** decompor · subproblema · parte · equipe

## 🐞 Missão 7 – Extra: Caça ao erro
**Objetivo:** achar e consertar o erro de um algoritmo.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Um erro no algoritmo se chama **bug** (em inglês, “inseto”). Achar e consertar o erro é **depurar**.
Em 1947, a equipe da cientista Grace Hopper achou uma mariposa presa dentro de um computador. A história do “inseto” ficou famosa.
| Passo | O que fazer |
| 1. Testar | Execute e veja o que acontece |
| 2. Comparar | Deu o resultado certo? |
| 3. Achar | Ache o primeiro passo errado |
| 4. Corrigir | Mude só esse passo e teste de novo |

Erros comuns: um passo **fora de ordem**, um passo que **falta** ou um passo **a mais**.
### 📖 O que significa?
- **Bug**: um erro no algoritmo ou no programa.
- **Depurar**: achar e corrigir o erro.
- **Testar**: executar para ver se funciona.
### 🌎 Onde eu uso isso?
- Quando o **jogo trava**, é um bug.
- A **atualização** do celular corrige bugs.
### ✅ Perguntas rápidas
1. ( ) Bug é um erro no algoritmo.
2. ( ) Depurar é achar e corrigir o erro.
3. ( ) Para depurar, é melhor mudar todos os passos de uma vez.
### 🧠 Resumo da Aula
**Bug** é um erro. **Depurar** é achar e corrigir: testar, comparar, achar o primeiro passo errado e mudar só ele.
**Palavras-chave:** bug · depurar · testar · erro

## 🐢 Missão 8 – Extra: Desenho com a tartaruga
**Objetivo:** fazer desenhos com setas e com o repita.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Na linguagem **Logo**, uma **tartaruga** 🐢 anda pela tela e deixa um **rastro**. O rastro vira **desenho**!
No portal, a tartaruga passa pelos pontos ⚪, que viram 🟩.
| Sem repetição | Com repetição |
| ➡️ ➡️ ⬇️ ⬇️ ⬅️ ⬅️ ⬆️ ⬆️ (8 comandos) | repita 2× ➡️ · repita 2× ⬇️ · repita 2× ⬅️ · repita 2× ⬆️ (4 blocos) |

Um **quadrado** tem **4 lados iguais**. Um **retângulo** tem 2 lados compridos e 2 curtos.
### 📖 O que significa?
- **Tartaruga**: o “lápis” que anda e deixa o rastro.
- **Rastro**: o caminho que vira desenho.
- **Quadrado**: figura com 4 lados iguais.
### 🌎 Onde eu uso isso?
- O **robô aspirador** anda por um caminho programado.
- A **impressora 3D** segue setas para desenhar e montar peças.
### ✅ Perguntas rápidas
1. ( ) A tartaruga deixa um rastro que vira desenho.
2. ( ) O quadrado tem 4 lados iguais.
3. ( ) O retângulo tem 4 lados iguais.
### 🧠 Resumo da Aula
A **tartaruga** anda e deixa um **rastro**: o caminho vira desenho. O **quadrado** tem 4 lados iguais, e o repita deixa o desenho mais curto.
**Palavras-chave:** tartaruga · rastro · quadrado · retângulo
