## 🧱 Missão 1 – Programar com blocos: sequência, repetição e seleção
**Objetivo:** montar programas com blocos usando sequência, repetição e seleção.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Um **programa** é uma lista de passos que o computador entende. Aqui, os passos são **blocos** que se encaixam como peças de montar.
O computador lê os blocos **de cima para baixo**, um de cada vez:
| Bloco | O que faz | Exemplo |
| 📺 mostrar na tela | Escreve uma mensagem na Tela do programa | mostrar na tela “Olá!” → aparece Olá! |
| 🔁 repita 3 vezes | Faz os blocos de dentro várias vezes | repita 3 vezes: mostrar “pulo” → pulo, pulo, pulo |
| 🔀 se … faça … senão | Escolhe um caminho | se nota ≥ 5, mostrar “passou”; senão, mostrar “recuperação” |

São três ideias:
| Ideia | No bloco | Na vida |
| ➡️ Sequência | Um bloco embaixo do outro | Acordar, escovar os dentes, tomar café |
| 🔁 Repetição | Blocos dentro do **repita** | Fazer 10 polichinelos |
| 🔀 Seleção | Blocos dentro do **se** | Se chover, levar guarda-chuva; senão, levar boné |

**Atenção à ordem:** se o “mostrar ‘fim’” ficar **dentro** do repita, ele aparece 3 vezes; se ficar **embaixo** do repita (fora dele), aparece só 1 vez.
Uma **variável** é uma caixinha com nome que guarda um valor: **definir nota para 7** guarda 7 na caixinha “nota”.
### 📖 O que significa?
- **Programa**: passos escritos numa linguagem que o computador entende. Todo aplicativo e todo jogo é um programa.
- **Bloco**: peça do editor que dá uma ordem ao computador. Os blocos se encaixam.
- **Rodar** (ou **executar**): fazer o computador seguir os blocos, de cima para baixo.
- **Repetição**: fazer os blocos de dentro várias vezes, com o **repita**.
- **Seleção**: escolher o caminho com **se … faça … senão**.
- **Variável**: caixinha com nome que guarda um valor.
### 🌎 Onde eu uso isso?
- O **despertador** é um programa com seleção: se for 6h, então toca.
- Nos **jogos**, a vida do personagem é uma variável: começa em 3 e diminui.
- A **máquina de lavar** segue uma sequência: molhar, bater, enxaguar.
### ✅ Perguntas rápidas
1. ( ) O computador lê os blocos de cima para baixo.
2. ( ) O bloco repita serve para escolher um caminho.
3. ( ) Uma variável é uma caixinha com nome que guarda um valor.
### 🧠 Resumo da Aula
O **programa** é feito de **blocos**, lidos de cima para baixo. **Sequência**: um bloco depois do outro. **Repetição**: o **repita** faz várias vezes. **Seleção**: o **se** escolhe o caminho. Dentro ou fora do repita muda o resultado. **Variável** é uma caixinha com nome.
**Palavras-chave:** programa · bloco · rodar · sequência · repetição · seleção · variável

## 📝 Missão 2 – Listas no programa
**Objetivo:** criar uma lista, pegar um item pela posição e saber o tamanho da lista.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
A **lista** é **uma variável só** que guarda **vários itens em ordem**.
Cada item tem uma **posição**, contada a partir do **1**:
| Posição | 1 | 2 | 3 | 4 |
| Item da lista **frutas** | maçã | uva | caju | açaí |

Com a lista, o programa consegue:
| Bloco | O que faz | Com a lista frutas |
| em lista … obter # | Pega o item de uma posição | item nº 3 → **caju** |
| tamanho de | Conta quantos itens a lista tem | tamanho de frutas → **4** |
| 👉 para cada item … na lista | Repete os blocos **uma vez para cada item** | mostra maçã, uva, caju, açaí |
### 📖 O que significa?
- **Lista**: variável que guarda vários itens em ordem, como a lista de chamada.
- **Item**: cada valor guardado na lista.
- **Posição**: o número do lugar do item na lista. Aqui começa no 1.
- **Tamanho**: quantos itens a lista tem.
- **Para cada**: bloco que passa por todos os itens da lista, um de cada vez.
### 🌎 Onde eu uso isso?
- A **playlist** é uma lista de músicas.
- O **carrinho da loja on-line** é uma lista de produtos.
- A **lista de chamada** da escola tem um nome em cada posição.
### ✅ Perguntas rápidas
1. ( ) Uma lista guarda vários itens numa variável só.
2. ( ) Na lista maçã, uva, caju, o item da posição 2 é maçã.
3. ( ) O bloco tamanho de mostra quantos itens a lista tem.
### 🧠 Resumo da Aula
A **lista** guarda vários **itens** em ordem. Cada item tem uma **posição** (começa no 1). O programa pega um item pela posição, conta o **tamanho** e passa por todos com o **para cada**.
**Palavras-chave:** lista · item · posição · tamanho · para cada

## 🗂️ Missão 3 – Registros: a ficha de cada coisa
**Objetivo:** guardar várias informações sobre uma coisa só numa ficha com campos.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Para guardar **várias informações diferentes sobre uma coisa só**, como nome, idade e turma de um aluno, usamos um **registro**: uma **ficha** com **campos**.
| Ficha (registro) do aluno | |
| campo **nome** | Ana |
| campo **idade** | 12 |
| campo **turma** | 7º A |

Cada campo tem um **nome** (idade) e um **valor** (12).
**Lista × registro:**
| | 📝 Lista | 🗂️ Registro (ficha) |
| Guarda | Vários itens parecidos | Várias informações de uma coisa só |
| Acha pela | Posição (1, 2, 3…) | Nome do campo (nome, idade…) |
| Exemplo | Nomes da turma | Os dados de um aluno |
### 📖 O que significa?
- **Registro**: várias informações sobre uma mesma coisa, guardadas juntas. Aqui chamamos de **ficha**.
- **Campo**: cada informação da ficha, com um nome (idade) e um valor (12).
- **Valor**: o que está guardado no campo.
- **Cadastro**: conjunto de fichas, como o cadastro dos alunos da escola.
### 🌎 Onde eu uso isso?
- O **contato do celular** é uma ficha: nome, telefone, aniversário.
- No **jogo**, cada personagem tem uma ficha: nome, vida, força.
- Na **secretaria da escola**, cada aluno tem uma ficha de matrícula.
### ✅ Perguntas rápidas
1. ( ) Um registro guarda várias informações sobre uma mesma coisa.
2. ( ) Num registro, achamos a informação pela posição 1, 2, 3.
3. ( ) O contato do celular é um exemplo de registro.
### 🧠 Resumo da Aula
O **registro** (ficha) guarda várias informações sobre uma coisa só. Cada informação é um **campo**, com **nome** e **valor**. Na lista achamos pela **posição**; no registro, pelo **nome do campo**.
**Palavras-chave:** registro · ficha · campo · valor · cadastro

## 🐞 Missão 4 – Depurar: achar e consertar erros
**Objetivo:** achar e consertar erros nos programas, testando e comparando.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Todo programador erra! Um erro no programa se chama **bug** (inseto, em inglês). Achar e consertar o erro é **depurar**.
Os erros mais comuns:
| Erro | O que acontece | Exemplo |
| 🔃 Ordem trocada | Os passos saem fora de ordem | mostrar “fim” antes do repita |
| 📦 Bloco no lugar errado | Dentro em vez de fora | “fim” dentro do repita aparece 3 vezes |
| 🔢 Número errado | Repete demais ou de menos | repita 4 em vez de 3 |

**O método do detetive 🕵️ (4 passos):**
| Passo | O que fazer |
| 1. Rodar | Aperte ▶️ e veja o que aparece |
| 2. Comparar | Compare com o que **devia** aparecer |
| 3. Achar | Procure o bloco do erro |
| 4. Mudar uma coisa só e testar de novo | Uma mudança por vez |

Por que mudar uma coisa só? **Para saber o que resolveu** o erro.
### 📖 O que significa?
- **Bug**: em inglês, “inseto”: um erro no programa.
- **Depurar**: achar e consertar os erros de um programa.
- **Testar**: rodar o programa para ver se ele faz o que devia.
- **Resultado esperado**: o que o programa **devia** mostrar.
### 🌎 Onde eu uso isso?
- Quando um **aplicativo atualiza** “com correções de erros”, alguém depurou o programa.
- Quando a **receita** dá errado, você procura o que fez diferente.
- Nos **jogos**, os testadores procuram bugs antes de lançar.
### ✅ Perguntas rápidas
1. ( ) Bug é um erro no programa.
2. ( ) Para depurar, o melhor é mudar tudo de uma vez.
3. ( ) Comparar o que apareceu com o que devia aparecer ajuda a achar o erro.
### 🧠 Resumo da Aula
Erro no programa é **bug**; consertar é **depurar**. Método do detetive: **rodar**, **comparar** com o esperado, **achar** o bloco e **mudar uma coisa só**.
**Palavras-chave:** bug · depurar · testar · resultado esperado

## 🧩 Missão 5 – Decompor e reaproveitar
**Objetivo:** dividir um problema grande em partes e usar um bloco próprio mais de uma vez.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Problema grande assusta. O segredo é **decompor**: dividir em partes menores.
**Exemplo: organizar a festa da turma**
| Parte | Quem resolve |
| 🎈 Decoração | Grupo 1 |
| 🍰 Comida | Grupo 2 |
| 🎵 Música | Grupo 3 |
| 🎮 Brincadeiras | Grupo 4 |

Quando uma parte **se repete**, criamos um **bloco nosso** com nome: ele é escrito **uma vez só** e **chamado** quando precisar. Isso é **reaproveitar**.
**Exemplo: a música com refrão**
| Sem bloco próprio | Com o bloco **refrão** |
| verso 1 · la la la · verso 2 · la la la | criar o bloco **refrão** (la la la) uma vez só; programa: verso 1 · **refrão** · verso 2 · **refrão** |

Mudou o refrão? Muda **dentro do bloco**, uma vez só, e vale em todos os lugares.
### 📖 O que significa?
- **Decompor**: dividir um problema grande em partes menores.
- **Reaproveitar**: usar de novo uma parte que já está pronta.
- **Bloco próprio**: blocos que você junta e dá um nome. Fica na gaveta 🧩 Meus blocos.
- **Chamar**: usar o bloco próprio no programa.
### 🌎 Onde eu uso isso?
- Num **trabalho em grupo**, cada um faz uma parte.
- Na **fábrica de carros**, cada setor monta uma parte.
- O **refrão** de uma música é cantado várias vezes, mas foi escrito uma vez só.
### ✅ Perguntas rápidas
1. ( ) Decompor é dividir um problema grande em partes menores.
2. ( ) O bloco próprio precisa ser escrito de novo cada vez que é usado.
3. ( ) Chamar o bloco é usar o bloco no programa.
### 🧠 Resumo da Aula
**Decompor** é dividir o problema em partes. A parte que se repete vira um **bloco próprio**, escrito uma vez e **chamado** quando precisar: isso é **reaproveitar**.
**Palavras-chave:** decompor · reaproveitar · bloco próprio · chamar

## 👥 Missão 6 – Programar em dupla
**Objetivo:** programar em dupla com os papéis de piloto e navegador.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Programadores trabalham muito em **dupla**: um computador, duas cabeças e dois **papéis**:
| Papel | O que faz | O que NÃO faz |
| 🕹️ Piloto | Fica com o mouse e o teclado e monta os blocos | Não decide tudo sozinho |
| 🧭 Navegador | Lê, pensa no próximo passo e confere cada bloco | Não pega o mouse |

**A cada 10 minutos, troquem de papel!**
| Passo | O que a dupla faz |
| 1. 📝 Planejar | Ler o problema juntos |
| 2. 🧱 Montar | O piloto monta; o navegador confere |
| 3. ▶️ Testar | Rodar depois de cada parte |
| 4. 🔄 Trocar | Trocar de papel |

Falem com respeito: o erro é **da dupla**, não de um só.
### 📖 O que significa?
- **Programação em dupla**: duas pessoas programando juntas no mesmo computador.
- **Piloto**: quem fica com o mouse e o teclado e monta os blocos.
- **Navegador**: quem lê, planeja e confere, sem mexer no mouse.
- **Revezar**: trocar de papel de tempos em tempos.
### 🌎 Onde eu uso isso?
- No **carro**, o motorista dirige e quem está ao lado olha o mapa.
- Num **jogo cooperativo**, cada um tem uma função no time.
- Nas **empresas de tecnologia**, programar em dupla ajuda a errar menos.
### ✅ Perguntas rápidas
1. ( ) O piloto fica com o mouse e monta os blocos.
2. ( ) O navegador pega o mouse sempre que quiser.
3. ( ) Na programação em dupla, os papéis devem ser revezados.
### 🧠 Resumo da Aula
O **piloto** monta os blocos; o **navegador** lê e confere, sem pegar o mouse. Os dois **revezam** a cada 10 minutos: **planejar**, **montar**, **testar** e **trocar**.
**Palavras-chave:** programação em dupla · piloto · navegador · revezar

## 🔍 Missão 7 – Extra: Desafios de depuração
**Objetivo:** usar o método do detetive para consertar programas com listas e fichas.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Hoje é dia de detetive 🕵️! Use o método da Missão 4: **rodar**, **comparar**, **achar** e **mudar uma coisa só**.
**Pistas dos erros:**
| Pista | Erro provável |
| Apareceu o item errado da lista | Posição errada (lembre: começa no 1) |
| Apareceu “(sem idade)” | O nome do campo está diferente (idade × idadee) |
### 📖 O que significa?
- **Pista**: o sinal que ajuda a achar o erro.
- **Hipótese**: o seu palpite sobre onde está o erro.
- **Corrigir**: mudar o programa para ele fazer o que devia.
### 🌎 Onde eu uso isso?
- O **mecânico** testa uma peça de cada vez até achar o defeito.
- O **médico** faz perguntas e exames até descobrir a doença.
- Na **conta errada**, você refaz passo a passo para achar onde errou.
### ✅ Perguntas rápidas
1. ( ) Se apareceu o item errado da lista, a posição pode estar errada.
2. ( ) Uma hipótese é um palpite sobre onde está o erro.
3. ( ) Mudar tudo de uma vez ajuda a saber o que resolveu.
### 🧠 Resumo da Aula
Pistas: item errado = **posição** errada; “(sem idade)” = **nome do campo** diferente. A **hipótese** é o palpite que você testa, mudando uma coisa de cada vez.
**Palavras-chave:** pista · hipótese · corrigir · posição · campo

## ❓ Missão 8 – Extra: O placar do quiz
**Objetivo:** contar os acertos de um quiz com uma variável contadora.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Todo jogo de perguntas (**quiz**) precisa de um programa que **confere as respostas** e **conta os pontos**.
O programa compara duas listas, posição por posição:
| Posição | 1 | 2 | 3 | 4 |
| Lista **gabarito** (respostas certas) | B | A | D | C |
| Lista **respostas** (do jogador) | B | C | D | C |
| Acertou? | ✅ | ❌ | ✅ | ✅ |

Resposta igual ao gabarito: **✅ Acertou**. Resposta diferente: **❌ Errou**.

Para contar os acertos usamos um **contador**: uma variável que começa em **0** e **aumenta 1** a cada acerto. Aqui são **3 acertos**.
### 📖 O que significa?
- **Quiz**: jogo de perguntas e respostas.
- **Gabarito**: a lista das respostas certas.
- **Contador**: variável que começa em 0 e aumenta de 1 em 1 para contar alguma coisa.
### 🌎 Onde eu uso isso?
- O **placar do Wayground** conta os pontos assim.
- Na **prova do portal**, o programa compara as suas respostas com o gabarito.
- O **contador de passos** do celular soma 1 a cada passo.
### ✅ Perguntas rápidas
1. ( ) O gabarito é a lista das respostas certas.
2. ( ) O contador começa em 0 e aumenta a cada acerto.
3. ( ) Para corrigir o quiz, não precisa comparar as listas.
### 🧠 Resumo da Aula
O programa do **quiz** compara o **gabarito** com as **respostas**, posição por posição. O **contador** começa em 0 e soma 1 a cada acerto.
**Palavras-chave:** quiz · gabarito · contador
