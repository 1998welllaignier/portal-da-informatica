## 🤝 Missão 1 – Protocolos: as regras da conversa
**Objetivo:** entender o que é um protocolo e por que aparelhos diferentes conseguem conversar pela rede.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Num telefonema, todo mundo segue as mesmas **regras**, mesmo sem perceber:
| Passo | No telefonema |
| 1 | Quem atende diz **“Alô?”** |
| 2 | Quem ligou se **apresenta** |
| 3 | Os dois **conversam**, um de cada vez |
| 4 | Os dois se **despedem** e desligam |

Os aparelhos também precisam de regras combinadas para conversar. Essas regras se chamam **protocolo**. Graças a elas, um celular de uma marca conversa com um computador de outra marca: os dois seguem o **mesmo protocolo**.
| Protocolo | Para que serve |
| 🌐 **HTTP** | Pedir e receber as páginas da internet |
| 🔒 **HTTPS** | O mesmo que o HTTP, mas com os dados **cifrados** (embaralhados) |
| 🏠 **IP** | Dar um **endereço** a cada aparelho, para os dados chegarem ao lugar certo |
| 📶 **Wi-Fi** | Ligar os aparelhos à rede **sem fio** |
| 🎧 **Bluetooth** | Ligar aparelhos **pertinho** um do outro, como o fone sem fio |

**A conversa do navegador com o site (HTTP):**
| Passo | O que acontece |
| 1 | Você digita o endereço ou clica num link |
| 2 | O navegador **pede** a página ao servidor do site |
| 3 | O servidor **responde** mandando a página |
| 4 | O navegador **mostra** a página na tela |

Se a página não existe, o servidor responde com o famoso **erro 404**: “página não encontrada”.
### 📖 O que significa?
- **Protocolo**: conjunto de regras combinadas para dois aparelhos conversarem.
- **HTTP** (do inglês *HyperText Transfer Protocol*, “protocolo de transferência de hipertexto”): protocolo das páginas da internet.
- **IP** (do inglês *Internet Protocol*, “protocolo da internet”): dá um endereço a cada aparelho ligado à rede.
- **Navegador**: programa que abre os sites, como o Chrome ou o Edge.
- **Servidor**: computador que guarda o site e responde aos pedidos.
- **Bluetooth**: ligação sem fio para aparelhos que estão bem perto.
- **Wi-Fi**: rede sem fio, que liga os aparelhos sem cabo.
- **HTTPS**: o HTTP com os dados cifrados (você vai ver na Missão 2).
- **Link**: texto ou botão que, ao ser clicado, abre outra página.
### 🌎 Onde eu uso isso?
- Toda vez que você **abre um site**, o navegador e o servidor seguem o HTTP.
- O **fone sem fio** conversa com o celular pelo Bluetooth.
- O celular entra no **Wi-Fi da escola** seguindo o protocolo do Wi-Fi.
### 🎯 Missão
🟢 **Básico** — no portal: ligue cada protocolo ao que ele faz, coloque o telefonema em ordem e responda sobre protocolos.
🟡 **Desafio** — no portal: o que aconteceu? Descubra o protocolo de cada situação.
🔴 **Turbo** — no portal: jogo da memória dos protocolos.
⚠️ Os computadores são usados por todos: **nunca apague nem mexa nos arquivos dos colegas**.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Protocolo é um conjunto de regras para os aparelhos conversarem.
2. ( ) Só aparelhos da mesma marca conseguem conversar pela rede.
3. ( ) O HTTP serve para pedir e receber as páginas da internet.
4. ( ) O erro 404 quer dizer que a página não foi encontrada.
5. ( ) O Bluetooth serve para ligar aparelhos muito longe, em outra cidade.
### 🧠 Resumo da Aula
**Protocolo** é o conjunto de regras que os aparelhos seguem para conversar. **HTTP** pede e recebe páginas; **HTTPS** faz o mesmo com os dados cifrados; **IP** dá o endereço; **Wi-Fi** liga sem fio; **Bluetooth** liga aparelhos pertinho. O navegador **pede**, o servidor **responde**, o navegador **mostra**. Erro **404** = página não encontrada.
**Palavras-chave:** protocolo · HTTP · HTTPS · IP · Wi-Fi · Bluetooth · navegador · servidor

## 🔒 Missão 2 – HTTP, HTTPS e o cadeado
**Objetivo:** saber a diferença entre HTTP e HTTPS e o que o cadeado do navegador mostra (e o que ele não mostra).
📅 **Data da aula:** ........ / ........
### 💡 Para começar
| Endereço | Parece com… | O que acontece |
| **http://** | 📮 Um **cartão-postal**: quem pegar no caminho consegue ler | Os dados viajam **abertos** |
| **https://** e um 🔒 | ✉️ Uma **carta lacrada**: no caminho, ninguém lê | Os dados viajam **cifrados** |

O **S** do HTTPS vem de *secure*, “seguro” em inglês. O 🔒 **cadeado** aparece ao lado do endereço quando a conversa com o site é cifrada.
**Atenção, a pegadinha:** o cadeado mostra que a **conversa é cifrada**, mas **não prova que o site é honesto**. Um site falso também pode ter cadeado. Por isso:
| Antes de digitar uma senha | Por quê |
| 🔒 Confira se tem **https** e cadeado | Sem eles, a senha viaja aberta |
| 🔤 Leia o **nome do site**, letra por letra | Golpistas criam nomes parecidos, trocando uma letra |
| 🔗 Prefira **digitar o endereço** você mesmo | Links de mensagens podem levar a sites falsos |
### 📖 O que significa?
- **HTTPS** (HTTP + *Secure*): o HTTP com os dados cifrados.
- **Cifrado**: embaralhado, para que só o site e você consigam ler.
- **Cadeado** 🔒: símbolo do navegador que mostra que a conversa com o site é cifrada.
- **Endereço do site**: o texto que aparece na barra de cima do navegador, como https://portal.professorwell.com.br.
- **Site falso**: página que imita um site verdadeiro para roubar dados.
- **Link**: texto ou botão que, ao ser clicado, abre outra página.
### 🌎 Onde eu uso isso?
- Ao entrar no **portal da escola**: o endereço começa com https e tem o cadeado.
- Antes de digitar a **senha** de um jogo ou de uma rede social.
- Ao receber um **link** com o nome de um site conhecido escrito um pouco diferente.
### 🎯 Missão
🟢 **Básico** — no portal: separe os endereços com e sem criptografia, ligue cada parte ao que ela é e responda sobre o cadeado.
🟡 **Desafio** — no portal: posso digitar a senha aqui? Decida para cada site.
🔴 **Turbo** — no portal: complete o texto do cadeado.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) No http, os dados viajam abertos, como um cartão-postal.
2. ( ) O S do HTTPS vem de *secure*, “seguro”.
3. ( ) O cadeado prova que o site é honesto.
4. ( ) Golpistas criam sites com nomes parecidos com os verdadeiros.
5. ( ) No https, os dados viajam cifrados.
### 🧠 Resumo da Aula
**HTTP** = cartão-postal (dados abertos). **HTTPS** com 🔒 = carta lacrada (dados cifrados). O cadeado mostra que a **conversa é cifrada**, mas **não prova que o site é honesto**: confira o **nome do site**, letra por letra, e prefira digitar o endereço.
**Palavras-chave:** HTTP · HTTPS · cifrado · cadeado · endereço do site · site falso

## 🔑 Missão 3 – Senhas e verificação em duas etapas
**Objetivo:** criar senhas fortes e entender como a verificação em duas etapas protege a conta.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
| Senha fraca | Senha forte |
| Curta: 123456, 2014 | Comprida: 12 caracteres ou mais |
| Tem nome, apelido ou data de nascimento | Não tem nada pessoal |
| Só números ou só letras | Mistura maiúsculas, minúsculas, números e símbolos |
| A mesma em todos os sites | Uma diferente para cada conta importante |

**Dica da frase-senha:** junte palavras que só você imagina e misture: **Pipa!Verde8Voa** é longa e fácil de lembrar (é só um exemplo: não use esta). Outro exemplo inventado: **Lago#Sol55Peixe**.
**Verificação em duas etapas:** além da senha, a conta pede uma **segunda prova**. Assim, mesmo se alguém descobrir a senha, não entra.
| Tipo de prova | Exemplo |
| 🧠 Algo que você **sabe** | A senha, o PIN |
| 📱 Algo que você **tem** | O código que chega no celular |
| 👆 Algo que você **é** | A digital, o rosto |

**Regra de ouro:** o código que chega no celular é **só seu**. Se alguém pedir esse código, **é golpe**.
### 📖 O que significa?
- **Senha forte**: senha comprida e misturada, sem nada pessoal.
- **Frase-senha**: várias palavras misturadas com números e símbolos, longa e fácil de lembrar.
- **Verificação em duas etapas**: proteção que pede a senha e mais uma prova (um código, a digital).
- **PIN**: senha curta de números, como a do celular.
- **Caractere**: cada letra, número, símbolo ou espaço.
### 🌎 Onde eu uso isso?
- Ao criar a conta de um **jogo** ou de um **e-mail**.
- Quando chega um **código por SMS** para entrar numa conta.
- Ao **desbloquear o celular** com a digital.
### 🎯 Missão
🟢 **Básico** — no portal: separe as senhas fortes e fracas, ligue cada proteção ao que ela faz e responda sobre as duas etapas.
🟡 **Desafio** — no portal: invente 2 senhas fortes (que você não vai usar de verdade).
🔴 **Turbo** — no portal: sabe, tem ou é? Separe as provas das duas etapas.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Uma senha com o seu nome e o ano em que você nasceu é forte.
2. ( ) Senha forte mistura letras, números e símbolos.
3. ( ) Na verificação em duas etapas, a conta pede uma segunda prova além da senha.
4. ( ) Pode passar para outra pessoa o código que chegou no seu celular.
5. ( ) A digital é um exemplo de algo que você é.
### 🧠 Resumo da Aula
Senha forte é **comprida**, **misturada** e sem nada **pessoal**; a **frase-senha** ajuda a lembrar. A **verificação em duas etapas** pede a senha e mais uma prova: algo que você **tem** (código no celular) ou que você **é** (digital). O código é **só seu**: quem pede é golpista.
**Palavras-chave:** senha forte · frase-senha · verificação em duas etapas · PIN · caractere

## 🎣 Missão 4 – Golpes e phishing
**Objetivo:** reconhecer os sinais de golpe e saber o que fazer.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Phishing** (parecido com *fishing*, “pescaria” em inglês) é o golpe que usa uma **isca**: uma mensagem ou um site **falso** que imita um banco, uma loja, um jogo ou a escola.
| Golpe | Como é |
| 👪 Falso parente | “Oi, troquei de número. Me manda um Pix?” |
| 🎁 Prêmio falso | “Você ganhou um celular! Pague só o frete hoje.” |
| 🔗 Link falso | “Sua conta será bloqueada. Clique aqui e digite a senha.” |
| 🎮 Moedas grátis | “Ganhe moedas do jogo: é só entrar com a sua senha neste site.” |

**Sinais de golpe:**
| Sinal | Exemplo |
| ⏰ **Pressa** | “Só hoje!”, “Em 1 hora!” |
| 🎁 **Prêmio fácil** | Algo caro de graça |
| 🔑 Pede **senha ou código** | “Mande o código que chegou no SMS” |
| 💸 Pede **dinheiro** | “Me empresta, depois te pago” |
| ✍️ **Erros** de português ou endereço estranho | “Promossão”, “banc0-oficial.xyz” |

**Caí num golpe, e agora?** Pare de responder, troque a senha, ative as duas etapas e **conte para um adulto de confiança**. Avise os seus contatos para não caírem também.
### 📖 O que significa?
- **Golpe**: enganar alguém para tirar vantagem, como dinheiro ou dados.
- **Phishing**: golpe com mensagem ou site falso que serve de isca.
- **Isca**: algo que chama a atenção para a pessoa cair no golpe.
- **Golpista**: quem aplica o golpe.
- **Perfil falso**: conta que finge ser outra pessoa ou empresa.
- **Link**: texto ou botão que, ao ser clicado, abre outra página.
### 🌎 Onde eu uso isso?
- Nas **mensagens** do celular e no **e-mail**.
- Nos **jogos on-line**, com ofertas de moedas grátis.
- Nas **redes sociais**, com perfis falsos de lojas.
### 🎯 Missão
🟢 **Básico** — no portal: marque os sinais de golpe, descubra o tipo de cada golpe e coloque em ordem o que fazer quando cair num golpe.
🟡 **Desafio** — no portal: caixa de entrada: golpe ou mensagem normal?
🔴 **Turbo** — no portal: ache as palavras do golpe no caça-palavras.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Phishing é o golpe que usa uma mensagem ou um site falso como isca.
2. ( ) Pressa e prêmio fácil são sinais de golpe.
3. ( ) Moedas grátis em troca da senha do jogo são uma boa oferta.
4. ( ) Se cair num golpe, é bom contar para um adulto de confiança.
5. ( ) Erros de português podem ser um sinal de golpe.
### 🧠 Resumo da Aula
**Phishing** é o golpe da isca falsa. Sinais: **pressa**, **prêmio fácil**, pedido de **senha, código ou dinheiro**, **erros** e endereço estranho. Caiu num golpe? **Pare de responder**, **troque a senha**, ative as **duas etapas** e **conte para um adulto**.
**Palavras-chave:** golpe · phishing · isca · golpista · perfil falso

## 💬 Missão 5 – Empatia na rede
**Objetivo:** lembrar que do outro lado da tela tem uma pessoa e escrever com respeito.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Empatia** é se colocar no lugar do outro. Na internet, a gente não vê o rosto nem ouve o tom de voz da pessoa, por isso é fácil ser mal entendido.
| Na conversa ao vivo | Na mensagem escrita |
| Você vê o **rosto** da pessoa | Você **não vê** a reação dela |
| O **tom de voz** mostra se é brincadeira | A brincadeira pode parecer **ofensa** |
| Dá para pedir desculpas na hora | O texto pode ser **copiado** e espalhado |

**Combinados da boa conversa na rede:**
| Combinado | Por quê |
| 🔠 Não escrever TUDO EM MAIÚSCULAS | Na internet, parece que você está **gritando** |
| 🔁 Ler antes de enviar | Evita mandar algo de que vai se arrepender |
| 🙂 Usar emoji para mostrar o tom | Ajuda a mostrar que é uma brincadeira ou um carinho |
| ⏸️ Esperar a raiva passar | Com raiva, a gente escreve coisas que machucam |
| 🤝 Ajudar quem não entendeu | Explicar com gentileza e oferecer ajuda |
| 🙏 Machucou alguém sem querer? | Pedir desculpas e apagar a mensagem |

**Antes de postar, faça três perguntas:** é **verdade**? É **gentil**? É **necessário**? Se a resposta for “não” para alguma delas, **não poste**.
### 📖 O que significa?
- **Empatia**: se colocar no lugar do outro e imaginar o que ele sente.
- **Tom**: o jeito como algo é dito (bravo, alegre, brincando).
- **Postar**: publicar algo na internet.
- **Emoji**: desenho pequeno que mostra emoções ou ideias nas mensagens.
- **Aplicativo** (ou *app*): programa instalado no celular ou no computador.
### 🌎 Onde eu uso isso?
- No **grupo da turma** no aplicativo de mensagens.
- Nos **comentários** de vídeos e fotos.
- No **chat dos jogos on-line**.
### 🎯 Missão
🟢 **Básico** — no portal: separe as mensagens gentis e as que machucam, ligue cada combinado ao seu motivo e responda sobre empatia.
🟡 **Desafio** — no portal: escolha a melhor resposta para cada situação no grupo da turma.
🔴 **Turbo** — no portal: coloque em ordem o que fazer antes de postar.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Empatia é se colocar no lugar do outro.
2. ( ) Na internet, escrever tudo em maiúsculas parece que você está gritando.
3. ( ) Na mensagem escrita, sempre dá para perceber o tom de voz.
4. ( ) Antes de postar, vale perguntar: é verdade, é gentil, é necessário?
5. ( ) Com raiva, o melhor é responder na hora.
### 🧠 Resumo da Aula
**Empatia** é se colocar no lugar do outro. Na mensagem escrita não se vê o rosto nem o **tom**, então a brincadeira pode virar ofensa. Combinados: não escrever **em maiúsculas**, **ler antes de enviar**, usar **emoji** para o tom e **esperar a raiva passar**. Antes de postar: é **verdade**, **gentil** e **necessário**?
**Palavras-chave:** empatia · tom · postar · emoji

## 🛑 Missão 6 – Cyberbullying: como agir
**Objetivo:** reconhecer o cyberbullying e saber como agir, sendo o alvo ou quem está vendo.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Cyberbullying** é quando alguém **humilha, ameaça ou persegue** outra pessoa pela internet, **de propósito** e **várias vezes**. Uma discussão em que os dois discordam com respeito **não** é cyberbullying.
| Exemplo de cyberbullying | O que é |
| 😠 Apelidos que humilham, repetidos no grupo | Ofender de propósito, várias vezes |
| 🖼️ Montagem com a foto do colega para zombar | Usar a imagem para humilhar |
| 🚪 Tirar alguém do grupo de propósito, toda vez | Excluir para machucar |
| 🗣️ Espalhar boato ou mentira sobre o colega | Mentir para prejudicar |
| 🎭 Criar perfil falso para zombar de alguém | Fingir ser a pessoa |

**Quem está na história:**
| Papel | Quem é | O que pode fazer |
| 🎯 **Alvo** | Quem sofre | Não responder com ofensa, guardar **prints**, **bloquear**, **denunciar** e **contar para um adulto de confiança** |
| 👀 **Espectador** | Quem vê | **Não curtir nem repassar**, apoiar o colega e avisar um adulto |
| 😈 **Autor** | Quem pratica | **Parar**, apagar o que postou e pedir desculpas |

**É lei:** desde 2024, a **intimidação sistemática virtual** (cyberbullying) é **crime** no Brasil (Lei nº 14.811/2024). Quando quem pratica é adolescente, ele responde pelo Estatuto da Criança e do Adolescente (ECA).
### 📖 O que significa?
- **Cyberbullying**: humilhar, ameaçar ou perseguir alguém pela internet, de propósito e várias vezes.
- **Alvo**: a pessoa que sofre o cyberbullying.
- **Espectador**: quem vê o que está acontecendo.
- **Print** (captura de tela): foto da tela, que serve para guardar a prova do que aconteceu.
- **Bloquear**: impedir que uma pessoa fale com você.
- **Denunciar**: avisar a plataforma (o aplicativo ou a rede social) sobre o que está errado.
- **ECA**: Estatuto da Criança e do Adolescente, a lei que protege e orienta crianças e adolescentes.
### 🌎 Onde eu uso isso?
- No **grupo da turma**, quando alguém começa a zombar de um colega.
- Nas **redes sociais**, ao ver uma montagem que humilha alguém.
- Nos **jogos on-line**, quando alguém persegue um jogador.
### 🎯 Missão
🟢 **Básico** — no portal: decida o que é e o que não é cyberbullying, marque as atitudes que ajudam e ligue cada papel ao que ele pode fazer.

## 📶 Missão 7 – Extra: Wi-Fi público
**Objetivo:** saber os riscos das redes Wi-Fi abertas e como se proteger nelas.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Wi-Fi público** é a rede de lugares como praças, rodoviárias, lanchonetes e shoppings. Muitas são **abertas**: entram sem senha.
| Risco | Como acontece |
| 👀 Bisbilhoteiro na rede | Numa rede aberta, alguém na mesma rede pode tentar ver o que **não está cifrado** |
| 🎭 Rede falsa | Um golpista cria uma rede com nome parecido, como “Wi-Fi Gratis Praca”, para espiar quem entrar |
| 🔁 Conexão automática | O celular entra sozinho em redes conhecidas, até numa falsa com o mesmo nome |

**Como se proteger:**
| Atitude | Por quê |
| 🏦 Não entrar no banco nem digitar senhas importantes | Se algo der errado, não perde nada importante |
| 📱 Usar os **dados móveis** para o que é importante | A conexão do celular não é compartilhada com estranhos |
| ❓ **Perguntar** ao lugar o nome certo da rede | Evita a rede falsa |
| 🔒 Conferir o **https** e o cadeado | Os dados viajam cifrados |
| 🗑️ **Esquecer a rede** depois de usar | O celular não entra sozinho de novo |
### 📖 O que significa?
- **Wi-Fi público**: rede sem fio de um lugar aberto ao público.
- **Rede aberta**: rede que entra sem senha.
- **Dados móveis**: a internet da operadora do celular (3G, 4G, 5G).
- **Esquecer a rede**: apagar a rede da lista do celular para ele não entrar sozinho.
### 🌎 Onde eu uso isso?
- Na **rodoviária** ou na **lanchonete**, ao ver uma rede “grátis”.
- Em **viagens**, quando a internet do celular acaba.
- No **celular**, ao configurar o Wi-Fi.
### 🎯 Missão
🟢 **Básico** — no portal: marque o que protege, separe o que pode e o que é melhor evitar e responda sobre as redes abertas.
🟡 **Desafio** — no portal: na rodoviária: conectar ou não?
🔴 **Turbo** — no portal: jogo da memória do Wi-Fi.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Rede aberta é a rede que entra sem senha.
2. ( ) Um golpista pode criar uma rede falsa com nome parecido.
3. ( ) No Wi-Fi público, o melhor é entrar no banco e digitar todas as senhas.
4. ( ) Os dados móveis são mais seguros para o que é importante.
5. ( ) Esquecer a rede impede que o celular entre sozinho de novo.
### 🧠 Resumo da Aula
O **Wi-Fi público** costuma ser **aberto**. Riscos: o **bisbilhoteiro** na rede e a **rede falsa** com nome parecido. Proteção: não entrar no **banco** nem digitar senhas importantes, usar os **dados móveis**, perguntar o **nome certo** da rede, conferir o **https** e **esquecer a rede** depois.
**Palavras-chave:** Wi-Fi público · rede aberta · rede falsa · dados móveis · esquecer a rede

## 🗣️ Missão 8 – Extra: Debate respeitoso
**Objetivo:** discordar com respeito, usando argumentos, e não ataques.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Discordar é normal e até bom: é assim que as ideias melhoram. O importante é **criticar a ideia, não a pessoa**.
| ✅ Argumento (ataca a ideia) | ❌ Ataque pessoal (ataca a pessoa) |
| “Eu discordo, porque o jogo fica mais lento com tantos jogadores.” | “Você não sabe nada, seu burro.” |
| “Li numa notícia do jornal da cidade que a praça vai reabrir.” | “Ninguém liga para o que você fala.” |
| “Entendi o seu ponto, mas penso diferente.” | “Cala a boca, você sempre erra.” |

**Regras do debate:**
| Regra | Como fazer |
| 👂 Ouvir até o fim | Esperar o outro terminar antes de responder |
| ✋ Esperar a vez | Um fala de cada vez |
| 📚 Dar um motivo | Dizer **por que** pensa assim e, se puder, de onde veio a informação (a **fonte**) |
| 🤝 Aceitar discordar | No fim, cada um pode continuar com a sua opinião, e tudo bem |
### 📖 O que significa?
- **Debate**: conversa em que as pessoas defendem opiniões diferentes.
- **Argumento**: motivo que explica por que você pensa de um jeito.
- **Ataque pessoal**: ofender a pessoa em vez de responder à ideia dela.
- **Fonte**: de onde veio a informação (um livro, um jornal, um site confiável).
- **Opinião**: o que cada um pensa sobre um assunto.
### 🌎 Onde eu uso isso?
- Nos **comentários** de um vídeo polêmico.
- No **grupo da turma**, quando a turma não concorda sobre o passeio.
- Nas **eleições do grêmio** da escola.
### 🎯 Missão
🟢 **Básico** — no portal: separe argumentos e ataques pessoais, coloque as regras do debate em ordem e ligue cada palavra ao seu significado.
🟡 **Desafio** — no portal: escolha a melhor resposta para continuar o debate.
🔴 **Turbo** — no portal: caça-palavras do debate.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) No debate respeitoso, a gente critica a ideia, não a pessoa.
2. ( ) “Você não sabe nada” é um bom argumento.
3. ( ) Argumento é o motivo que explica a sua opinião.
4. ( ) No fim do debate, tudo bem cada um continuar com a sua opinião.
5. ( ) Fonte é de onde veio a informação.
### 🧠 Resumo da Aula
No **debate respeitoso**, você critica a **ideia**, não a **pessoa**. Use **argumentos**: discordar e dar um motivo, com **fontes**; evite o **ataque pessoal**. Regras: **ouvir até o fim**, **esperar a vez**, **dar um motivo** e **aceitar discordar**.
**Palavras-chave:** debate · argumento · ataque pessoal · fonte · opinião
