## 🧱 Missão 1 – Programar com blocos: sequência, repetição e seleção
**Objetivo:** montar programas com blocos usando sequência, repetição e seleção, e entender como o computador executa cada bloco.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
No 6º ano você escreveu **algoritmos**: passos em ordem para resolver um problema. Um **programa** é um algoritmo escrito numa linguagem que o computador entende. Aqui, a linguagem são **blocos** que se encaixam como peças de montar.
O computador lê os blocos **de cima para baixo**, um de cada vez, e faz **exatamente** o que eles mandam:
| Bloco | O que faz | Exemplo |
| 📺 mostrar na tela | Escreve uma mensagem na Tela do programa | mostrar na tela “Olá!” → aparece Olá! |
| 🔁 repita 3 vezes | Faz os blocos de dentro várias vezes | repita 3 vezes: mostrar “pulo” → pulo, pulo, pulo |
| 🔀 se … faça … senão | Escolhe um caminho conforme uma condição | se nota ≥ 5, mostrar “passou”; senão, mostrar “recuperação” |

São as mesmas três ideias dos algoritmos:
| Ideia | No bloco | Na vida |
| ➡️ Sequência | Um bloco embaixo do outro | Acordar, escovar os dentes, tomar café |
| 🔁 Repetição | Blocos dentro do **repita** | Fazer 10 polichinelos |
| 🔀 Seleção | Blocos dentro do **se** | Se chover, levar guarda-chuva; senão, levar boné |

**Atenção à ordem:** se o “mostrar ‘fim’” ficar **dentro** do repita, ele aparece 3 vezes; se ficar **embaixo** do repita (fora dele), aparece só 1 vez, no final. A posição do bloco muda o resultado!
Uma **variável** é uma caixinha com nome que guarda um valor: **definir nota para 7** guarda 7 na caixinha “nota”. Depois, o programa pode usar a nota numa conta ou numa condição.
### 📖 O que significa?
- **Programa**: algoritmo escrito numa linguagem que o computador entende. Onde eu vejo: todo aplicativo e todo jogo é um programa.
- **Programar**: criar programas, dizendo ao computador o que fazer, passo a passo.
- **Bloco**: peça do editor que representa uma instrução (um comando). Os blocos se encaixam para formar o programa.
- **Executar** (ou **rodar**): fazer o computador seguir os blocos do programa, de cima para baixo.
- **Sequência**: blocos um embaixo do outro, executados na ordem.
- **Repetição** (laço): bloco que faz os blocos de dentro várias vezes, como o **repita**.
- **Seleção** (condição): bloco que escolhe o caminho com **se … faça … senão**. A condição é uma pergunta de sim ou não, como “nota ≥ 5?”.
- **Variável**: caixinha com nome que guarda um valor (um número ou um texto) para o programa usar depois.
### 🌎 Onde eu uso isso?
- O **despertador** do celular é um programa com **seleção**: se for 6h, então toca.
- Nos **jogos**, a vida do personagem é uma **variável**: começa em 3 e diminui quando ele leva dano.
- A **máquina de lavar** segue uma **sequência** (molhar, bater, enxaguar, centrifugar) com **repetições**.

### 🎯 Missão
🟢 **Básico** — no editor de blocos: monte o seu primeiro programa, use o **repita** para encurtar e o **se** para decidir.
🟡 **Desafio** — no editor: um programa com variável e seleção que diz se o aluno passou.
🔴 **Turbo** — no editor: a contagem regressiva do foguete.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) O computador executa os blocos de cima para baixo.
2. ( ) O bloco repita serve para escolher um caminho conforme uma condição.
3. ( ) Se o bloco “mostrar ‘fim’” ficar dentro do repita 3 vezes, ele aparece 3 vezes.
4. ( ) Uma variável é uma caixinha com nome que guarda um valor.
5. ( ) Programa é um algoritmo escrito numa linguagem que o computador entende.
### 🧠 Resumo da Aula
Um **programa** é um algoritmo numa linguagem que o computador entende; aqui ela é feita de **blocos**. O computador **executa** os blocos de cima para baixo. **Sequência**: um bloco depois do outro. **Repetição**: o **repita** faz os blocos de dentro várias vezes. **Seleção**: o **se … faça … senão** escolhe o caminho pela condição. A posição do bloco (dentro ou fora) muda o resultado. **Variável** é uma caixinha com nome que guarda um valor.
**Palavras-chave:** programa · bloco · executar · sequência · repetição · seleção · condição · variável

## 📝 Missão 2 – Listas no programa
**Objetivo:** criar listas no programa, pegar um item pela posição, saber o tamanho da lista e percorrer todos os itens.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Imagine guardar o nome de 19 alunos em 19 variáveis diferentes: aluno1, aluno2, aluno3… Cansativo! Para isso existe a **lista**: **uma variável só** que guarda **vários itens em ordem**.
Cada item tem uma **posição**, contada a partir do **1**:
| Posição | 1 | 2 | 3 | 4 |
| Item da lista **frutas** | maçã | uva | caju | açaí |

Com a lista, o programa consegue:
| Bloco | O que faz | Com a lista frutas |
| 📝 criar lista com | Cria a lista com os itens | frutas = maçã, uva, caju, açaí |
| em lista … obter # | Pega o item de uma posição | item nº 3 → **caju** |
| tamanho de | Conta quantos itens a lista tem | tamanho de frutas → **4** |
| na lista … adicionar no fim | Coloca um item novo no final | adicionar “banana” → agora são 5 |
| 👉 para cada item … na lista | Repete os blocos de dentro **uma vez para cada item** | mostra maçã, uva, caju, açaí (um por linha) |

O **para cada** é uma repetição esperta: você não precisa saber quantos itens tem. Se a lista crescer, ele percorre os novos itens também.
**Cuidado:** pedir o item nº 5 de uma lista com 4 itens dá problema: a posição **não existe**.
### 📖 O que significa?
- **Lista**: variável que guarda vários itens em ordem, como a lista de chamada.
- **Item** (ou **elemento**): cada valor guardado na lista.
- **Posição** (ou **índice**): o número do lugar do item na lista. Aqui começa no 1.
- **Tamanho**: quantos itens a lista tem.
- **Percorrer**: passar por todos os itens da lista, um de cada vez, do primeiro ao último.
- **Para cada**: bloco de repetição que percorre a lista, fazendo os blocos de dentro uma vez para cada item.
- **Adicionar**: colocar um item novo na lista (aqui, no fim).
### 🌎 Onde eu uso isso?
- A **playlist** é uma lista de músicas: o aplicativo toca uma por vez, do começo ao fim (percorrer).
- O **carrinho da loja on-line** é uma lista: cada produto adicionado entra no fim, e o aplicativo mostra quantos itens tem (tamanho).
- O **histórico do navegador** é uma lista dos sites que você visitou, em ordem.

### 🎯 Missão
🟢 **Básico** — no editor: crie uma lista, mostre um item pela posição, mostre o tamanho e percorra a lista com o **para cada**.
🟡 **Desafio** — no editor: a lista de compras que cresce e a soma dos preços.
🔴 **Turbo** — no editor: mostre só os itens de uma lista que passam numa condição.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Uma lista guarda vários itens numa variável só.
2. ( ) Na lista maçã, uva, caju, o item da posição 2 é maçã.
3. ( ) O bloco tamanho de mostra quantos itens a lista tem.
4. ( ) O para cada repete os blocos uma vez para cada item da lista.
5. ( ) Numa lista de 4 itens, existe o item da posição 5.
### 🧠 Resumo da Aula
A **lista** guarda vários **itens** em ordem numa variável só. Cada item tem uma **posição** (aqui começa no 1). Com a lista, o programa pega um item pela posição, descobre o **tamanho** (quantos itens tem), **adiciona** itens no fim e **percorre** todos com o **para cada**, que repete os blocos uma vez para cada item. Posição que não existe dá erro.
**Palavras-chave:** lista · item · posição · tamanho · percorrer · para cada · adicionar

## 🗂️ Missão 3 – Registros: a ficha de cada coisa
**Objetivo:** organizar várias informações sobre uma mesma coisa num registro (ficha) com campos, e usar listas de fichas.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Uma lista guarda vários itens **do mesmo tipo** (vários nomes, várias notas). Mas e quando queremos guardar **várias informações diferentes sobre uma coisa só**, como nome, idade e turma de um aluno? Usamos um **registro**: uma **ficha** com **campos**.
| Ficha (registro) do aluno | |
| campo **nome** | Ana |
| campo **idade** | 12 |
| campo **turma** | 7º A |

Cada campo tem um **nome** (nome, idade, turma) e um **valor** (Ana, 12, 7º A). No editor:
| Bloco | O que faz |
| 🗂️ nova ficha | Cria uma ficha vazia (guarde numa variável, ex.: **aluno**) |
| na ficha … o campo … vale … | Escreve um valor num campo da ficha |
| campo … da ficha … | Lê o valor de um campo |

**Lista × registro:**
| | 📝 Lista | 🗂️ Registro (ficha) |
| Guarda | Vários itens parecidos | Várias informações de uma coisa só |
| Acha pela | Posição (1, 2, 3…) | Nome do campo (nome, idade…) |
| Exemplo | Nomes da turma | Os dados de um aluno |

E dá para juntar os dois: uma **lista de fichas** é exatamente uma **tabela**! Cada ficha é uma **linha** e cada campo é uma **coluna**.
### 📖 O que significa?
- **Registro**: conjunto de informações diferentes sobre uma mesma coisa, guardado junto. Aqui chamamos de **ficha**.
- **Campo**: cada informação da ficha, com um nome (ex.: idade) e um valor (ex.: 12).
- **Valor**: o que está guardado no campo (um texto, um número…).
- **Cadastro**: conjunto de fichas, como o cadastro dos alunos da escola.
- **Tabela**: uma lista de fichas: cada ficha é uma linha e cada campo é uma coluna.
### 🌎 Onde eu uso isso?
- O **contato do celular** é uma ficha: campos nome, telefone, foto, aniversário.
- No **jogo**, cada personagem tem uma ficha: nome, vida, força, velocidade.
- Na **secretaria da escola**, cada aluno tem uma ficha de matrícula; o conjunto delas é o cadastro.

🟢 **Básico** — no portal: separe o que é lista e o que é registro, ache campos e valores; no editor, monte a ficha de um aluno e mostre os campos.
🟡 **Desafio** — no editor: a ficha do personagem que perde vida.
🔴 **Turbo** — no editor: uma lista de fichas percorrida com o **para cada**.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Um registro guarda várias informações diferentes sobre uma mesma coisa.
2. ( ) Num registro, achamos a informação pela posição 1, 2, 3.
3. ( ) No campo idade = 12, “idade” é o nome do campo e 12 é o valor.
4. ( ) Uma lista de fichas funciona como uma tabela.
5. ( ) O contato do celular é um exemplo de registro.
### 🧠 Resumo da Aula
Um **registro** (ficha) guarda várias informações diferentes sobre uma mesma coisa. Cada informação é um **campo**, com **nome** (idade) e **valor** (12). Na lista achamos pela **posição**; no registro, pelo **nome do campo**. Uma **lista de fichas** é uma **tabela**: cada ficha é uma linha e cada campo, uma coluna. Exemplos: contato do celular, personagem de jogo, ficha de matrícula.
**Palavras-chave:** registro · ficha · campo · valor · cadastro · tabela

## 🐞 Missão 4 – Depurar: achar e consertar erros
**Objetivo:** encontrar e corrigir erros em programas, testando, comparando o resultado com o esperado e mudando uma coisa de cada vez.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Todo programador erra, até os profissionais! Um erro no programa se chama **bug** (inseto, em inglês). Achar e consertar o erro é **depurar** (em inglês, *debug*).
Os erros mais comuns em blocos:
| Erro | O que acontece | Exemplo |
| 🔃 Ordem trocada | Os passos saem fora de ordem | mostrar “fim” antes do repita |
| 📦 Bloco no lugar errado | Dentro em vez de fora (ou o contrário) | “fim” dentro do repita aparece 3 vezes |
| 🔢 Número errado | Repete demais ou de menos | repita 4 em vez de 3 |
| ⚖️ Condição trocada | Escolhe o caminho errado | se nota < 5, mostrar “passou” |
| ✏️ Valor errado | Texto ou conta errada | mostrar “Óla” em vez de “Olá” |
| ♾️ Repetição sem fim | O programa não para | enquanto verdadeiro, sem nunca mudar |

**O método do detetive 🕵️ (4 passos):**
| Passo | O que fazer |
| 1. Rodar | Aperte ▶️ e veja o que aparece |
| 2. Comparar | Compare com o que **devia** aparecer: em que **linha** começou a diferença? |
| 3. Achar | Procure o bloco responsável por aquela linha |
| 4. Mudar uma coisa só e testar de novo | Se mudar tudo de uma vez, você não sabe o que resolveu |

O portal ajuda no passo 2: ele diz **qual linha** saiu diferente.
### 📖 O que significa?
- **Bug**: em inglês, “inseto”: um erro no programa. O nome ficou famoso em 1947, quando uma mariposa presa num computador causou uma falha.
- **Depurar**: achar e consertar os erros de um programa. Em inglês, *debug* (tirar o inseto).
- **Testar**: rodar o programa para ver se ele faz o que devia.
- **Resultado esperado**: o que o programa **devia** mostrar.
- **Resultado obtido**: o que o programa **mostrou de verdade**.
- **Repetição sem fim** (laço infinito): repetição que nunca termina, porque a condição de parar nunca acontece.
### 🌎 Onde eu uso isso?
- Quando um **aplicativo atualiza** “com correções de erros”, foi alguém depurando o programa.
- Quando a **receita** dá errado, você depura: o que eu fiz diferente? Muito sal? Pouco tempo no forno?
- Em **jogos**, os testadores jogam muitas vezes procurando bugs antes de lançar.

🟡 **Desafio** — no editor: um programa com dois erros.

### 🧠 Resumo da Aula
Erro no programa é **bug**; achar e consertar é **depurar**. Erros comuns: ordem trocada, bloco dentro ou fora do lugar, número errado, condição trocada, valor errado e repetição sem fim. Método do detetive: **rodar**, **comparar** o resultado obtido com o **esperado** (em que linha começou a diferença?), **achar** o bloco responsável e **mudar uma coisa só** antes de testar de novo.
**Palavras-chave:** bug · depurar · testar · resultado esperado · resultado obtido · repetição sem fim

## 🧩 Missão 5 – Decompor e reaproveitar
**Objetivo:** dividir um problema grande em partes menores e criar blocos próprios para reaproveitar uma parte do programa várias vezes.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Problema grande assusta. O segredo é **decompor**: dividir em partes menores, que dá para resolver uma de cada vez.
**Exemplo: organizar a festa da turma**
| Parte | Quem resolve |
| 🎈 Decoração | Grupo 1 |
| 🍰 Comida | Grupo 2 |
| 🎵 Música | Grupo 3 |
| 🎮 Brincadeiras | Grupo 4 |

No programa é igual. E quando uma parte **se repete** em vários lugares, criamos um **bloco nosso** com nome: ele **é escrito uma vez só e chamado quando precisar**. Isso é **reaproveitar**.
**Exemplo: a música com refrão**
| Sem bloco próprio | Com o bloco **refrão** |
| verso 1 · la la la · la la la · verso 2 · la la la · la la la | criar o bloco **refrão** (la la la · la la la) uma vez só; programa: verso 1 · **refrão** · verso 2 · **refrão** |

Vantagens de criar o seu bloco (na gaveta 🧩 **Meus blocos**, com “para fazer algo” e dando um nome):
| Vantagem | Por quê |
| ✂️ Programa mais curto | A parte repetida é escrita uma vez só |
| 🛠️ Conserta num lugar só | Mudou o refrão? Muda no bloco e vale em todos os lugares |
| 👀 Mais fácil de ler | O nome do bloco diz o que ele faz |
| 👥 Dá para dividir o trabalho | Cada colega cria um bloco |

### 📖 O que significa?
- **Decompor**: dividir um problema grande em partes menores, mais fáceis de resolver.
- **Reaproveitar** (reutilizar): usar de novo uma parte que já está pronta, em vez de fazer tudo outra vez.
- **Bloco próprio** (função ou procedimento): conjunto de blocos que você junta, dá um nome e chama quando precisar. Fica na gaveta 🧩 Meus blocos.
- **Chamar**: usar o bloco próprio no programa. Cada vez que ele é chamado, os blocos de dentro são executados.
- **Colaborar**: trabalhar junto, cada um fazendo uma parte do mesmo projeto.
### 🌎 Onde eu uso isso?
- Num **trabalho em grupo**, cada um faz uma parte (introdução, pesquisa, cartaz): decomposição.
- Na **fábrica de carros**, cada setor monta uma parte (motor, porta, pintura).
- O botão **“compartilhar”** é um bloco pronto que todo aplicativo reaproveita.
| ✍️ Pense e escreva: decomponha uma tarefa de casa (arrumar o quarto, fazer o almoço) em pelo menos 3 partes. |

### 🎯 Missão
🟢 **Básico** — no portal: decomponha problemas em partes; no editor, crie o bloco **refrão** e chame-o duas vezes.
🟡 **Desafio** — no editor: um bloco próprio usado dentro de uma repetição.
🔴 **Turbo** — no editor: conserte o refrão num lugar só e veja mudar em todos.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Decompor é dividir um problema grande em partes menores.
2. ( ) Um bloco próprio precisa ser escrito de novo cada vez que é usado.
3. ( ) Se eu mudar o bloco próprio, a mudança vale em todos os lugares onde ele é chamado.
4. ( ) Chamar o bloco é usar o bloco no programa.
5. ( ) Num trabalho em grupo, dividir as partes entre os colegas é um exemplo de decomposição.
### 🧠 Resumo da Aula
**Decompor** é dividir um problema grande em partes menores. Quando uma parte se repete, criamos um **bloco próprio** (função) com nome, na gaveta 🧩 Meus blocos, e o **chamamos** sempre que precisar: isso é **reaproveitar**. Vantagens: programa mais curto, conserto num lugar só, leitura mais fácil e trabalho dividido entre colegas (**colaborar**).
**Palavras-chave:** decompor · reaproveitar · bloco próprio · função · chamar · colaborar

## 👥 Missão 6 – Programar em dupla
**Objetivo:** programar em dupla com os papéis de piloto e navegador, combinar o plano antes de montar e criar juntos um programa completo.

### 💡 Para começar
Programadores de verdade trabalham muito em **dupla**. Um computador, duas cabeças, dois **papéis** que se revezam:
| Papel | O que faz | O que NÃO faz |

| 🧭 Navegador | Lê o enunciado, pensa no próximo passo, confere cada bloco e procura erros | Não pega o mouse |

- **Plano**: a lista das partes do programa, combinada antes de começar a montar.
### 🌎 Onde eu uso isso?
- No **carro**, o motorista dirige e quem está ao lado olha o mapa: piloto e navegador.
- Num **jogo cooperativo**, um ataca e o outro cuida da vida do time.
- Nas **empresas de tecnologia**, programar em dupla é usado para errar menos e ensinar os novatos.

Hoje é dia de detetive 🕵️! Os programas chegam **quebrados** e a sua missão é consertar. Use o mesmo método da Missão 4:
| Passo | O que fazer |

## ❓ Missão 8 – Extra: O placar do quiz
**Objetivo:** usar listas, repetição, seleção e uma variável contadora para corrigir as respostas de um quiz e mostrar o placar.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Todo jogo de perguntas (quiz) precisa de um programa que **confere as respostas** e **conta os pontos**. Vamos montar esse programa!
O programa usa **duas listas** do mesmo tamanho, comparando posição por posição:
| Posição | 1 | 2 | 3 | 4 |
| Lista **gabarito** (respostas certas) | B | A | D | C |
| Lista **respostas** (do jogador) | B | C | D | C |
| Acertou? | ✅ | ❌ | ✅ | ✅ |

Para contar os acertos usamos uma **variável contadora**, que começa em **0** e **aumenta 1** a cada acerto:
| Passo | Bloco |
| 1 | definir **acertos** para 0 |
| 2 | definir **i** para 1 (a posição que estamos conferindo) |
| 3 | repita 4 vezes: **se** item **i** do gabarito = item **i** das respostas, **então** alterar **acertos** por 1; depois alterar **i** por 1 |
| 4 | mostrar na tela acertos → **3** |

O bloco **alterar … por 1** (gaveta 📦 Variáveis) soma 1 ao valor da variável.
### 📖 O que significa?
- **Quiz**: jogo de perguntas e respostas.
- **Gabarito**: a lista das respostas certas.
- **Contador**: variável que começa em 0 e aumenta de 1 em 1 para contar alguma coisa (acertos, vidas, moedas).
- **Alterar … por 1**: bloco que soma 1 ao valor de uma variável.
- **Comparar**: verificar se dois valores são iguais (=) ou diferentes, ou qual é maior.
### 🌎 Onde eu uso isso?
- O **placar do Wayground** e de jogos on-line confere cada resposta e conta os pontos assim.
- Na **prova do portal**, o programa compara as suas respostas com o gabarito.
- O **contador de passos** do celular soma 1 a cada passo.

🟢 **Básico** — no portal: confira um quiz à mão e ache o contador; no editor, monte o contador de acertos.
🟡 **Desafio** — no editor: o placar com mensagem final (se acertou tudo, “Parabéns!”).
🔴 **Turbo** — no editor: conte também os erros.
### ✅ Perguntas rápidas

Para corrigir um **quiz**, o programa compara a lista **gabarito** com a lista **respostas**, posição por posição. Uma variável **contadora** começa em 0 e o bloco **alterar … por 1** soma 1 a cada acerto. No fim, o programa mostra o placar. Contadores estão em placares, provas e contadores de passos.
