## 🧱 Missão 1 – Meu primeiro programa
**Objetivo:** montar um programa com blocos.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
| Passo | O que fazer |
| 1 | Abrir a **gaveta** 📺 Mostrar |
| 2 | **Arrastar** o bloco para a área branca |
| 3 | **Encaixar** um bloco embaixo do outro |
| 4 | Apertar **▶️ Rodar o programa** |

O computador lê os blocos **de cima para baixo**.
### 📖 O que significa?
- **Programa**: instruções que o computador segue.
- **Bloco**: peça do programa.
- **Gaveta**: onde ficam os blocos.
### 🌎 Onde eu uso isso?
- Nos **jogos**.
- Nos **aplicativos** do celular.
### ✅ Perguntas rápidas
1. ( ) O computador lê os blocos de cima para baixo.
2. ( ) Para ver o resultado, aperto ▶️ Rodar.
3. ( ) A ordem dos blocos não importa.
### 🧠 Resumo da Aula
Arraste os **blocos**, **encaixe** e aperte **▶️ Rodar**. O computador lê **de cima para baixo**.
**Palavras-chave:** programa · bloco · gaveta

## 🔁 Missão 2 – Repetição e seleção em blocos
**Objetivo:** usar o repita e o se.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
| Bloco | O que faz | Exemplo |
| 🔁 repita 3 vezes | Faz os blocos de dentro várias vezes | pula, pula, pula |
| 🔀 se … senão | Escolhe um caminho | Se chover: guarda-chuva; senão: boné |
### 📖 O que significa?
- **Repita**: faz várias vezes.
- **Repetição**: fazer a mesma coisa várias vezes.
- **Se**: escolhe um caminho.
- **Condição**: pergunta de sim ou não.
### 🌎 Onde eu uso isso?
- **10 polichinelos**: repetição.
- **Se chover, guarda-chuva**: seleção.
### ✅ Perguntas rápidas
1. ( ) O repita faz os blocos várias vezes.
2. ( ) O se escolhe um caminho.
3. ( ) O repita escolhe um caminho.
### 🧠 Resumo da Aula
O **repita** repete. O **se** escolhe o caminho pela **condição**.
**Palavras-chave:** repita · se · condição

## 📦 Missão 3 – Variáveis: as caixinhas do programa
**Objetivo:** guardar um valor numa variável.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Variável** é uma **caixinha com nome** que guarda um valor.
| Bloco | Valor de pontos depois do bloco |
| definir pontos para 0 | 0 |
| alterar pontos por 5 | 5 |
| alterar pontos por 3 | 8 |
### 📖 O que significa?
- **Variável**: caixinha com nome.
- **Valor**: o que está guardado.
- **Alterar por**: somar ao valor.
### 🌎 Onde eu uso isso?
- O **placar** do jogo.
- As **vidas** do personagem.
### ✅ Perguntas rápidas
1. ( ) Variável é uma caixinha com nome.
2. ( ) Alterar pontos por 5 soma 5 aos pontos.
3. ( ) Variável não guarda nada.
### 🧠 Resumo da Aula
A **variável** guarda um **valor**. **Definir** coloca; **alterar por** soma.
**Palavras-chave:** variável · valor · alterar por

## 🧩 Missão 4 – Um bloco para muitos casos
**Objetivo:** chamar um bloco que já existe.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Você pode **criar um bloco** e **chamar** ele quando quiser: para o bloco funcionar, eu **chamo** o bloco.
| Blocos do programa | Tela |
| definir nome para “Ana” · saudar | Olá, Ana |
| definir nome para “Leo” · saudar | Olá, Leo |

O **nome** é o **parâmetro**: o valor que muda.
### 📖 O que significa?
- **Chamar**: mandar o bloco fazer o que tem dentro.
- **Parâmetro**: o valor que muda.
### 🌎 Onde eu uso isso?
- O botão **curtir** é o mesmo em todos os posts.
- A **receita de suco**: a fruta muda.
### ✅ Perguntas rápidas
1. ( ) Chamar o bloco faz ele funcionar.
2. ( ) O nome é o parâmetro.
3. ( ) Para cada nome, preciso de um bloco novo.
### 🧠 Resumo da Aula
Crie o bloco uma vez e **chame** muitas vezes. O **parâmetro** é o que muda.
**Palavras-chave:** chamar · parâmetro

## 📝 Missão 5 – Listas e tipos de dados
**Objetivo:** pegar um item da lista.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
| Tipo | Exemplos | Dá para… |
| 🔢 Número | 7, 15 | Fazer contas |
| 🔤 Texto | “Ana” | Mostrar |
| 📝 Lista | [maçã, uva, caju] | Guardar vários valores |

Na lista **frutas** = [maçã, uva, caju]: o **item 1** é maçã, o **item 2** é uva e o **item 3** é caju.
### 📖 O que significa?
- **Lista**: vários valores em ordem.
- **Item**: cada valor da lista.
- **Posição**: o número do lugar (1, 2, 3).
### 🌎 Onde eu uso isso?
- A **lista de compras**.
- A **chamada** da turma.
### ✅ Perguntas rápidas
1. ( ) A lista guarda vários valores.
2. ( ) O item 1 da lista frutas é maçã.
3. ( ) “Ana” é um número.
### 🧠 Resumo da Aula
A **lista** guarda vários valores em ordem. Cada **item** tem uma **posição**.
**Palavras-chave:** lista · item · posição

## 🎮 Missão 6 – Projeto: meu joguinho
**Objetivo:** fazer o botão verde dar pontos.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
| Regra | Evento | Ação |
| 1 | Começo | pontos = 0 |
| 2 | 🟢 botão verde | mais 1 ponto |

**Evento** é algo que acontece, como apertar um botão. O bloco **⚡ quando** diz o que fazer.
### 📖 O que significa?
- **Evento**: algo que acontece.
- **Ação**: o que o programa faz.
### 🌎 Onde eu uso isso?
- Nos **jogos**: apertar o botão faz pular.
- No **controle remoto**.
### ✅ Perguntas rápidas
1. ( ) Apertar um botão é um evento.
2. ( ) O botão verde dá mais 1 ponto.
3. ( ) Evento é um erro do programa.
### 🧠 Resumo da Aula
O **evento** (botão) faz a **ação** acontecer. Verde = mais 1 ponto.
**Palavras-chave:** evento · ação

## 🧠 Missão 7 – Extra: Desafios de lógica
**Objetivo:** achar o erro do programa.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Bug** é um erro no programa. **Depurar** é achar e consertar.
| Bloco | x |
| definir x para 2 | 2 |
| alterar x por 2 | 4 |
| mostrar x | aparece **4** |
### 📖 O que significa?
- **Bug**: erro no programa.
- **Depurar**: achar e consertar o erro.
### 🌎 Onde eu uso isso?
- Quando o **jogo trava**.
- Ao conferir uma **conta**.
### ✅ Perguntas rápidas
1. ( ) Bug é um erro.
2. ( ) Depurar é consertar o erro.
3. ( ) Definir x para 2 e alterar x por 2 deixa x com 2.
### 🧠 Resumo da Aula
**Bug** é erro; **depurar** é consertar. Siga os blocos anotando os valores.
**Palavras-chave:** bug · depurar

### ✅ Perguntas rápidas

2. ( ) O repita pode fazer o toc, toc, toc.
3. ( ) História não tem começo.
### 🧠 Resumo da Aula
Cada linha é uma **cena**. O **repita** faz o que se repete.
**Palavras-chave:** cena · personagem
