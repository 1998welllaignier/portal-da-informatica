## 📇 Missão 1 – Dados pessoais
**Objetivo:** saber quais informações são dados pessoais.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Dado pessoal** é uma informação que diz **quem você é**.
| Dado pessoal | Exemplo |
| 🧑 Nome completo | Ana Souza Lima |
| 🏠 Endereço | Rua das Flores, 10 |
| 📍 Localização | Onde você está agora |

Antes de dar um dado, pergunte: **quem está pedindo? Para quê?** Não dou o meu telefone para qualquer pessoa.
### 📖 O que significa?
- **Dado pessoal**: informação que diz quem você é.
- **Privacidade**: decidir o que os outros sabem de você.
### 🌎 Onde eu uso isso?
- Num **cadastro**.
- Quando um **desconhecido** pede o seu telefone.
### ✅ Perguntas rápidas
1. ( ) O endereço é um dado pessoal.
2. ( ) A localização é um dado pessoal.
3. ( ) Dou o meu telefone para qualquer pessoa.
### 🧠 Resumo da Aula
**Dado pessoal** diz quem você é: nome, endereço, localização. Antes de dar: **quem pede? Para quê?**
**Palavras-chave:** dado pessoal · privacidade

## 🔐 Missão 2 – Dados sensíveis e LGPD
**Objetivo:** conhecer os dados mais delicados e a lei que protege os dados.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Alguns dados são ainda mais delicados: os **dados sensíveis**.
| Dado sensível (exemplos da lei) | Exemplo |
| 🏥 Saúde | Uma doença |
| 🙏 Religião | A religião da pessoa |
| 👆 Biometria | A digital |

A **LGPD** é a lei que protege os seus dados. Ela diz que você pode pedir para **apagar** os seus dados.
### 📖 O que significa?
- **Dado sensível**: dado mais delicado, como a saúde.
- **Biometria**: partes do corpo que identificam, como a digital.
- **LGPD**: a lei que protege os dados.
### 🌎 Onde eu uso isso?
- Ao **desbloquear o celular** com a digital.
- Numa **ficha médica**.
### ✅ Perguntas rápidas
1. ( ) Dado de saúde é um dado sensível.
2. ( ) A digital é biometria.
3. ( ) A LGPD não protege os dados.
### 🧠 Resumo da Aula
**Dados sensíveis**: saúde, religião, **biometria**. A **LGPD** protege os dados e deixa você pedir para **apagar**.
**Palavras-chave:** dado sensível · biometria · LGPD

## 🛡️ Missão 3 – Segurança das contas
**Objetivo:** proteger as contas.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
| Hábito | Por quê |
| 🔑 Senha diferente em cada conta | Se uma vazar, as outras ficam seguras |
| 📲 Verificação em duas etapas | Sem o código, ninguém entra |
| 🚪 Sair da conta na escola | O próximo não entra na sua conta |

**Nunca** passe a senha ou o código, nem para o amigo. Pediram o código? Não passo.
### 📖 O que significa?
- **Conta**: o seu cadastro num jogo, e-mail ou rede social.
- **Código**: o número que chega no celular para entrar na conta.
### 🌎 Onde eu uso isso?
- No **computador da escola**.
- Na conta de um **jogo**.
### ✅ Perguntas rápidas
1. ( ) No computador da escola, eu saio da conta.
2. ( ) Duas etapas protegem a conta.
3. ( ) Passo o código para o meu amigo.
### 🧠 Resumo da Aula
**Senha diferente**, **duas etapas** e **sair da conta**. Nunca passe a senha nem o **código**.
**Palavras-chave:** conta · código

## ⚙️ Missão 4 – Configurar a privacidade
**Objetivo:** escolher quem vê os seus posts.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Em **Configurações**, você escolhe quem vê o quê.
| Configuração | Opção mais protegida |
| 👤 Conta | **Privada** |
| 📍 Localização nos posts | **Desligada** |
| 💬 Quem pode mandar mensagem | **Só amigos** |

**Bloquear**: a pessoa não fala mais com você. Desconhecido chato? Eu bloqueio.
### 📖 O que significa?
- **Conta privada**: só quem você aceita vê.
- **Bloquear**: a pessoa não consegue mais falar com você.
### 🌎 Onde eu uso isso?
- Numa **conta nova**.
- Quando um **desconhecido** manda mensagem.
### ✅ Perguntas rápidas
1. ( ) Conta privada: só quem eu aceito vê.
2. ( ) Localização desligada protege mais.
3. ( ) Bloquear deixa a pessoa mandar mais mensagens.
### 🧠 Resumo da Aula
Em **Configurações**: conta **privada**, localização **desligada**, mensagens **só de amigos**. Desconhecido chato? **Bloquear**.
**Palavras-chave:** conta privada · bloquear

## 🎣 Missão 8 – Extra: Golpes com dados vazados
**Objetivo:** não cair em golpe de quem “sabe tudo” sobre você.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Vazamento**: dados de muitas pessoas caem nas mãos de criminosos.
| Golpe | Como é |
| 📞 Falsa central | “Sou do banco, confirme o código” |
| 📦 Falsa entrega | “Pague a taxa neste link” |

**Regra de ouro:** saber o seu nome **não prova** que a pessoa é de confiança. Empresa séria **não pede** senha nem código.
### 📖 O que significa?
- **Vazamento**: dados que escapam e caem com criminosos.
- **Golpe**: engano para tirar vantagem.
- **Link**: endereço que abre uma página da internet.
### 🌎 Onde eu uso isso?
- Numa **ligação** estranha.
- Num **SMS de entrega** que você não esperava.
### ✅ Perguntas rápidas
1. ( ) Empresa séria não pede o código.
2. ( ) Se sabe o meu nome, é de confiança.
3. ( ) Depois de um vazamento, troco a senha.
### 🧠 Resumo da Aula
**Vazamento** ajuda o golpista a parecer confiável. **Falsa central** e **falsa entrega** são golpes. Empresa séria não pede senha nem código.
**Palavras-chave:** vazamento · golpe
