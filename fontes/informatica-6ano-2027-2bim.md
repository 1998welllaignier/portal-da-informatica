## 🧭 Missão 1 – Algoritmos do dia a dia
**Objetivo:** entender o que é um algoritmo e reconhecer algoritmos na rotina, escritos de um jeito claro e preciso.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Um **algoritmo** é uma lista de **passos**, em ordem, para resolver um problema ou fazer uma tarefa. Você usa algoritmos o tempo todo, mesmo sem perceber: para escovar os dentes, para fazer um suco, para chegar à escola.
**O computador não adivinha nada.** Ele faz exatamente o que mandamos, do jeito que mandamos. Por isso, cada passo precisa ser **claro** (não deixa dúvida) e **preciso** (diz exatamente o que fazer). Cada passo de um algoritmo se chama **instrução**.
| Algoritmo ruim (vago) | Algoritmo bom (claro e preciso) |
| “Faz o suco aí.” | 1. Pegar um copo. 2. Colocar 2 colheres de suco em pó. 3. Encher o copo com água. 4. Mexer com a colher. |
| “Vai até a cozinha.” | 1. Levantar da cadeira. 2. Andar até a porta. 3. Virar à direita. 4. Andar até a pia. |

Todo algoritmo tem **começo**, **meio** e **fim**: começa num ponto, segue os passos e termina quando o problema está resolvido. Se o algoritmo for bem feito, **qualquer pessoa** que seguir os passos chega ao **mesmo resultado**.
**Pessoas e computadores:** uma pessoa entende “faz o suco aí” porque já sabe fazer. O computador não sabe. Um **programa** de computador é um algoritmo escrito numa linguagem que o computador entende.
### 📖 O que significa?
- **Algoritmo**: sequência de passos, em ordem, para resolver um problema. A palavra vem do nome do matemático persa al-Khwarizmi, que viveu há mais de mil anos. Onde eu vejo: em receitas, manuais de montagem e nos aplicativos do celular.
- **Instrução**: cada passo de um algoritmo, uma ordem clara do que fazer. Exemplo: “Encher o copo com água”.
- **Passo**: uma das partes de um algoritmo; os passos são seguidos um depois do outro.
- **Preciso**: que diz exatamente o que fazer, sem deixar dúvida. “2 colheres” é preciso; “um pouco” não é.
- **Programa**: algoritmo escrito numa linguagem que o computador entende. Para que serve: é ele que faz o aplicativo, o jogo ou o site funcionar.
- **Resultado**: o que se consegue no fim do algoritmo, quando o problema está resolvido. Exemplo: o copo de suco pronto.
### 🌎 Onde eu uso isso?
- A **receita de bolo** da sua família é um algoritmo: ingredientes, passos em ordem e o bolo no fim.
- O **manual de montagem** de um brinquedo ou de um móvel mostra os passos numerados, com desenhos.
- O **GPS** do celular dá instruções passo a passo: “siga em frente”, “vire à direita”.
- O **jogo** que você joga no celular funciona porque alguém escreveu milhares de instruções para ele.
### 🎯 Missão
🟢 **Básico** — no portal: monte o algoritmo do copo de suco, separe as instruções claras das vagas, jogue a memória das palavras novas e responda às perguntas.
🟡 **Desafio** — no portal: coloque em ordem o algoritmo de fazer um sanduíche.
🔴 **Turbo** — no portal: ache as palavras do algoritmo no caça-palavras.
⚠️ Os computadores são usados por todos: **nunca apague nem mexa nos arquivos dos colegas**.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Algoritmo é uma sequência de passos, em ordem, para resolver um problema.
2. ( ) O computador adivinha o que queremos, mesmo se a instrução for vaga.
3. ( ) “Coloque um pouco de açúcar” é uma instrução precisa.
4. ( ) Uma receita de bolo é um exemplo de algoritmo.
5. ( ) Um programa de computador é um algoritmo escrito numa linguagem que o computador entende.
### 🧠 Resumo da Aula
Um **algoritmo** é uma sequência de **passos**, em ordem, para resolver um problema. Cada passo é uma **instrução** e precisa ser **clara** e **precisa**, porque o computador não adivinha nada. Todo algoritmo tem começo, meio e fim, e chega a um **resultado**. Um **programa** é um algoritmo escrito numa linguagem que o computador entende.
**Palavras-chave:** algoritmo · instrução · passo · preciso · programa · resultado

## ➡️ Missão 2 – Sequência: a ordem importa
**Objetivo:** montar algoritmos em sequência e perceber que trocar a ordem dos passos muda o resultado.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Na **sequência**, as instruções são feitas **uma depois da outra**, de cima para baixo, na ordem em que estão escritas. O computador nunca pula um passo e nunca muda a ordem sozinho.
**A ordem importa!** Veja o que acontece quando trocamos dois passos:
| Ordem certa | Ordem trocada | O que dá errado |
| 1. Calçar a meia. 2. Calçar o tênis. | 1. Calçar o tênis. 2. Calçar a meia. | A meia fica por cima do tênis! |
| 1. Abrir a porta. 2. Entrar na sala. | 1. Entrar na sala. 2. Abrir a porta. | Você bate na porta fechada. |
| 1. Colocar o creme dental. 2. Escovar os dentes. | 1. Escovar os dentes. 2. Colocar o creme dental. | Escova sem creme! |

**O robô do labirinto** também segue uma sequência. Cada seta é uma instrução que anda **uma casa**: ➡️ direita, ⬅️ esquerda, ⬆️ cima, ⬇️ baixo. Se uma seta estiver no lugar errado, o robô bate na parede 🧱 ou para longe da estrela ⭐.
| Comando | O que o robô faz |
| ➡️ | Anda uma casa para a direita |
| ⬅️ | Anda uma casa para a esquerda |
| ⬆️ | Anda uma casa para cima |
| ⬇️ | Anda uma casa para baixo |

**Dica para montar a sequência:** pergunte sempre “o que tem que acontecer **primeiro**?”. Depois, “e agora, o que vem **logo depois**?”.
### 📖 O que significa?
- **Sequência**: instruções feitas uma depois da outra, na ordem em que estão escritas. Onde eu vejo: nos passos numerados de uma receita.
- **Ordem**: a posição de cada passo (1º, 2º, 3º…). Trocar a ordem pode mudar o resultado.
- **Comando**: uma ordem dada ao computador ou ao robô, como ➡️ (andar uma casa para a direita).
- **Executar**: fazer o que o algoritmo manda, passo a passo. No portal, o botão ▶ Executar faz o robô seguir as setas.
- **Labirinto**: tabuleiro com caminhos e paredes; o robô precisa achar o caminho até a estrela sem bater nas paredes.
### 🌎 Onde eu uso isso?
- Para **mandar uma mensagem**: desbloquear o celular, abrir o aplicativo, escolher a pessoa, digitar e só depois enviar.
- No **micro-ondas**: colocar a comida, fechar a porta, escolher o tempo e só então apertar Iniciar.
- Na **senha do celular**: os números certos na ordem errada não abrem o aparelho.
### 🎯 Missão
🟢 **Básico** — no portal: leve o robô até a estrela com setas, coloque em ordem o algoritmo de atravessar a rua e descubra o que acontece quando a ordem é trocada.
🟡 **Desafio** — no portal: um labirinto maior, sem bater em nenhuma parede.
🔴 **Turbo** — no portal: complete o texto sobre sequência.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Na sequência, as instruções são feitas uma depois da outra.
2. ( ) Trocar a ordem dos passos nunca muda o resultado.
3. ( ) Cada seta do robô anda uma casa.
4. ( ) O computador pode pular um passo do algoritmo quando quiser.
5. ( ) Para montar uma sequência, pergunto: “o que tem que acontecer primeiro?”.
### 🧠 Resumo da Aula
Na **sequência**, o computador faz as instruções uma depois da outra, na **ordem** em que estão escritas, sem pular nenhuma. **Trocar a ordem muda o resultado**: calçar o tênis antes da meia não dá certo. No labirinto, cada **comando** (seta) anda uma casa, e o botão ▶ **Executar** faz o robô seguir o algoritmo.
**Palavras-chave:** sequência · ordem · comando · executar · labirinto

## 🔁 Missão 3 – Repetição: o comando repita
**Objetivo:** usar o comando “repita” para deixar o algoritmo mais curto quando um passo se repete.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Imagine dar esta ordem ao robô: ➡️ ➡️ ➡️ ➡️ ➡️ ➡️. São 6 setas iguais! Em vez de escrever tudo, podemos dizer: **repita 6 vezes ➡️**. Isso é uma **repetição** (em programação também se diz **laço**).
| Sem repetição | Com repetição |
| ➡️ ➡️ ➡️ ➡️ ⬇️ ⬇️ (6 comandos) | repita 4× ➡️ · repita 2× ⬇️ (2 comandos) |
| Bater palma, bater palma, bater palma | Repita 3 vezes: bater palma |
| Pular, pular, pular, pular, pular | Repita 5 vezes: pular |

A repetição deixa o algoritmo **mais curto**, **mais fácil de ler** e **mais fácil de corrigir**: se precisar mudar de 4 para 5 passos, você muda só um número.
**Toda repetição precisa saber quando parar.** “Repita 3 vezes” para depois da 3ª vez. Uma repetição que nunca para trava o programa: é o **laço infinito**, um erro comum de programação.
Também dá para repetir **um grupo** de passos: “Repita 4 vezes: ande 1 casa, vire à direita” desenha um quadrado.
### 📖 O que significa?
- **Repetição**: fazer o mesmo passo (ou o mesmo grupo de passos) várias vezes. Também se chama **laço**.
- **Repita**: o comando que diz quantas vezes um passo deve ser feito. Exemplo: “repita 3 vezes ➡️”.
- **Laço**: outro nome da repetição; em inglês, *loop* (“volta”, como numa corda que dá a volta).
- **Laço infinito**: repetição que nunca termina, porque não tem quando parar. Ela trava o programa.
- **Padrão**: algo que se repete sempre do mesmo jeito. Achar o padrão ajuda a usar a repetição.
### 🌎 Onde eu uso isso?
- O **despertador** toca de novo a cada 5 minutos se você apertar “soneca”: ele repete o alarme.
- A **música** no modo “repetir” toca de novo e de novo.
- O **semáforo** repete sempre: verde, amarelo, vermelho, verde…
- No **exercício físico**: “faça 10 polichinelos” é uma repetição.
### 🎯 Missão
🟢 **Básico** — no portal: leve o robô até a estrela usando “repita”, siga um algoritmo de pintura com repetição e ligue cada repetição ao que ela faz.
🟡 **Desafio** — no portal: chegue à estrela com poucos blocos.
🔴 **Turbo** — no portal: descubra quando a repetição para.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) O comando “repita” deixa o algoritmo mais curto.
2. ( ) “Repita 3 vezes ➡️” é o mesmo que ➡️ ➡️ ➡️.
3. ( ) Laço infinito é uma repetição que para depois de 3 vezes.
4. ( ) Repetição também se chama laço.
5. ( ) Não dá para repetir um grupo de passos, só um passo de cada vez.
### 🧠 Resumo da Aula
A **repetição** (ou **laço**) faz o mesmo passo várias vezes. Com o comando **repita**, ➡️ ➡️ ➡️ vira “repita 3× ➡️”: o algoritmo fica mais curto e mais fácil de corrigir. Dá para repetir um passo ou um grupo de passos. Toda repetição precisa saber **quando parar**; a que nunca para é o **laço infinito**.
**Palavras-chave:** repetição · repita · laço · laço infinito · padrão

## 🔀 Missão 4 – Seleção: se… então… senão
**Objetivo:** usar a seleção para o algoritmo escolher o que fazer, de acordo com uma condição.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Às vezes o algoritmo precisa **escolher** um caminho. Para isso usamos a **seleção**: **se** uma **condição** for verdadeira, **então** faz uma coisa; **senão**, faz outra.
| Se… (condição) | então… (quando é verdade) | senão… (quando é mentira) |
| estiver chovendo | levo o guarda-chuva | vou sem guarda-chuva |
| o sinal estiver verde | atravesso | espero |
| a senha estiver certa | o celular abre | aparece “senha incorreta” |

**A condição** é sempre uma pergunta que só pode ter duas respostas: **sim (verdadeiro)** ou **não (falso)**. “Está chovendo?” é uma boa condição. “Que horas são?” não é, porque a resposta não é sim nem não.
**Seleção com repetição:** dá para juntar as duas ideias. “Repita 5 vezes: desenhe um quadrado; se for o 2º ou o 4º, pinte de preto; senão, deixe branco.” Assim o computador faz desenhos com padrões.
### 📖 O que significa?
- **Seleção**: parte do algoritmo que escolhe o que fazer, de acordo com uma condição. Também se chama **decisão**.
- **Condição**: pergunta que só pode ser respondida com sim (verdadeiro) ou não (falso). Exemplo: “O sinal está verde?”.
- **Se… então… senão**: o jeito de escrever a seleção. **Se** a condição for verdadeira, **então** faz uma coisa; **senão** (se for falsa), faz outra.
- **Verdadeiro**: quando a condição acontece (a resposta é sim).
- **Falso**: quando a condição não acontece (a resposta é não).
### 🌎 Onde eu uso isso?
- No **celular**: se a bateria estiver abaixo de 20%, então aparece o aviso de bateria fraca.
- Na **porta automática** do mercado: se alguém chegar perto, então ela abre; senão, fica fechada.
- No **jogo**: se você pegar a moeda, então ganha pontos; senão, continua igual.
- Na **escola**: se a nota for 5,0 ou mais, então está aprovado.
### 🎯 Missão
🟢 **Básico** — no portal: monte instruções de seleção, siga um algoritmo de pintura com se… senão e diga se cada condição é verdadeira ou falsa.
🟡 **Desafio** — no portal: escolha o que o algoritmo faz em cada situação.
🔴 **Turbo** — no portal: marque as boas condições (as que são respondidas com sim ou não).
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Na seleção, o algoritmo escolhe o que fazer de acordo com uma condição.
2. ( ) “Que horas são?” é uma boa condição para a seleção.
3. ( ) O “senão” acontece quando a condição é falsa.
4. ( ) A condição só pode ter duas respostas: verdadeiro ou falso.
5. ( ) Não dá para usar seleção e repetição no mesmo algoritmo.
### 🧠 Resumo da Aula
Na **seleção**, o algoritmo escolhe um caminho: **se** a **condição** for **verdadeira**, **então** faz uma coisa; **senão** (se for **falsa**), faz outra. A condição é uma pergunta de **sim ou não**. Dá para juntar seleção e repetição para criar padrões.
**Palavras-chave:** seleção · condição · se · então · senão · verdadeiro · falso

## 📥 Missão 5 – Entradas e saídas de um problema
**Objetivo:** identificar, antes de resolver um problema, o que é preciso receber (entradas) e o que se espera conseguir (saídas).
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Antes de montar um algoritmo, vale perguntar duas coisas: **do que eu preciso?** e **o que eu quero conseguir no fim?**
| Pergunta | Nome | Exemplo: fazer um bolo |
| Do que eu preciso para começar? | **Entradas** | farinha, ovos, leite, açúcar, fermento |
| O que eu faço com elas? | **Processamento** (os passos do algoritmo) | misturar, colocar na forma, assar |
| O que eu quero conseguir no fim? | **Saída** (o resultado esperado) | o bolo pronto |

No computador é igual. Na **calculadora**, as **entradas** são os números e a conta (2 + 3); o processamento é o cálculo; a **saída** é o resultado (5) que aparece na tela.
**Por que isso ajuda?** Se faltar uma entrada, o algoritmo não funciona: sem ovos, não sai o bolo. E, sabendo a saída esperada, dá para **conferir** se o algoritmo deu certo.
| Problema | Entradas | Saída esperada |
| Calcular a média da prova | as notas | a média |
| Mandar um áudio | a voz (pelo microfone) | o áudio enviado |
| Achar o caminho no mapa | onde estou e aonde vou | o caminho na tela |
### 📖 O que significa?
- **Entrada**: tudo o que o algoritmo precisa receber para começar. Exemplo: os números digitados na calculadora.
- **Saída**: o resultado que o algoritmo entrega no fim. Exemplo: o resultado da conta na tela.
- **Processamento**: os passos que transformam as entradas na saída.
- **Problema**: a situação que queremos resolver com o algoritmo.
- **Resultado esperado**: a saída que deveria aparecer se tudo der certo; serve para conferir o algoritmo.
### 🌎 Onde eu uso isso?
- Na **calculadora do celular**: você digita os números (entradas) e vê o resultado (saída).
- No **aplicativo de mapa**: você informa aonde quer ir (entrada) e recebe o caminho (saída).
- Na **máquina de café** ou de **refrigerante**: escolhe a bebida e põe o dinheiro (entradas) e recebe a bebida (saída).
### 🎯 Missão
🟢 **Básico** — no portal: separe as entradas e as saídas de problemas do dia a dia, ligue cada problema à sua saída e complete a tabela da calculadora.
🟡 **Desafio** — no portal: complete o texto sobre entradas e saídas.
🔴 **Turbo** — no portal: ache as palavras da missão no caça-palavras.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Entrada é tudo o que o algoritmo precisa receber para começar.
2. ( ) Na calculadora, o resultado que aparece na tela é uma entrada.
3. ( ) Se faltar uma entrada, o algoritmo pode não funcionar.
4. ( ) Saber a saída esperada ajuda a conferir se o algoritmo deu certo.
5. ( ) Processamento são os passos que transformam as entradas na saída.
### 🧠 Resumo da Aula
Antes de resolver um problema, pergunte: **do que eu preciso** (as **entradas**) e **o que eu quero no fim** (a **saída**). O **processamento** são os passos que transformam as entradas na saída. Sem as entradas certas, o algoritmo não funciona; sabendo o **resultado esperado**, dá para conferir se ele deu certo.
**Palavras-chave:** entrada · saída · processamento · problema · resultado esperado

## 🧩 Missão 6 – Decompor: dividir para resolver
**Objetivo:** dividir um problema grande em partes menores e mais fáceis, resolvendo uma de cada vez.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Um problema grande parece difícil. Mas, se dividirmos em **partes menores**, cada parte fica fácil. Isso se chama **decomposição** (ou **decompor**).
**Exemplo: organizar o aniversário da turma.** Parece muita coisa! Dividindo, fica assim:
| Parte (subproblema) | O que fazer |
| 🎈 Decoração | balões, faixa, toalha |
| 🍰 Comida | bolo, salgados, suco |
| 🎵 Diversão | músicas e brincadeiras |
| 🧹 Limpeza | recolher o lixo e arrumar a sala |

Cada parte vira um problema menor, chamado **subproblema**, que pode ser resolvido por **uma pessoa ou um grupo**. Quando todas as partes ficam prontas, o problema grande está resolvido.
**Os programadores fazem assim:** um jogo de celular é dividido em partes (os personagens, o cenário, os pontos, os sons), e cada equipe cuida de uma.
**Como decompor:** 1. diga qual é o problema grande; 2. pergunte “de que partes ele é feito?”; 3. resolva uma parte de cada vez; 4. junte tudo e confira.
### 📖 O que significa?
- **Decompor**: dividir um problema grande em partes menores e mais fáceis. O nome do processo é **decomposição**.
- **Subproblema**: cada parte menor de um problema grande. Exemplo: “a comida” é um subproblema de “organizar o aniversário”.
- **Problema grande**: a tarefa inteira, que parece difícil antes de ser dividida.
- **Parte**: um pedaço do problema, que pode ser resolvido sozinho e depois juntado aos outros.
- **Equipe**: grupo de pessoas que dividem as partes de um trabalho.
### 🌎 Onde eu uso isso?
- Para **arrumar o quarto**: arrumar a cama, guardar as roupas e recolher os brinquedos.
- No **trabalho em grupo da escola**: cada um faz uma parte: pesquisar o assunto, fazer o cartaz, ensaiar a apresentação e apresentar para a turma.
- Num **time de futebol**: goleiro, defesa, meio-campo e ataque dividem o jogo (o goleiro tem uma parte só: defender o gol).
- Para **estudar para a prova**: uma matéria ou um assunto por dia.
### 🎯 Missão
🟢 **Básico** — no portal: separe as tarefas de uma festa em partes, marque as partes de um problema e jogue a memória da decomposição.
🟡 **Desafio** — no portal: ligue cada problema grande a uma das suas partes.
🔴 **Turbo** — no portal: responda às perguntas sobre decompor.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Decompor é dividir um problema grande em partes menores.
2. ( ) Cada parte menor de um problema se chama subproblema.
3. ( ) Depois de dividir, é preciso resolver todas as partes ao mesmo tempo, sozinho.
4. ( ) Um jogo de celular é dividido em partes, e cada equipe cuida de uma.
5. ( ) Decompor deixa o problema mais difícil.
### 🧠 Resumo da Aula
**Decompor** é dividir um problema grande em partes menores, os **subproblemas**. Cada parte é mais fácil e pode ser resolvida por uma pessoa ou **equipe**. Quando todas as partes ficam prontas, o problema grande está resolvido. Os programadores dividem os programas assim.
**Palavras-chave:** decompor · decomposição · subproblema · parte · equipe

## 🐞 Missão 7 – Extra: Caça ao erro
**Objetivo:** encontrar e corrigir erros em algoritmos, testando passo a passo.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Até os melhores programadores erram. Um erro num programa se chama **bug** (em inglês, “inseto”). Achar e corrigir o erro se chama **depurar** (em inglês, *debug*, “tirar o inseto”).
**Por que “inseto”?** Em 1947, a equipe da cientista Grace Hopper achou uma mariposa presa dentro de um computador enorme, que estava dando defeito. Eles colaram a mariposa no caderno com a anotação “primeiro caso de bug encontrado”. A palavra já era usada para defeitos, e a história ficou famosa.
**Como caçar o erro, passo a passo:**
| Passo | O que fazer |
| 1. Testar | Execute o algoritmo e veja o que acontece |
| 2. Comparar | O resultado é o esperado? Onde ficou diferente? |
| 3. Achar | Vá passo a passo até achar o primeiro passo errado |
| 4. Corrigir | Mude só esse passo e teste de novo |

**Erros mais comuns:** um passo **fora de ordem**, um passo que **falta**, um passo **a mais** ou um número errado na repetição.
### 📖 O que significa?
- **Bug**: em inglês, “inseto”: um erro no algoritmo ou no programa, que faz o resultado sair errado.
- **Depurar**: achar e corrigir o erro. Em inglês, *debug* (“tirar o inseto”).
- **Testar**: executar o algoritmo para ver se o resultado é o esperado.
- **Corrigir**: mudar o passo errado para o algoritmo funcionar.
- **Grace Hopper**: cientista da computação americana (1906–1992), pioneira da programação; a história da mariposa aconteceu na equipe dela.
### 🌎 Onde eu uso isso?
- Quando o **aplicativo** pede para **atualizar**, muitas vezes é para corrigir bugs.
- Quando a **receita** não dá certo, você confere passo a passo onde errou.
- No **jogo**, quando o personagem atravessa a parede, é um bug que os programadores precisam corrigir.
### 🎯 Missão
🟢 **Básico** — no portal: conserte o programa do robô, ache o passo errado e coloque o algoritmo na ordem certa.
🟡 **Desafio** — no portal: separe os algoritmos certos dos que têm bug.
🔴 **Turbo** — no portal: conserte um robô que repete demais.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Bug é um erro no algoritmo ou no programa.
2. ( ) Depurar é achar e corrigir o erro.
3. ( ) Para achar o erro, o melhor é mudar todos os passos de uma vez.
4. ( ) Um passo fora de ordem pode ser um bug.
5. ( ) Bons programadores nunca erram.
### 🧠 Resumo da Aula
Um **bug** é um erro no algoritmo. **Depurar** é achar e corrigir o erro: **testar**, comparar com o resultado esperado, achar o primeiro passo errado e **corrigir** só ele. Erros comuns: passo fora de ordem, faltando, a mais ou número errado na repetição.
**Palavras-chave:** bug · depurar · testar · corrigir · Grace Hopper

## 🐢 Missão 8 – Extra: Desenho com a tartaruga
**Objetivo:** fazer desenhos com algoritmos, juntando sequência e repetição.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Nos anos 1960, o pesquisador Seymour Papert e a sua equipe criaram a linguagem **Logo**, feita para crianças aprenderem a programar. Nela, uma **tartaruga** 🐢 anda pela tela e deixa um **rastro**, como um lápis. Mandando a tartaruga andar, o rastro vira **desenho**.
Hoje vamos desenhar no quadriculado: cada seta anda **uma casa**, e o caminho da tartaruga vira o desenho. Os pontos ⚪ mostram por onde ela precisa passar; quando ela passa, o ponto fica 🟩.
**Desenhar um quadrado:** um quadrado tem **4 lados iguais**. Para desenhar um quadrado de 2 casas de lado:
| Sem repetição | Com repetição |
| ➡️ ➡️ ⬇️ ⬇️ ⬅️ ⬅️ ⬆️ ⬆️ (8 comandos) | repita 2× ➡️ · repita 2× ⬇️ · repita 2× ⬅️ · repita 2× ⬆️ (4 blocos) |

**O segredo do desenho:** ache o **padrão**. Um quadrado é “ande um lado, vire” repetido 4 vezes. Um retângulo tem 2 lados compridos e 2 curtos. Uma **linha reta** é repetir várias vezes a mesma seta, e uma **escada** é o degrau ➡️ ⬇️ repetido: ➡️ ⬇️ ➡️ ⬇️ ➡️ ⬇️. Por isso, a repetição **ajuda a desenhar figuras**.
### 📖 O que significa?
- **Tartaruga** (do Logo): o “lápis” que anda pela tela e deixa um rastro, formando o desenho.
- **Logo**: linguagem de programação criada para crianças nos anos 1960; ficou famosa pela tartaruga.
- **Rastro**: o caminho que a tartaruga deixa por onde passa; é o desenho.
- **Quadrado**: figura com 4 lados iguais.
- **Retângulo**: figura com 4 lados: 2 compridos e 2 curtos.
### 🌎 Onde eu uso isso?
- As **máquinas de corte** e as **impressoras 3D** seguem algoritmos de “ande até aqui, vire”, como a tartaruga.
- O **robô aspirador** anda pela casa seguindo um caminho programado.
- Nos **jogos**, os personagens andam por caminhos calculados por algoritmos.
### 🎯 Missão
🟢 **Básico** — no portal: desenhe um quadrado e um retângulo com a tartaruga e descubra o padrão de cada desenho.
🟡 **Desafio** — no portal: desenhe o quadrado com poucos blocos, usando “repita”.
🔴 **Turbo** — no portal: desenhe uma escada.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Na linguagem Logo, a tartaruga deixa um rastro que vira desenho.
2. ( ) Um quadrado tem 4 lados iguais.
3. ( ) A repetição não ajuda a desenhar figuras.
4. ( ) Um retângulo tem 2 lados compridos e 2 curtos.
5. ( ) A linguagem Logo foi criada para crianças aprenderem a programar.
### 🧠 Resumo da Aula
Na linguagem **Logo**, a **tartaruga** anda e deixa um **rastro**: o caminho vira desenho. Juntando **sequência** e **repetição**, desenhamos figuras: o **quadrado** (4 lados iguais) é “ande um lado, vire” repetido 4 vezes. Achar o **padrão** deixa o algoritmo curto.
**Palavras-chave:** tartaruga · Logo · rastro · quadrado · retângulo · padrão
