## 🦠 Missão 1 – Malwares: os programas do mal
**Objetivo:** saber o que é malware e como se proteger.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Malware** é um programa feito para **prejudicar**. Veja alguns:
| Tipo | O que faz | Parece com… |
| 🦠 Vírus | Gruda nos arquivos | Uma gripe que passa |
| 🐴 Cavalo de Troia | Finge ser um programa bom | Um presente com surpresa ruim |
| 📢 Adware | Enche a tela de propagandas | Panfletos sem parar |

**Como se proteger:**
| Atitude | Por quê |
| 🔄 Atualizar o celular | Fecha as falhas |
| 🛡️ Usar antivírus | Ele bloqueia o malware |
| 🏪 Baixar só da loja oficial | Lá os aplicativos são conferidos |
### 📖 O que significa?
- **Malware**: programa do mal, feito para prejudicar.
- **Antivírus**: programa que bloqueia o malware.
- **Aplicativo**: programa do celular.
- **Loja oficial**: a loja de aplicativos do próprio celular.
### 🌎 Onde eu uso isso?
- Ao **baixar um jogo**.
- Quando aparece **propaganda demais** no celular.
### ✅ Perguntas rápidas
1. ( ) Malware é um programa feito para prejudicar.
2. ( ) O cavalo de Troia finge ser um programa bom.
3. ( ) Baixar de qualquer site é seguro.
### 🧠 Resumo da Aula
**Malware** é programa do mal. Para se proteger: **atualizar**, usar **antivírus** e baixar só da **loja oficial**.
**Palavras-chave:** malware · vírus · cavalo de Troia · antivírus

## 🎣 Missão 2 – Engenharia social, força bruta e DDoS
**Objetivo:** reconhecer um golpe.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Muitas vezes o golpista **engana a pessoa**. Isso é **engenharia social**.
| Sinal de golpe | Exemplo |
| ⏰ Pressa | “URGENTE! Em 1 hora!” |
| 🎁 Prêmio fácil | “Você ganhou um celular!” |
| 🔑 Pede a senha | “Mande a sua senha” |
| 💸 Pede dinheiro | “Me manda um Pix” |

**Banco nunca pede a senha por mensagem.**
**Força bruta** é quando um programa testa **todas as senhas** até acertar. **DDoS** é quando milhares de computadores acessam um site **ao mesmo tempo** para ele cair.
### 📖 O que significa?
- **Golpe**: enganar alguém para tirar vantagem.
- **Engenharia social**: enganar a pessoa para ela entregar os dados.
- **Força bruta**: testar todas as senhas.
- **DDoS**: derrubar um site com milhares de acessos.
### 🌎 Onde eu uso isso?
- Nas **mensagens** do celular.
- No **e-mail**.
### ✅ Perguntas rápidas
1. ( ) Pressa é um sinal de golpe.
2. ( ) O banco pede a senha por mensagem.
3. ( ) Força bruta é testar todas as senhas.
### 🧠 Resumo da Aula
Sinais de golpe: **pressa**, **prêmio fácil**, pedido de **senha** ou de **dinheiro**. Na dúvida, **não responda** e avise um adulto.
**Palavras-chave:** golpe · engenharia social · força bruta · DDoS

## 🔤 Missão 3 – Cifra de César: a mensagem secreta
**Objetivo:** cifrar uma palavra com a chave 3.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Na **cifra de César**, cada letra **anda 3 casas** no alfabeto. O número 3 é a **chave**.
| Letra normal | A | B | C | D | E | … | X | Y | Z |
| Letra cifrada | D | E | F | G | H | … | A | B | C |

Exemplo: **LUA** vira **OXD**. Para **decifrar**, cada letra **volta** 3 casas: OXD vira LUA.
### 📖 O que significa?
- **Cifrar**: esconder a mensagem trocando as letras.
- **Decifrar**: voltar para a mensagem normal.
- **Chave**: o número de casas que cada letra anda.
### 🌎 Onde eu uso isso?
- Nos **aplicativos de mensagens**, que embaralham o que você escreve.
- Num **bilhete secreto** para um amigo.
### ✅ Perguntas rápidas
1. ( ) Com a chave 3, A vira D.
2. ( ) Para decifrar, as letras andam mais casas para a frente.
3. ( ) LUA cifrada com a chave 3 é OXD.
### 🧠 Resumo da Aula
Na **cifra de César**, cada letra anda o número da **chave**. Para **decifrar**, a letra **volta**.
**Palavras-chave:** cifrar · decifrar · chave

## 🔐 Missão 4 – Criptografia hoje: chaves e HTTPS
**Objetivo:** saber o que quer dizer o cadeado do site.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Hoje os sites usam **duas chaves**:
| Chave | Como é |
| 🔓 Chave pública | Um cadeado aberto: todo mundo pode **fechar** |
| 🗝️ Chave privada | Secreta: só o dono **abre** |

Quando o endereço começa com **https** e tem um **🔒 cadeado**, a conversa com o site é **cifrada**.
**Atenção:** o cadeado **não prova** que o site é honesto. Confira sempre o **nome do site**.
### 📖 O que significa?
- **Criptografia**: embaralhar a mensagem para só quem tem a chave ler.
- **HTTPS**: o endereço com cadeado; os dados viajam cifrados.
- **Chave pública**: o cadeado aberto, que todos podem ter.
- **Chave privada**: a chave secreta, que abre.
### 🌎 Onde eu uso isso?
- Ao entrar no **portal da escola**: olhe o cadeado.
- Nos **aplicativos de mensagens**.
### ✅ Perguntas rápidas
1. ( ) O https mostra que a conversa é cifrada.
2. ( ) A chave privada é de todo mundo.
3. ( ) O cadeado prova que o site é honesto.
### 🧠 Resumo da Aula
A **chave pública** fecha; só a **chave privada** abre. O **https** e o 🔒 mostram que a conversa é **cifrada**, mas é preciso conferir o **nome do site**.
**Palavras-chave:** criptografia · HTTPS · chave pública · chave privada

## 🔑 Missão 5 – Senhas e armazenamento seguro
**Objetivo:** reconhecer uma senha forte.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
| Senha fraca | Senha forte |
| Curta: 123456 | Comprida |
| Tem o seu nome ou o seu aniversário | Não tem nada pessoal |
| Só números | Mistura letras, números e símbolos |

**Exemplo de senha forte (inventada):** Gato!Azul7Pula.
O site **não guarda** a sua senha: ele guarda um **hash**, um resumo embaralhado.
A **verificação em duas etapas** pede um **código no celular**, além da senha.
### 📖 O que significa?
- **Senha forte**: comprida e misturada, sem nada pessoal.
- **Hash**: resumo embaralhado da senha.
- **Verificação em duas etapas**: senha + código no celular.
### 🌎 Onde eu uso isso?
- Na conta do **jogo** e do **e-mail**.
- No **celular**.
### ✅ Perguntas rápidas
1. ( ) 123456 é uma senha forte.
2. ( ) Senha forte mistura letras, números e símbolos.
3. ( ) A verificação em duas etapas pede um código no celular.
### 🧠 Resumo da Aula
Senha forte é **comprida** e **misturada**, sem nada **pessoal**. Senha é **pessoal**: não conte para ninguém.
**Palavras-chave:** senha forte · hash · duas etapas

## 🎮 Missão 6 – Projeto: programa por eventos
**Objetivo:** ligar cada evento à sua ação.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Um programa por eventos funciona assim: **QUANDO** algo acontece, **FAÇA** uma ação.
| Regra | Evento (QUANDO…) | Ação (FAÇA…) |
| 1 | A porta abre depois das 18h | Tocar a sirene |
| 2 | Alguém digita o código certo | Desligar a sirene |
| 3 | O código é errado 3 vezes | Mandar aviso ao celular do professor |

**Evento** é o que **acontece**. **Ação** é o que o programa **faz**.
### 📖 O que significa?
- **Evento**: algo que acontece e o programa percebe.
- **Ação**: o que o programa faz.
- **Sirene**: o som alto do alarme.
### 🌎 Onde eu uso isso?
- O celular **vibra quando chega mensagem**.
- No jogo, o personagem **pula quando aperto a tecla**.
### ✅ Perguntas rápidas
1. ( ) A porta abrir é um evento.
2. ( ) Tocar a sirene é uma ação.
3. ( ) A ação acontece antes do evento.
### 🧠 Resumo da Aula
**QUANDO** acontece um **evento**, **FAÇA** uma **ação**. O alarme da sala tem **3 regras**.
**Palavras-chave:** evento · ação · regra

## 💰 Missão 7 – Extra: Ransomware e backup
**Objetivo:** saber por que fazer backup.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
O **ransomware** tranca os arquivos e pede **dinheiro** (o **resgate**). Pagar **não garante** nada.
A proteção é o **backup**, a cópia de segurança. A **regra 3-2-1**:
| Número | Regra | Exemplo |
| 3 | 3 cópias | O original + 2 cópias |
| 2 | 2 tipos de lugar | Computador e HD externo |
| 1 | 1 cópia fora de casa | Na nuvem |
### 📖 O que significa?
- **Ransomware**: malware que tranca os arquivos e pede resgate.
- **Backup**: cópia de segurança.
- **Nuvem**: guardar arquivos pela internet.
- **HD externo**: disco ligado pelo cabo USB.
### 🌎 Onde eu uso isso?
- Ao **salvar as fotos** do celular na nuvem.
- Nos **computadores da escola**.
### ✅ Perguntas rápidas
1. ( ) Backup é uma cópia de segurança.
2. ( ) Pagar o resgate garante que os arquivos voltam.
3. ( ) Na regra 3-2-1, uma cópia fica fora de casa.
### 🧠 Resumo da Aula
O **ransomware** tranca os arquivos. A proteção é o **backup**: regra **3-2-1**.
**Palavras-chave:** ransomware · backup · regra 3-2-1

## 🕵️ Missão 8 – Extra: Esteganografia
**Objetivo:** achar a palavra escondida num bilhete.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Esteganografia** é **esconder** uma mensagem dentro de outra coisa, sem ninguém perceber.
| Bilhete | Primeira letra |
| **S**aí cedo hoje. | S |
| **O**ntem choveu muito. | O |
| **L**evei o guarda-chuva. | L |

Lendo as **primeiras letras**, de cima para baixo: **SOL**.
Outro exemplo: no bilhete “Recebi o livro. / Está ótimo. / Devolvo amanhã. / Envio um abraço.”, as primeiras letras formam **REDE**.
### 📖 O que significa?
- **Esteganografia**: escrita escondida.
- **Acróstico**: as primeiras letras formam uma palavra.
### 🌎 Onde eu uso isso?
- Num **bilhete secreto** para um amigo.
- Em **fotos** que escondem letras nos pontinhos.
### ✅ Perguntas rápidas
1. ( ) Esteganografia é esconder uma mensagem.
2. ( ) No bilhete, as primeiras letras formam SOL.
3. ( ) Na esteganografia, todo mundo percebe o segredo.
### 🧠 Resumo da Aula
**Esteganografia** esconde a mensagem. No **acróstico**, as **primeiras letras** formam a palavra.
**Palavras-chave:** esteganografia · acróstico
