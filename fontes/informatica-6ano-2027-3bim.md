## 🧱 Missão 1 – Meu primeiro programa
**Objetivo:** montar o primeiro programa com blocos e entender que o computador executa os blocos na ordem.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Um **programa** é um **algoritmo** escrito numa linguagem que o computador entende. Aqui, a linguagem são **blocos** que se encaixam.
**Como usar o editor de blocos:**
| Passo | O que fazer |
| 1 | Abra uma **gaveta** (por exemplo, 📺 Mostrar) |
| 2 | **Arraste** o bloco para a área branca |
| 3 | **Encaixe** um bloco embaixo do outro (eles grudam) |
| 4 | Clique no texto do bloco para **escrever** |
| 5 | Aperte **▶️ Rodar o programa** e veja a **📺 Tela do programa** |

O computador lê os blocos **de cima para baixo**, um de cada vez, e faz **exatamente** o que eles mandam. Isso é a **sequência**.
**A ordem importa:** “mostrar ‘Bom dia’” e depois “mostrar ‘Tchau’” é diferente de “mostrar ‘Tchau’” e depois “mostrar ‘Bom dia’”.
**O bloco solto não roda:** se o bloco não estiver **encaixado** no programa, o computador não executa ele.
### 📖 O que significa?
- **Programa**: algoritmo escrito numa linguagem que o computador entende.
- **Bloco**: peça do editor que representa uma instrução.
- **Gaveta**: lugar do editor onde ficam os blocos, separados por tipo.
- **Executar** (ou **rodar**): fazer o computador seguir os blocos.
- **Sequência**: blocos um embaixo do outro, executados na ordem.
- **Encaixar**: grudar um bloco no outro para que façam parte do mesmo programa.
- **Aplicativo** (ou *app*): programa instalado no celular ou no computador.
### 🌎 Onde eu uso isso?
- Todo **jogo** e todo **aplicativo** é um programa.
- A **receita de bolo** é uma sequência: a ordem dos passos importa.
- O **despertador** do celular segue o que foi programado.
### 🎯 Missão
🟢 **Básico** — no editor de blocos: monte o seu primeiro programa, coloque os blocos na ordem certa e responda sobre a sequência.
🟡 **Desafio** — no editor: o bom-dia do robô, com 4 linhas na ordem.
🔴 **Turbo** — no editor: conserte o programa que está na ordem errada.
⚠️ Os computadores são usados por todos: **nunca apague nem mexa nos arquivos dos colegas**.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) O computador lê os blocos de cima para baixo.
2. ( ) A ordem dos blocos não muda o resultado.
3. ( ) Programa é um algoritmo numa linguagem que o computador entende.
4. ( ) Um bloco solto, fora do programa, também é executado.
5. ( ) Para ver o resultado, aperto ▶️ Rodar o programa.
### 🧠 Resumo da Aula
Um **programa** é um algoritmo em **blocos**. Abra a **gaveta**, arraste, **encaixe** e aperte **▶️ Rodar**. O computador **executa** de cima para baixo: é a **sequência**, e a ordem importa. Bloco solto não roda.
**Palavras-chave:** programa · bloco · gaveta · executar · sequência · encaixar

## 🔁 Missão 2 – Repetição e seleção em blocos
**Objetivo:** usar o repita para não repetir blocos e o se para o programa decidir.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
| Bloco | O que faz | Exemplo |
| 🔁 **repita 3 vezes** | Faz os blocos de dentro várias vezes | repita 3 vezes: mostrar “pula” → pula, pula, pula |
| 🔀 **se … faça … senão** | Escolhe um caminho conforme uma condição | se chover = verdadeiro, mostrar “guarda-chuva”; senão, mostrar “boné” |

**Dentro ou fora?** Se o “mostrar ‘fim’” ficar **dentro** do repita 3 vezes, ele aparece **3 vezes**. Se ficar **embaixo** do repita (fora dele), aparece **1 vez**, no final.
**A condição** é uma pergunta de **sim ou não** (verdadeiro ou falso). Na gaveta **⚖️ Comparar** ficam os blocos para perguntar, como **10 > 5** (10 é maior que 5?).
| Comparação | Quer dizer | Exemplo verdadeiro |
| = | igual | 3 = 3 |
| > | maior que | 10 > 5 |
| < | menor que | 2 < 9 |
| ≥ | maior ou igual | 5 ≥ 5 |
### 📖 O que significa?
- **Repetição** (ou laço): fazer os mesmos blocos várias vezes.
- **Seleção**: escolher um caminho com o **se … faça … senão**.
- **Condição**: pergunta de sim ou não que o se confere.
- **Verdadeiro e falso**: as duas respostas possíveis de uma condição.
- **Comparar**: ver se um valor é igual, maior ou menor que outro.
### 🌎 Onde eu uso isso?
- Fazer **10 polichinelos** é uma repetição.
- **Se chover, levo guarda-chuva** é uma seleção.
- No jogo, **se a vida acabar, aparece “Fim de jogo”**.
### 🎯 Missão
🟢 **Básico** — no editor: encurte com o repita, monte um se … senão e responda: dentro ou fora do repita?
🟡 **Desafio** — no editor: o semáforo decide sozinho.
🔴 **Turbo** — no editor: repita e se juntos.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) O repita faz os blocos de dentro várias vezes.
2. ( ) O se serve para repetir.
3. ( ) A condição é uma pergunta de sim ou não.
4. ( ) Um bloco embaixo do repita, fora dele, aparece uma vez só.
5. ( ) 10 > 5 é verdadeiro.
### 🧠 Resumo da Aula
O **repita** faz os blocos de dentro várias vezes (**repetição**). O **se … faça … senão** escolhe um caminho (**seleção**) pela **condição**, que é **verdadeira** ou **falsa**. Dentro do repita repete; fora, uma vez só. Comparações: =, >, <, ≥.
**Palavras-chave:** repetição · seleção · condição · verdadeiro · falso · comparar

## 📦 Missão 3 – Variáveis: as caixinhas do programa
**Objetivo:** guardar e mudar valores com variáveis.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Uma **variável** é uma **caixinha com nome** que guarda um valor.
| Bloco | O que faz | Exemplo |
| 📦 **definir pontos para 0** | Coloca um valor na caixinha | A caixinha “pontos” guarda 0 |
| ➕ **alterar pontos por 1** | Soma um valor ao que já estava | 0 vira 1; depois 1 vira 2 |
| 👀 **pontos** (o bloco redondo) | Pega o valor que está na caixinha | Mostra 2 |

**Juntar texto e variável:** o bloco **criar texto com** (gaveta 🔤 Texto) junta pedaços: “Pontos: ” + pontos → **Pontos: 2**.
**Exemplo passo a passo:**
| Bloco | Valor de pontos depois do bloco |
| definir pontos para 0 | 0 |
| alterar pontos por 5 | 5 |
| alterar pontos por 3 | 8 |
| mostrar “Pontos: ” + pontos | 8 (aparece “Pontos: 8”) |

Uma variável pode guardar um **número** (como 8) ou um **texto** (como “Ana”).
### 📖 O que significa?
- **Variável**: caixinha com nome que guarda um valor.
- **Valor**: o que está guardado na variável (um número ou um texto).
- **Definir**: colocar um valor na variável.
- **Alterar por**: somar um número ao valor da variável.
- **Juntar** (criar texto com): unir pedaços de texto e variáveis numa frase.
### 🌎 Onde eu uso isso?
- O **placar** de um jogo é uma variável que muda a cada gol.
- As **vidas** do personagem diminuem quando ele cai.
- O **saldo** do bilhete do ônibus muda a cada viagem.
### 🎯 Missão
🟢 **Básico** — no editor: crie a variável pontos, mude o valor e mostre com texto; acompanhe o valor passo a passo.
🟡 **Desafio** — no editor: o placar da partida.
🔴 **Turbo** — no editor: a variável dentro do repita.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Variável é uma caixinha com nome que guarda um valor.
2. ( ) “alterar pontos por 1” apaga o valor e coloca 1.
3. ( ) Uma variável pode guardar um número ou um texto.
4. ( ) Definir pontos para 0, mudar por 5 e mudar por 3 deixa pontos com 8.
5. ( ) O bloco criar texto com junta pedaços numa frase.
### 🧠 Resumo da Aula
A **variável** é uma caixinha com nome. **Definir** coloca um **valor**; **alterar por** soma ao valor; o bloco redondo pega o valor. **Criar texto com** junta texto e variável. A variável guarda **número** ou **texto**.
**Palavras-chave:** variável · valor · definir · alterar por · juntar

## 🧩 Missão 4 – Um bloco para muitos casos
**Objetivo:** criar um bloco próprio e usar uma variável como parâmetro para ele servir em vários casos.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Às vezes um pedaço do programa se repete em vários lugares. Em vez de montar tudo de novo, você **cria o seu próprio bloco** (gaveta **🧩 Meus blocos**) e **chama** ele quando precisar. No editor, o bloco criado aparece como **para saudar** (com os blocos dentro), e na gaveta surge o bloco **saudar**, que serve para chamar.
| Ideia | Exemplo |
| 🧩 **Criar um bloco** | O bloco **saudar** mostra “Olá, ” + nome |
| 📞 **Chamar** o bloco | Toda vez que você chama **saudar**, ele faz o que tem dentro |
| 🎛️ **Parâmetro** | O valor que **muda** a cada vez: aqui, a variável **nome** |

**Um bloco para muitos casos:**
| Blocos do programa | Tela |
| definir nome para “Ana” · chamar saudar | Olá, Ana |
| definir nome para “Leo” · chamar saudar | Olá, Leo |

O bloco **saudar** é o **mesmo**; só o **parâmetro** (nome) mudou. Assim o programa fica **mais curto** e, se precisar mudar a saudação, você muda **em um lugar só**.
### 📖 O que significa?
- **Meu bloco** (ou função): um bloco criado por você, com outros blocos dentro.
- **Chamar**: mandar o computador fazer o que está dentro do seu bloco.
- **Parâmetro**: o valor que muda a cada vez que o bloco é usado.
- **Reaproveitar**: usar a mesma coisa de novo, sem montar tudo outra vez.
### 🌎 Onde eu uso isso?
- O **botão “curtir”** é o mesmo em todos os posts; só muda o post.
- A **receita de suco** serve para várias frutas: a fruta é o parâmetro.
- Na escola, a **chamada** é o mesmo jeito de perguntar, só muda o nome.
### 🎯 Missão
🟢 **Básico** — no editor: chame o bloco saudar, use o parâmetro nome para dois alunos e ligue cada ideia ao seu significado.
🟡 **Desafio** — no editor: o bloco aniversário para três pessoas.
🔴 **Turbo** — no editor: conserte o bloco para mudar em um lugar só.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Posso criar o meu próprio bloco na gaveta Meus blocos.
2. ( ) Chamar o bloco faz o computador executar o que tem dentro dele.
3. ( ) Parâmetro é o valor que muda a cada vez.
4. ( ) Para cada nome novo, preciso criar um bloco diferente.
5. ( ) Um bloco próprio deixa o programa mais curto.
### 🧠 Resumo da Aula
Você pode **criar o seu bloco** (🧩 Meus blocos) e **chamar** ele várias vezes. O **parâmetro** é o valor que muda (como o **nome**). O bloco é o mesmo para **muitos casos**: o programa fica mais curto e a mudança é feita em um lugar só (**reaproveitar**).
**Palavras-chave:** meu bloco · chamar · parâmetro · reaproveitar

## 📝 Missão 5 – Listas e tipos de dados
**Objetivo:** guardar vários valores numa lista e conhecer os tipos de dados.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Tipos de dados:** o computador trata cada valor de um jeito.
| Tipo | Exemplos | Dá para… |
| 🔢 **Número** | 7, 15, 100 | Fazer contas |
| 🔤 **Texto** | “Ana”, “bom dia” | Juntar e mostrar |
| ✅ **Lógico** | verdadeiro, falso | Responder condições |
| 📝 **Lista** | [“maçã”, “uva”, “caju”] | Guardar vários valores em ordem |

**Lista:** uma variável que guarda **vários valores em ordem**. Cada valor tem uma **posição**: na lista frutas = [“maçã”, “uva”, “caju”], o **item 1** é “maçã”, o **item 2** é “uva” e o **item 3** é “caju”. O **tamanho** da lista é **3**.
| Bloco (gaveta 📝 Listas e 👉 Para cada) | O que faz |
| criar lista com | Monta a lista |
| obter nº | Pega o item de uma posição |
| tamanho de | Conta quantos itens a lista tem |
| para cada item da lista | Faz os blocos de dentro para cada item, um de cada vez |
### 📖 O que significa?
- **Tipo de dado**: o jeito de cada valor (número, texto, lógico, lista).
- **Lista**: variável que guarda vários valores em ordem.
- **Item**: cada valor da lista.
- **Posição**: o número do lugar do item na lista (1, 2, 3…).
- **Tamanho**: quantos itens a lista tem.
- **Lógico**: tipo de dado que só pode ser verdadeiro ou falso.
### 🌎 Onde eu uso isso?
- A **lista de compras** e a **chamada** da turma.
- A **playlist** de músicas: cada música tem uma posição.
- O **“Você é maior de 12 anos? Sim ou não”** é um valor lógico.
### 🎯 Missão
🟢 **Básico** — no editor: pegue um item da lista, mostre o tamanho e use o para cada; separe os tipos de dados.
🟡 **Desafio** — no editor: a chamada da turma com o para cada.
🔴 **Turbo** — no editor: some os pontos da lista.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Uma lista guarda vários valores em ordem.
2. ( ) Na lista [“maçã”, “uva”, “caju”], o item 2 é “caju”.
3. ( ) O tamanho da lista [“maçã”, “uva”, “caju”] é 3.
4. ( ) “Ana” é um dado do tipo número.
5. ( ) Verdadeiro e falso são dados do tipo lógico.
### 🧠 Resumo da Aula
**Tipos de dados**: **número** (contas), **texto** (juntar e mostrar), **lógico** (verdadeiro ou falso) e **lista** (vários valores em ordem). Na lista, cada **item** tem uma **posição** (1, 2, 3…), e o **tamanho** é quantos itens ela tem. O **para cada** passa por todos os itens.
**Palavras-chave:** tipo de dado · lista · item · posição · tamanho · lógico

## 🎮 Missão 6 – Projeto: meu joguinho
**Objetivo:** planejar, montar e testar um joguinho de botões com eventos, variáveis e seleção.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Hoje você junta tudo num **joguinho**: o jogador aperta **botões** e o programa conta os pontos.
**Evento** é algo que acontece e o programa percebe, como **apertar um botão**. O bloco **⚡ quando** diz o que fazer **quando** o evento acontece. No portal, ao rodar, os botões são apertados sozinhos, na ordem mostrada.
**As regras do joguinho “Pega-Moeda”:**
| Regra | Evento | Ação |
| 1 | Começo do jogo | definir pontos para 0 |
| 2 | 🟢 botão verde (pegou moeda) | alterar pontos por 1 e mostrar os pontos |
| 3 | 🔴 botão vermelho (pegou bomba) | alterar pontos por −1 e mostrar os pontos |

**As etapas do projeto (decompor):**
| Etapa | O que fazer |
| 1 | **Planejar**: escrever as regras (evento → ação) |
| 2 | **Montar**: colocar os blocos de cada regra |
| 3 | **Testar**: rodar e conferir se os pontos estão certos |
| 4 | **Melhorar**: consertar erros e acrescentar uma regra nova |
### 📖 O que significa?
- **Evento**: algo que acontece e o programa percebe, como apertar um botão.
- **Projeto**: um trabalho maior, feito em etapas.
- **Decompor**: dividir um problema grande em partes menores.
- **Testar**: rodar o programa para ver se faz o que devia.
- **Regra do jogo**: o que acontece em cada situação.
### 🌎 Onde eu uso isso?
- Nos **jogos**: apertar o botão faz o personagem pular.
- No **controle remoto**: cada botão é um evento.
- Em qualquer **trabalho em equipe**: planejar, fazer, testar, melhorar.
### 🎯 Missão
🟢 **Básico** — no editor: monte a regra do botão verde, depois a do vermelho; coloque as etapas do projeto em ordem.
🟡 **Desafio** — no editor: o jogo avisa “Você venceu!” ao chegar a 3 pontos.
🔴 **Turbo** — no editor: acrescente o botão azul que vale 2 pontos.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Evento é algo que acontece e o programa percebe.
2. ( ) O bloco quando diz o que fazer quando o evento acontece.
3. ( ) No projeto, testar é a primeira etapa.
4. ( ) No Pega-Moeda, o botão vermelho tira 1 ponto.
5. ( ) Decompor é dividir um problema grande em partes menores.
### 🧠 Resumo da Aula
O **evento** (apertar um botão) aciona o bloco **⚡ quando**. No **Pega-Moeda**: começo → pontos = 0; 🟢 verde → +1; 🔴 vermelho → −1. O **projeto** tem etapas: **planejar**, **montar**, **testar** e **melhorar** (**decompor**).
**Palavras-chave:** evento · projeto · decompor · testar · regra do jogo

## 🧠 Missão 7 – Extra: Desafios de lógica
**Objetivo:** prever o que um programa faz e achar o erro antes de rodar.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Programadores leem o programa e **preveem** o resultado **antes de rodar**. Depois rodam para **conferir**.
**Como prever:** siga os blocos de cima para baixo e anote o **valor** de cada variável, como uma tabela.
| Bloco | x |
| definir x para 2 | 2 |
| repita 3 vezes: alterar x por 2 | 4, 6, 8 |
| mostrar x | aparece **8** |

**Depurar** é achar e consertar o **erro** (o “bug”) do programa. Erros comuns:
| Erro | Exemplo | Conserto |
| 🔀 Ordem trocada | “Tchau” aparece antes de “Oi” | Trocar os blocos de lugar |
| 🔢 Número errado | repita 2 vezes, mas eram 3 | Mudar o número |
| 📦 Fora do lugar | “fim” dentro do repita | Arrastar para fora |
| ⚖️ Comparação errada | se nota > 5 (e a nota 5 devia mostrar “passou”) | Trocar para ≥ |
### 📖 O que significa?
- **Prever**: dizer o resultado antes de acontecer.
- **Depurar**: achar e consertar o erro do programa.
- **Bug** (em inglês, “inseto”): erro no programa.
- **Rastrear**: seguir o programa passo a passo, anotando os valores.
### 🌎 Onde eu uso isso?
- No **jogo** que trava: alguém precisa achar o bug.
- Na **conta de matemática**: refazer passo a passo para achar o erro.
- Ao **seguir uma receita** e o bolo não crescer: qual passo deu errado?
### 🎯 Missão
🟢 **Básico** — no portal: preveja o resultado de programas, ligue cada erro ao conserto e depure um programa.

**Palavras-chave:** prever · depurar · bug · rastrear

## 🎬 Missão 8 – Extra: Minha história animada
**Objetivo:** contar uma história com blocos, usando sequência, repetição e variáveis.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Um programa também pode **contar uma história**. Cada linha da Tela do programa é uma **cena**.
| Ideia da história | Bloco |
| ➡️ Uma cena depois da outra | Sequência: mostrar, mostrar, mostrar |
| 🔁 Algo que se repete (passos, batidas na porta) | repita |
| 🧑 O nome do personagem em várias cenas | Variável **heroi** |

**Exemplo:** definir heroi para “Tito” → mostrar “Era uma vez Tito” → repita 3 vezes: mostrar “toc” → mostrar “Tito abriu a porta”.
| Tela do programa |
| Era uma vez Tito |
| toc |
| toc |
| toc |
| Tito abriu a porta |

**Roteiro:** toda história tem **começo** (quem é o personagem), **meio** (o que acontece) e **fim** (como termina).
### 📖 O que significa?
- **Cena**: cada parte da história; aqui, cada linha da tela.
- **Personagem**: quem vive a história.
- **Roteiro**: o plano da história: começo, meio e fim.
- **Animação**: imagens ou textos que mudam e contam algo.
### 🌎 Onde eu uso isso?
- Nos **desenhos animados**: cada cena vem depois da outra.
- Nas **histórias em quadrinhos**.
- Nos **jogos com história**, em que o nome do herói aparece em várias falas.
### 🎯 Missão
🟢 **Básico** — no editor: monte a história do Tito, use a variável heroi e coloque o roteiro em ordem.
🟡 **Desafio** — no editor: troque o herói e a história muda sozinha.
🔴 **Turbo** — no editor: a contagem do foguete na história.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Cada linha da tela pode ser uma cena da história.
2. ( ) O repita serve para repetir “toc” várias vezes.
3. ( ) Mudando a variável heroi, o nome muda em todas as cenas.
4. ( ) O roteiro tem começo, meio e fim.
5. ( ) Uma história não pode ter repetição.
### 🧠 Resumo da Aula
Um programa pode contar uma história: cada linha é uma **cena**. **Sequência** = uma cena depois da outra; **repita** = o que se repete; variável **heroi** = o nome em todas as cenas. O **roteiro** tem **começo**, **meio** e **fim**.
**Palavras-chave:** cena · personagem · roteiro · animação
