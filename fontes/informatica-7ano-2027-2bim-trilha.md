## 🕸️ Missão 1 – Grafos: pontos e ligações
**Objetivo:** saber o que é um grafo: pontos ligados por linhas.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Um **grafo** é um desenho de **pontos ligados por linhas**. O computador guarda mapas assim.
| Parte do grafo | O que é | Exemplo no mapa da cidade |
| ⚪ Vértice | Um ponto: um lugar | A escola, a praça |
| ➖ Aresta | A linha que liga dois pontos | A rua |
| 🔢 Peso | O número na linha | 5 minutos |
| 🔗 Grau | Quantas linhas chegam ao ponto | A praça tem grau 2 |

### 📖 O que significa?
- **Grafo**: pontos ligados por linhas.
- **Vértice**: cada ponto.
- **Aresta**: cada linha.
- **Peso**: o número escrito na linha.
- **Aplicativo**: programa do celular ou do computador.
### 🌎 Onde eu uso isso?
- No **mapa** do celular: as esquinas são pontos e as ruas são linhas.
- Na **rede de computadores** da escola.
### ✅ Perguntas rápidas
1. ( ) Um grafo tem pontos (vértices) e linhas (arestas).
2. ( ) No mapa, as ruas são os vértices.
3. ( ) O peso é o número escrito na linha.
### 🧠 Resumo da Aula
Um **grafo** tem **vértices** (pontos) e **arestas** (linhas). O **peso** é o número da linha. O **grau** é quantas linhas chegam a um ponto.
**Palavras-chave:** grafo · vértice · aresta · peso · grau

## 🧭 Missão 2 – O caminho mais curto
**Objetivo:** achar o caminho mais curto somando os números.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Para saber quanto um caminho leva, **somamos** os números (pesos) das linhas.
| Caminho | Conta | Total |
| Casa → Escola (rua direta) | 9 | **9 minutos** |
| Casa → Padaria → Escola | 3 + 2 | **5 minutos** ✅ |
| Casa → Praça → Escola | 4 + 4 | **8 minutos** |

O **mais curto** é o de **menor soma**. O aplicativo de mapa faz essa conta.
### 📖 O que significa?
- **Caminho**: os pontos por onde eu passo, um depois do outro.
- **Caminho mais curto**: o de menor soma.
- **Somar**: juntar os números (3 + 2 = 5).
### 🌎 Onde eu uso isso?
- O **aplicativo de mapa** mostra o caminho mais rápido.
- O **entregador** escolhe o caminho mais curto.
### ✅ Perguntas rápidas
1. ( ) Para saber o total do caminho, somamos os números.
2. ( ) O caminho mais curto é o de maior soma.
3. ( ) Casa → Padaria → Escola leva 5 minutos.
### 🧠 Resumo da Aula
Some os números de cada caminho. O **caminho mais curto** é o de **menor soma**.
**Palavras-chave:** caminho · caminho mais curto · somar

## 🤝 Missão 3 – Grafos de amizades
**Objetivo:** ver amizades como um grafo.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Num grafo de amizades, cada **pessoa** é um ponto e cada **amizade** é uma linha.
| Pessoa | Amigos | Grau |
| Ana | Bia, Caio, Davi | 3 |
| Bia | Ana, Caio | 2 |
| Eva | Davi | 1 |

A **Ana** tem mais amigos: o grau dela é **3**.
A rede social sugere os **amigos dos seus amigos**. Mas **só aceite quem você conhece de verdade**.
### 📖 O que significa?
- **Rede social**: um grafo de pessoas.
- **Grau**: quantos amigos a pessoa tem no grafo.
- **Amigo em comum**: amigo de duas pessoas ao mesmo tempo.
### 🌎 Onde eu uso isso?
- Nas **redes sociais**: “pessoas que você talvez conheça”.
- No **grupo da turma** no celular.
### ✅ Perguntas rápidas
1. ( ) Num grafo de amizades, cada pessoa é um ponto.
2. ( ) A Eva tem mais amigos que a Ana.
3. ( ) Só devo aceitar quem eu conheço de verdade.
### 🧠 Resumo da Aula
Pessoas são pontos e amizades são linhas. O **grau** mostra quantos amigos cada um tem. A rede sugere amigos dos amigos: aceite só quem você conhece.
**Palavras-chave:** rede social · grau · amigo em comum

## 🗂️ Missão 4 – Escolher a estrutura certa
**Objetivo:** escolher entre lista, tabela e grafo.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Existem jeitos diferentes de guardar dados:
| Estrutura | Como é | Serve para | Exemplo |
| 📝 Lista | Itens em ordem | Coisas em sequência | Fila da cantina |
| 🗂️ Tabela | Linhas e colunas | Várias informações de cada item | Boletim |
| 🕸️ Grafo | Pontos e linhas | Ligações | Mapa da cidade |

### 📖 O que significa?
- **Lista**: itens em ordem.
- **Tabela**: linhas e colunas.
- **Grafo**: pontos ligados por linhas.
### 🌎 Onde eu uso isso?
- A **playlist** é uma lista.
- Os **contatos** do celular são uma tabela.
### ✅ Perguntas rápidas
1. ( ) A fila da cantina é uma lista.
2. ( ) O mapa da cidade é melhor guardado numa lista.
3. ( ) O boletim é uma tabela.
### 🧠 Resumo da Aula
**Lista** = ordem. **Tabela** = várias informações. **Grafo** = ligações.
**Palavras-chave:** lista · tabela · grafo

## 📋 Missão 5 – Projeto em equipe: planejar
**Objetivo:** planejar um projeto com a equipe.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
A turma vai fazer o **Guia de Rotas da Escola** em equipe. Primeiro, o **plano**:
| Etapa | Pergunta |
| 1. Problema | O que queremos resolver? |
| 2. Ideia | Como vamos resolver? |
| 3. Tarefas | Quem faz o quê? |

Cada pessoa tem um **papel**:
| Papel | O que faz |
| 🔎 Pesquisador | Junta os dados |
| 🛠️ Construtor | Monta o grafo |
| 🧪 Testador | Confere se está certo |

Combinados: **ouvir todos** e **ajudar quem travou**.
### 📖 O que significa?
- **Projeto**: trabalho com um objetivo e um prazo.
- **Papel**: a tarefa de cada pessoa na equipe.
- **Prazo**: até quando terminar.
### 🌎 Onde eu uso isso?
- No **trabalho em grupo** da escola.
- Na **festa junina**: cada equipe cuida de uma parte.
### ✅ Perguntas rápidas
1. ( ) Todo projeto começa com um plano.
2. ( ) Na equipe, uma pessoa faz tudo sozinha.
3. ( ) O testador confere se está certo.
### 🧠 Resumo da Aula
O **plano** tem problema, ideia e tarefas. Cada pessoa tem um **papel**. A equipe ouve todos e se ajuda.
**Palavras-chave:** projeto · plano · papel · prazo

📅 **Data da aula:** ........ / ........

- Na **feira de ciências**, as equipes apresentam os projetos.
### ✅ Perguntas rápidas
1. ( ) Depois de construir, a equipe testa.
2. ( ) Testar não serve para nada.
3. ( ) Na apresentação, a equipe mostra o que fez.
### 🧠 Resumo da Aula
**Construir**, **testar** e **melhorar**. No fim, **apresentar** o projeto.
**Palavras-chave:** construir · testar · melhorar · apresentar

## 🗺️ Missão 7 – Extra: Mapa de Curionópolis em grafo
**Objetivo:** transformar lugares da cidade num grafo.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Lugares de **Curionópolis** viram pontos. Os tempos são **de mentirinha**, só para o exercício.
| Aresta | Peso (minutos de caminhada) |
| Escola – Praça | 6 |
| Escola – Feira | 9 |
| Feira – Rodoviária | 5 |

**Escola → Feira → Rodoviária** = 9 + 5 = **14 minutos**.
### 📖 O que significa?
- **Lugar**: vira um ponto (vértice).
- **Rua**: vira uma linha (aresta).
- **Tempo**: vira o número (peso).
### 🌎 Onde eu uso isso?
- Para explicar a um **visitante** como chegar à escola.
- O **mototáxi** escolhe o caminho mais rápido.
### ✅ Perguntas rápidas
1. ( ) Cada lugar da cidade vira um ponto do grafo.
2. ( ) Cada rua vira uma linha.
3. ( ) Escola → Feira → Rodoviária leva 20 minutos.
### 🧠 Resumo da Aula
Lugar = ponto. Rua = linha. Tempo = número. Assim a cidade vira um grafo.
**Palavras-chave:** lugar · rua · tempo · grafo

## 🌀 Missão 8 – Extra: Labirintos
**Objetivo:** sair de um labirinto com uma estratégia.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Um **labirinto** tem corredores e **becos sem saída**.
| No labirinto | No grafo |
| Cruzamento | Ponto onde dá para escolher |
| Beco sem saída | Ponto sem continuação |
| Corredor | Linha |

**Estratégia “tentar e voltar”:** se chegar num beco sem saída, **volte** e tente outro caminho.
### 📖 O que significa?
- **Labirinto**: lugar com muitos corredores.
- **Beco sem saída**: corredor que não continua.
- **Voltar**: retornar ao último cruzamento.
### 🌎 Onde eu uso isso?
- Nos **jogos** de labirinto.
- O **robô aspirador** precisa achar o caminho pela casa.
### ✅ Perguntas rápidas
1. ( ) Um labirinto tem becos sem saída.
2. ( ) No beco sem saída, eu volto e tento outro caminho.
3. ( ) Todo corredor leva até a saída.
### 🧠 Resumo da Aula
O labirinto tem **cruzamentos**, **corredores** e **becos sem saída**. Chegou num beco? **Volte** e tente outro caminho.
**Palavras-chave:** labirinto · beco sem saída · voltar
