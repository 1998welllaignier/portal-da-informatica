### 💡 Para começar
O **papel de parede** (o Windows chama de **tela de fundo** ou **plano de fundo da área de trabalho**) é a imagem que fica atrás dos ícones da área de trabalho.
Muita gente procura uma imagem na internet, baixa, consegue ver no navegador… mas o Windows **não deixa** colocar como papel de parede. Por quê? Por causa do **formato** da imagem!
**Passo 1: qual é o meu Windows?** Os passos mudam um pouco entre o Windows 10 e o Windows 11. Primeiro, descubra qual é o seu.
| Jeito | Como fazer | O que aparece |
| ⚡ Rápido: a barra de tarefas | Olhe onde fica o botão **Iniciar** (o ⊞, a “janelinha”) | **No centro** da barra: Windows 11 · **No canto esquerdo**: Windows 10 |
| ✅ Certo: as Configurações | ⚙️ **Configurações › Sistema › Sobre** | Em “Especificações do Windows”, a **Edição** diz: Windows 10 ou Windows 11 |
| ⌨️ Atalho: a janela Executar | Aperte a tecla **⊞ + R**, digite **winver** e aperte **Enter** | A janela **Sobre o Windows** mostra a versão |

**Atenção:** o jeito rápido não é 100% garantido, porque no Windows 11 dá para mudar o botão Iniciar para a esquerda. Na dúvida, confira em **Configurações › Sistema › Sobre** ou com o **winver**.
**Passo 2: os formatos que o papel de parede aceita.** O formato é o final do nome do arquivo, depois do ponto (a **extensão**).
| Formato | Serve como papel de parede? | Onde aparece |
| .jpg / .jpeg | ✅ Aceita | Fotos do celular, da câmera e do WhatsApp |
| .png | ✅ Aceita | Desenhos, prints da tela, imagens com fundo transparente |
| .bmp, .gif, .tif | ✅ Aceita | Formatos mais antigos |
| .webp | ❌ Não aceita (Windows 10 e Windows 11 comum) | Muitas imagens baixadas de sites |
| .jxl 🆕 | ❌ Não aceita | O “novo JPEG”, de 2026 |

**Por que tantos sites usam .webp?** O **WebP** deixa a imagem **bem menor**, e o site abre mais rápido. O navegador abre .webp sem problema. O papel de parede do Windows é que ainda não aceita (a Microsoft está testando isso numa versão de teste do Windows 11, que ainda não chegou para todos).
**Passo 3: como descobrir o formato da imagem baixada.**
| Onde | Como ver |
| 📁 Explorador de Arquivos › Downloads | A coluna **Tipo** mostra, por exemplo, “Arquivo WEBP” |
| Ligar as extensões (Windows 10) | Explorador › aba **Exibir** › marcar **Extensões de nomes de arquivos** |
| Ligar as extensões (Windows 11) | Explorador › **Exibir › Mostrar › Extensões de nomes de arquivos** |
| Na hora de salvar | Na janela **Salvar como**, o campo **Tipo** mostra o formato |

**Passo 4: converter no Paint e colocar como papel de parede.**
| Passo | O que fazer |
| 1 | No Explorador de Arquivos, clique com o **botão direito** na imagem .webp › **Abrir com › Paint** |
| 2 | No Paint: **Arquivo › Salvar como › Imagem PNG** (ou **Imagem JPEG**) |
| 3 | Escolha a pasta, confira o nome e clique em **Salvar**. Agora existe uma cópia em **.png** |
| 4 | Clique com o **botão direito** na imagem **.png** › **Definir como plano de fundo da área de trabalho** |

**Cuidado:** só trocar o final do nome (renomear de .webp para .png) **não converte** a imagem: por dentro ela continua sendo .webp e o Windows não aceita. Converter é **salvar de novo em outro formato**, como no Paint.
Outro caminho para o passo 4: ⚙️ **Configurações › Personalização › Tela de fundo** › **Procurar** (Windows 10) ou **Procurar fotos** (Windows 11) › escolha a imagem .png ou .jpg. Nessa janela, a imagem .webp **nem aparece**, porque ela só mostra os formatos aceitos!
### 📖 O que significa?
- **Papel de parede**: a imagem atrás dos ícones da área de trabalho. O Windows chama de **tela de fundo** ou **plano de fundo da área de trabalho**.
- **Formato** (de imagem): o jeito como a imagem foi guardada no arquivo. Aparece na **extensão**, o final do nome depois do ponto (.jpg, .png, .webp).
- **JPG** (ou **JPEG**): sigla em inglês de *Joint Photographic Experts Group* (Grupo Conjunto de Especialistas em Fotografia), o grupo que criou esse formato de foto. É o formato mais usado em fotos.
- **PNG**: sigla em inglês de *Portable Network Graphics* (Gráficos Portáteis para Rede). Guarda a imagem sem perder qualidade e aceita fundo transparente.
- **WebP**: formato criado pelo Google para imagens de sites. *Web* quer dizer “rede”, a internet, e o *P* vem de *picture* (imagem). Deixa a imagem bem menor, mas o papel de parede do Windows não aceita.
- **Converter**: transformar um arquivo de um formato em outro, como de .webp para .png.
- **Paint**: o programa de desenho que já vem no Windows. Ele abre imagens .webp e salva em .png ou .jpg.
- **winver**: comando do Windows (de *Windows version*, versão do Windows) que abre a janela **Sobre o Windows**.
- **Executar**: a janela que abre com **⊞ + R**, onde digitamos o nome de um comando, como winver.
### 🌎 Onde eu uso isso?
- Para colocar a foto do **time**, do **jogo** ou da **família** no papel de parede do computador.
- Quando um site ou programa diz **“formato não suportado”**: é só converter para .png ou .jpg.
- Quando alguém pergunta **“que Windows é esse?”**, por exemplo para instalar um jogo ou programa que pede Windows 10 ou 11.
### 🎯 Missão
Descobrir qual Windows está no simulador, baixar a imagem do estádio, descobrir o formato dela, converter no Paint e colocar como papel de parede.
### ✅ Perguntas rápidas
1. ( ) No Windows 11, o botão Iniciar normalmente fica no centro da barra de tarefas.
2. ( ) O papel de parede do Windows aceita imagens .webp sem problema.
3. ( ) O comando winver mostra qual é a versão do Windows.
4. ( ) No Paint, dá para salvar uma imagem .webp como Imagem PNG.
5. ( ) Se eu só mudar o nome do arquivo de .webp para .png, a imagem é convertida.
### 🧠 Resumo da Aula
Primeiro descubra o seu Windows: o botão **Iniciar no centro** é Windows 11, **no canto esquerdo** é Windows 10 (para ter certeza: **Configurações › Sistema › Sobre** ou **⊞ + R › winver**). O papel de parede aceita **.jpg, .png, .bmp, .gif e .tif**, mas **não aceita .webp** (nem .jxl). Para resolver: abra a imagem no **Paint › Arquivo › Salvar como › Imagem PNG** e depois clique com o botão direito na imagem nova › **Definir como plano de fundo da área de trabalho**.
