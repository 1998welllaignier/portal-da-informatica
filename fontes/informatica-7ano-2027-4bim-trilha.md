## ♻️ Missão 1 – Descarte e meio ambiente
**Objetivo:** saber onde jogar o celular e as pilhas velhas.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
| Destino | O que acontece |
| 🗑️ Lixo comum | **Contamina** a terra e a água |
| 🔥 Queimar | Solta **fumaça** que faz mal |
| ♻️ Ponto de coleta | Vai para a **reciclagem** |

O lugar certo é o **ponto de coleta**. Lixo comum e fogo: errado. Antes de doar o celular, apago os meus dados.
### 📖 O que significa?
- **Lixo eletrônico**: aparelhos jogados fora, como celular e pilha.
- **Ponto de coleta**: lugar que recebe aparelhos velhos para reciclar.
- **Reciclagem**: usar o material de novo.
### 🌎 Onde eu uso isso?
- Com o **celular quebrado** da família.
- Com as **pilhas gastas**.
### ✅ Perguntas rápidas
1. ( ) Pilha no lixo comum contamina a terra.
2. ( ) O lugar certo é o ponto de coleta.
3. ( ) Queimar fios é seguro.
### 🧠 Resumo da Aula
Lixo eletrônico vai para o **ponto de coleta**, não para o lixo comum nem para o fogo. Lá vira **reciclagem**.
**Palavras-chave:** lixo eletrônico · ponto de coleta · reciclagem

## 📱 Missão 2 – Dentro do celular: metais e reciclagem
**Objetivo:** saber o que tem dentro do celular.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
| Parte do celular | Material | Para que serve |
| 🔋 Bateria | **Lítio** | Guardar a energia |
| 🧩 Placa | **Cobre** e **ouro** | Levar a eletricidade |
| 📱 Tela | **Vidro** | Mostrar a imagem |

**Cuidado:** bateria **estufada** (inchada) pode **pegar fogo**. Não furo. Levo ao ponto de coleta.
### 📖 O que significa?
- **Metal**: material como o cobre e o ouro.
- **Bateria estufada**: bateria inchada, perigosa.
### 🌎 Onde eu uso isso?
- Quando a **bateria** do celular incha.
- Quando a família **troca de celular**.
### ✅ Perguntas rápidas
1. ( ) A bateria usa lítio.
2. ( ) A placa tem cobre e ouro.
3. ( ) Posso furar a bateria estufada.
### 🧠 Resumo da Aula
Dentro do celular: **lítio** (bateria), **cobre** e **ouro** (placa), **vidro** (tela). Bateria **estufada**: não fure, leve ao ponto de coleta.
**Palavras-chave:** metal · bateria estufada

## 📝 Missão 3 – Produto digital: o roteiro
**Objetivo:** ajudar a equipe a planejar um vídeo curto.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
O **roteiro** é o plano do vídeo, cena por cena.
| Cena | O que aparece | O que se fala | ⏱️ Tempo |
| 1 – Abertura | Celular velho | “Você tem um desses?” | 10 s |
| 2 – Problema | Lixão | “No lixo, ele polui.” | 20 s |
| 3 – Solução | Ponto de coleta | “Leve ao ponto de coleta!” | 20 s |

Para filmar o rosto de alguém, **peça autorização**.
### 📖 O que significa?
- **Roteiro**: o plano do vídeo, cena por cena.
- **Cena**: uma parte do vídeo.
### 🌎 Onde eu uso isso?
- Nos **vídeos** da escola.
- Os **filmes** começam por um roteiro.
### ✅ Perguntas rápidas
1. ( ) O roteiro é o plano do vídeo.
2. ( ) O vídeo tem cenas.
3. ( ) Filmo o rosto do colega sem pedir.
### 🧠 Resumo da Aula
O **roteiro** organiza as **cenas**: abertura, problema, solução. Rosto de alguém, só com **autorização**.
**Palavras-chave:** roteiro · cena

📅 **Data da aula:** ........ / ........

- Em **vídeos** de aniversário.

### ✅ Perguntas rápidas

3. ( ) Lugar barulhento é melhor para gravar.
### 🧠 Resumo da Aula
Grave com o celular **deitado**, **luz** de frente e lugar **silencioso**. No **editor**: ordenar, cortar e **exportar**.
**Palavras-chave:** editor · exportar

## 📒 Missão 5 – Documentar e publicar
**Objetivo:** colocar os créditos e publicar com segurança.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
| Parte da ficha técnica | Exemplo |
| 🎬 Título | “Celular no lixo? Não!” |
| 👥 Equipe | Só o primeiro nome |
| 📚 Créditos | Quem fez a música |

**Antes de publicar:** todos **autorizaram**? Não tem **endereço** nem **telefone**? Então pode. Não coloco o telefone de ninguém no vídeo.
### 📖 O que significa?
- **Créditos**: os nomes de quem fez.
- **Publicar**: deixar outras pessoas verem.
### 🌎 Onde eu uso isso?
- Nos **créditos** do fim dos filmes.
- Ao postar um **trabalho**.
### ✅ Perguntas rápidas
1. ( ) A ficha técnica tem os créditos.
2. ( ) Antes de publicar, todos precisam autorizar.
3. ( ) Coloco o telefone de um colega no vídeo.
### 🧠 Resumo da Aula
A ficha técnica tem título, equipe e **créditos**. Para **publicar**: autorização e nada de endereço ou telefone.
**Palavras-chave:** créditos · publicar

## 🖼️ Missão 7 – Extra: Fotos e sons viram dados
**Objetivo:** saber que a foto é feita de pontinhos.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
A foto é feita de **pixels**: quadradinhos de cor.
| Cor | R (vermelho) | G (verde) | B (azul) |
| ⬛ Preto | 0 | 0 | 0 |
| ⬜ Branco | 255 | 255 | 255 |

Mais pixels = foto com **mais detalhes**.
### 📖 O que significa?
- **Pixel**: quadradinho de cor da foto.
- **Zoom**: aumentar a imagem.
### 🌎 Onde eu uso isso?
- Na **câmera** do celular.
- Ao dar **zoom** numa foto.
### ✅ Perguntas rápidas
1. ( ) A foto é feita de pixels.
2. ( ) Mais pixels, mais detalhes.
3. ( ) O preto é 255, 255, 255.
### 🧠 Resumo da Aula
A foto é feita de **pixels**. Preto é 0, 0, 0; branco é 255, 255, 255. No **zoom**, aparecem os quadradinhos.
**Palavras-chave:** pixel · zoom

## 🌐 Missão 8 – Extra: Um site simples
**Objetivo:** conhecer as tags do HTML.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
As páginas da internet são escritas em **HTML**.
| Tag | Para que serve | Exemplo |
| <h1> | Título | <h1>Recicle!</h1> |
| <p> | Texto | <p>Pilha no ponto de coleta.</p> |
| <a> | Link | <a href="mais.html">Mais</a> |

### 📖 O que significa?
- **HTML**: a linguagem das páginas da internet.
- **Tag**: etiqueta do HTML, como <p>.
- **Link**: texto que abre outra página.
### 🌎 Onde eu uso isso?
- Em **todo site** que você abre.
- Na **página da equipe**.
### ✅ Perguntas rápidas
1. ( ) As páginas são escritas em HTML.
2. ( ) A tag <h1> faz um título.
3. ( ) A tag <a> faz uma imagem.
### 🧠 Resumo da Aula
**HTML** usa **tags**: <h1> título, <p> texto, <a> **link**.
**Palavras-chave:** HTML · tag · link
