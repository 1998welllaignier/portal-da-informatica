## 🪪 Missão 1 – Dados pessoais
**Objetivo:** reconhecer quais informações são dados pessoais e por que protegê-las.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Dado pessoal** é qualquer informação que **identifica** uma pessoa ou que, junto com outras, permite **descobrir quem ela é**.
| Dado pessoal | Exemplo |
| 🧑 Nome completo | Ana Souza Lima |
| 🏠 Endereço | Rua das Flores, 10 |
| 📞 Telefone | (94) 9 ••••-•••• |
| 🎂 Data de nascimento | 05/03/2013 |
| 🪪 Documentos | CPF, RG |
| 📸 Foto do rosto | A sua selfie |
| 📍 Localização | Onde você está agora |

**Juntos, revelam mais:** sozinho, “gosta de futebol” não diz quem você é. Mas “estuda na escola tal + 8º ano + joga no time do bairro + mora perto da praça” pode **identificar** você.
**Por que proteger?** Com os seus dados, um golpista pode **fingir ser você**, **descobrir onde você mora** ou criar **golpes mais convincentes**.
**Regra prática:** antes de informar um dado, pergunte: **quem está pedindo? Para quê? Precisa mesmo?**
### 📖 O que significa?
- **Dado pessoal**: informação que identifica uma pessoa.
- **Identificar**: descobrir quem é a pessoa.
- **CPF**: Cadastro de Pessoas Físicas, o número de identificação de cada pessoa no Brasil.
- **Golpista**: quem engana para tirar vantagem.
- **Privacidade**: o direito de decidir o que os outros sabem sobre você.
### 🌎 Onde eu uso isso?
- Ao preencher um **cadastro** num site ou numa promoção.
- Ao postar uma **foto** com o uniforme ou a fachada da casa.
- Quando alguém desconhecido pede o seu **telefone** num jogo.
### 🎯 Missão
🟢 **Básico** — no portal: separe o que é dado pessoal, marque o que pode identificar alguém e responda as três perguntas antes de informar um dado.
🟡 **Desafio** — no portal: o cadastro da promoção: o que ele precisa mesmo?
🔴 **Turbo** — no portal: jogo da memória dos dados pessoais.
⚠️ Os computadores são usados por todos: **nunca apague nem mexa nos arquivos dos colegas**.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Dado pessoal é uma informação que identifica uma pessoa.
2. ( ) A localização é um dado pessoal.
3. ( ) Informações soltas nunca identificam ninguém, nem juntas.
4. ( ) Antes de informar um dado, vale perguntar quem pede e para quê.
5. ( ) O CPF não é um dado pessoal.
### 🧠 Resumo da Aula
**Dado pessoal** identifica a pessoa: nome, endereço, telefone, data de nascimento, **documentos** (CPF, RG), **foto** e **localização**. Informações soltas, **juntas**, podem identificar. Proteja: **quem pede? para quê? precisa mesmo?**
**Palavras-chave:** dado pessoal · identificar · CPF · golpista · privacidade

## 🔐 Missão 2 – Dados sensíveis e LGPD
**Objetivo:** reconhecer os dados sensíveis e conhecer os direitos que a LGPD garante.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Alguns dados pessoais são ainda mais delicados: os **dados sensíveis**. Se forem expostos, podem levar a **discriminação** (tratar alguém de forma injusta).
| Dado sensível (exemplos da lei) | Exemplo |
| 🏥 Saúde | Uma doença, um remédio que a pessoa toma |
| 🙏 Religião | A religião da pessoa |
| 🗳️ Opinião política | Em quem a pessoa votou |
| 🌍 Origem racial ou étnica | A cor da pele, a etnia |
| 👆 Biometria | A digital, o rosto usado para desbloquear |
| 🧬 Dado genético | O DNA |

**A LGPD** (Lei Geral de Proteção de Dados, Lei nº 13.709/2018) diz que as empresas e o governo precisam **cuidar** dos dados, e dá direitos a você:
| Direito | O que você pode pedir |
| 👀 Saber | Quais dados a empresa tem sobre você |
| ✏️ Corrigir | Arrumar um dado errado |
| 🗑️ Apagar | Excluir dados que não são mais necessários |
| ↩️ Retirar o consentimento | Desistir da autorização que deu |

Quem fiscaliza a LGPD é a **ANPD** (Autoridade Nacional de Proteção de Dados). Para dados de **crianças**, a lei exige a autorização de um dos **pais ou responsáveis**.
**Um aplicativo pediu um dado sensível que não precisa?** Não informa e conversa com um adulto.
### 📖 O que significa?
- **Dado sensível**: dado pessoal mais delicado, como saúde, religião ou biometria.
- **Discriminação**: tratar alguém de forma injusta por causa de quem ele é.
- **Biometria**: características do corpo usadas para identificar, como a digital e o rosto.
- **LGPD**: lei que protege os dados pessoais no Brasil.
- **Consentimento**: a sua autorização para usarem os seus dados.
- **ANPD**: o órgão que fiscaliza a LGPD.
- **Aplicativo**: programa do celular ou do computador.
### 🌎 Onde eu uso isso?
- Ao **desbloquear o celular** com a digital ou o rosto.
- Numa **ficha médica** da escola ou do posto de saúde.
- Quando um aplicativo pede para **usar os seus dados**.
### 🎯 Missão
🟢 **Básico** — no portal: separe dados pessoais comuns e sensíveis, ligue cada direito da LGPD ao que ele permite e responda sobre a ANPD.
🟡 **Desafio** — no portal: o aplicativo de jogos pediu dados de saúde: e agora?
🔴 **Turbo** — no portal: complete o texto da LGPD.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Dados de saúde são dados sensíveis.
2. ( ) A digital usada para desbloquear o celular é biometria.
3. ( ) Pela LGPD, você não pode pedir para apagar os seus dados.
4. ( ) A ANPD fiscaliza a LGPD.
5. ( ) Dados sensíveis expostos podem levar a discriminação.
### 🧠 Resumo da Aula
**Dados sensíveis** são os mais delicados: **saúde**, **religião**, **opinião política**, **origem racial ou étnica**, **biometria** e **dado genético**. A **LGPD** dá os direitos de **saber**, **corrigir**, **apagar** e **retirar o consentimento**; quem fiscaliza é a **ANPD**.
**Palavras-chave:** dado sensível · discriminação · biometria · LGPD · consentimento · ANPD

## 🛡️ Missão 3 – Segurança das contas
**Objetivo:** proteger as contas com hábitos simples.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
| Hábito | Por quê |
| 🔑 Senha forte e **diferente** em cada conta importante | Se uma vazar, as outras continuam seguras |
| 📲 **Verificação em duas etapas** | Mesmo com a senha, ninguém entra sem o código |
| 🚪 **Sair da conta** em computador compartilhado | O próximo não entra na sua conta |
| 📧 E-mail e telefone de **recuperação** atualizados | Se perder o acesso, você consegue voltar |
| 🔔 Ler os **alertas de login** | “Novo acesso de outro aparelho” pode ser invasão |
| 🙅 Nunca passar senha ou código | Nem para o melhor amigo |

**Recebi um alerta de acesso que não fui eu. E agora?** 1) **Troque a senha**; 2) **Saia de todos os aparelhos** (a opção existe nas configurações de muitas contas); 3) **Ative as duas etapas**; 4) **Avise um adulto**.
### 📖 O que significa?
- **Conta**: o seu cadastro num serviço (e-mail, jogo, rede social).
- **Login**: entrar na conta com usuário e senha.
- **Recuperação de conta**: o jeito de voltar a entrar quando perde a senha.
- **Alerta de login**: aviso de que alguém entrou na conta.
- **Invasão**: quando outra pessoa entra na sua conta sem permissão.
### 🌎 Onde eu uso isso?
- No **computador da escola**: sair da conta no fim da aula.
- No **e-mail** que chega avisando um acesso novo.
- Ao criar a conta de um **jogo**.
### 🎯 Missão
🟢 **Básico** — no portal: ligue cada hábito ao seu motivo, marque o que protege a conta e coloque em ordem o que fazer depois de um alerta.
🟡 **Desafio** — no portal: os alertas da semana: fui eu ou é invasão?
🔴 **Turbo** — no portal: caça-palavras da segurança.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Usar a mesma senha em tudo é seguro.
2. ( ) No computador da escola, preciso sair da conta no fim da aula.
3. ( ) Alerta de login de um aparelho desconhecido pode ser invasão.
4. ( ) Posso passar o código da verificação para um amigo.
5. ( ) E-mail de recuperação ajuda a voltar a entrar na conta.
### 🧠 Resumo da Aula
Hábitos: **senha forte e diferente**, **duas etapas**, **sair da conta** em computador compartilhado, **recuperação** atualizada, ler os **alertas de login** e nunca passar senha ou código. Alerta estranho: **troque a senha**, **saia de todos os aparelhos**, ative as **duas etapas** e **avise um adulto**.
**Palavras-chave:** conta · login · recuperação de conta · alerta de login · invasão

## ⚙️ Missão 4 – Configurar a privacidade
**Objetivo:** escolher quem vê o quê nas redes sociais e nos aplicativos.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
Quase todo aplicativo tem um menu de **privacidade** (em **Configurações**). Lá você escolhe **quem vê o quê**.
| Configuração | Opção mais protegida |
| 👤 Conta | **Privada**: só quem você aceita vê os posts |
| 🏷️ Quem pode marcar você | **Só quem você segue** ou ninguém |
| 💬 Quem pode mandar mensagem | **Só amigos** |
| 📍 Localização nos posts | **Desligada** |
| 🔎 Aparecer em buscas pelo telefone | **Desligado** |
| 🟢 Mostrar quando está on-line | **Desligado** |

**Revise de vez em quando:** os aplicativos mudam as configurações nas atualizações. Uma vez por mês, dê uma olhada.
**Bloquear e silenciar:** **bloquear** impede a pessoa de ver você e mandar mensagem; **silenciar** só para de mostrar os posts dela para você.
### 📖 O que significa?
- **Configurações de privacidade**: o menu em que você escolhe quem vê os seus dados e posts.
- **Conta privada**: só as pessoas aceitas veem os posts.
- **Marcar**: colocar o nome de alguém num post.
- **Bloquear**: impedir que uma pessoa veja você e fale com você.
- **Silenciar**: parar de ver os posts de alguém, sem que a pessoa saiba.
- **Aplicativo**: programa do celular ou do computador.
### 🌎 Onde eu uso isso?
- Ao criar uma **conta nova** numa rede social.
- Quando um **desconhecido** começa a mandar mensagens.
- Depois de uma **atualização** do aplicativo.
### 🎯 Missão
🟢 **Básico** — no portal: escolha a opção mais protegida de cada configuração, ligue cada termo ao seu significado e responda: bloquear ou silenciar?
🟡 **Desafio** — no portal: configure a conta da Júlia.
🔴 **Turbo** — no portal: coloque em ordem a revisão da privacidade.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Na conta privada, só quem você aceita vê os posts.
2. ( ) Localização nos posts ligada é a opção mais protegida.
3. ( ) Bloquear impede a pessoa de mandar mensagem.
4. ( ) As atualizações podem mudar as configurações.
5. ( ) Silenciar avisa a pessoa que você silenciou.
### 🧠 Resumo da Aula
Em **Configurações de privacidade**, escolha: conta **privada**, marcações e mensagens **só de quem você aceita**, **localização desligada**, não aparecer na busca pelo telefone. **Revise** depois das atualizações. **Bloquear** impede contato; **silenciar** só esconde os posts.
**Palavras-chave:** configurações de privacidade · conta privada · marcar · bloquear · silenciar

1. ( ) Uma dica por slide fica mais fácil de lembrar.
2. ( ) O critério “Seguro” confere se o guia não mostra dados pessoais reais.
3. ( ) Feedback bom é só criticar.
4. ( ) Rubrica é a lista do que vai ser avaliado.
5. ( ) Passar muito do tempo ajuda as outras equipes.
### 🧠 Resumo da Aula
Apresente com **uma dica por parte**, **imagens**, **exemplos inventados** e no **tempo**. A **rubrica** tem os **critérios**: correto, para o público, seguro, atraente e equipe. **Feedback**: algo bom + uma sugestão.
**Palavras-chave:** rubrica · critério · feedback · atraente

## 📍 Missão 7 – Extra: Localização e rastreamento
**Objetivo:** perceber como a localização é registrada e controlar quem sabe onde você está.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
O celular sabe onde você está pelo **GPS**, pelo **Wi-Fi** e pelas **antenas** da operadora. Essa localização pode aparecer em vários lugares:
| Onde aparece | Risco | Como proteger |
| 📸 Dentro da foto (nos **metadados**) | Quem recebe o arquivo pode ver onde foi tirada | Desligar a localização da câmera |
| 📍 Localização em tempo real | Mostra onde você está **agora** | Compartilhar só com a família |
| 🗺️ Histórico de localização | Mostra todos os lugares por onde passou | Desligar ou apagar o histórico |
| 🏷️ Check-in num post | Diz onde você está e que não está em casa | Postar depois de sair do lugar |

**Rastreamento** também acontece nos sites: **cookies** e outros rastreadores registram o que você vê para mostrar propaganda.
### 📖 O que significa?
- **GPS**: sistema de satélites que mostra a posição de um aparelho.
- **Metadados**: informações escondidas dentro de um arquivo (data, aparelho, local).
- **Localização em tempo real**: mostrar no mapa onde você está naquele momento.
- **Histórico de localização**: a lista dos lugares por onde o celular passou.
- **Check-in**: marcar num post o lugar onde você está.
- **Rastreamento**: registrar o que alguém faz ou por onde anda.
- **Cookies**: pequenos arquivos que os sites guardam no navegador para lembrar de você.
- **Wi-Fi**: internet sem fio.
- **Aplicativo**: programa do celular ou do computador.
### 🌎 Onde eu uso isso?
- Ao **tirar e mandar fotos** pelo celular.
- No **aplicativo de mapa**.
- Ao **postar** de um passeio.
### 🎯 Missão
🟢 **Básico** — no portal: ligue cada lugar onde a localização aparece ao seu risco, marque o que protege e responda sobre os metadados.
🟡 **Desafio** — no portal: o passeio da Bia: postar agora ou depois?
🔴 **Turbo** — no portal: complete o texto da localização.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) A foto pode guardar nos metadados o lugar onde foi tirada.
2. ( ) Localização em tempo real mostra onde você está agora.
3. ( ) Check-in num post diz para todos onde você está.

## 🎣 Missão 8 – Extra: Golpes com dados vazados
**Objetivo:** entender como golpistas usam dados vazados e como se proteger.
📅 **Data da aula:** ........ / ........
### 💡 Para começar
**Vazamento de dados** é quando informações de muitas pessoas escapam de um site ou empresa e caem nas mãos de criminosos.
**Por que é perigoso?** Com os seus dados verdadeiros (nome, CPF, telefone), o golpista parece **confiável**: “Olá, Ana Souza, CPF terminado em 12, sua compra foi aprovada…”.
| Golpe | Como é |
| 📞 Falsa central | “Aqui é do banco, temos o seu CPF, confirme o código” |
| 📦 Falsa entrega | “Seu pacote está retido, pague a taxa neste link” |
| 🔑 Confirme os dados | “Atualize o cadastro para não perder a conta” |

**Regra de ouro:** **saber os seus dados não prova que a pessoa é de confiança.** Empresa séria não pede senha nem código. Na dúvida: **desligar e ligar para o número oficial** da empresa.
**Se houve vazamento:** troque a senha daquele serviço (e de onde ela se repetia), ative as **duas etapas** e desconfie de contatos que “já sabem tudo” sobre você.
### 📖 O que significa?
- **Vazamento de dados**: quando dados de muitas pessoas escapam e caem com criminosos.
- **Confiável**: que merece confiança.
- **Falsa central**: golpista que finge ser atendente de uma empresa.
- **Taxa**: valor cobrado; nos golpes, é a desculpa para pedir dinheiro.
- **Pacote**: encomenda entregue pelos Correios ou por uma transportadora.
- **Link**: endereço que, ao ser tocado, abre uma página da internet.
### 🌎 Onde eu uso isso?
- Quando chega **e-mail de um site** avisando que houve vazamento.
- Numa **ligação** que já sabe o seu nome completo.
- Num **SMS de entrega** que você não esperava.
### 🎯 Missão
🟢 **Básico** — no portal: descubra o golpe de cada mensagem, coloque em ordem o que fazer depois de um vazamento e responda a regra de ouro.
🟡 **Desafio** — no portal: a ligação que sabia tudo.
🔴 **Turbo** — no portal: caça-palavras do vazamento.
### ✅ Perguntas rápidas
Escreva **V** para verdadeiro ou **F** para falso:
1. ( ) Vazamento é quando dados de muitas pessoas escapam.
2. ( ) Se a pessoa sabe o meu CPF, ela é com certeza de confiança.
3. ( ) Empresa séria não pede senha nem código.
4. ( ) Depois de um vazamento, é bom trocar a senha.
5. ( ) Golpe da falsa entrega pede uma taxa por link.
### 🧠 Resumo da Aula
No **vazamento de dados**, golpistas conseguem dados verdadeiros e parecem **confiáveis**. Golpes: **falsa central**, **falsa entrega** (taxa por link) e **confirme os dados**. Regra de ouro: saber os seus dados não prova confiança. Depois de um vazamento: **troque a senha**, ative as **duas etapas** e desconfie.
**Palavras-chave:** vazamento de dados · confiável · falsa central · taxa
